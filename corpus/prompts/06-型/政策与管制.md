# 读法册 · 政策与管制（**规则侧**）
> **输出格式 = 本册模板** `corpus/templates/06-政策与管制.md`：抄一份到 `output/<标的>/<材料 id>/material.md` 再填；**采不到的栏目整节删掉，不呈现空项**（模板由 `system/scripts/env/gen_templates.py` 从本册生成，勿手改模板）。

适用于：法规原文、机构决定、判决、关税、出口管制、制裁、反垄断、数据与 AI 立法、补贴与产业政策。

**这一册只做一件事**：把"规则变了"变成"谁必须改什么、从哪天起、不改会怎样"。

## 1. 文书状态机（本册最重要的表）

同一个政策，处在不同状态，影响完全不同。**判断状态是第一步，不是最后一步。**

| 状态 | 含义 | 能不能提修正 |
|---|---|---|
| 提案 / 征求意见（proposed / comment period） | 还没定 | 只能"不确定性通道"，不许算影响 |
| 终稿（final rule） | 已定，但可能未生效 | 可算方向，幅度标"待生效" |
| 刊登（published in Federal Register） | 已公示 | **不等于已并入 eCFR，也不等于已生效** |
| 生效（effective） | 开始约束 | 可算影响，写生效日 |
| 分阶段 / 过渡期（phase-in） | 部分条款延后 | 必须写"哪条哪天起" |
| 被诉讼 / 中止（stayed） | 执行暂停 | 影响延后，写"程序风险" |
| 被废止 / 被推翻 | 不再有效 | 写"已失效"，并追替代规则 |
| 豁免 / 祖父条款（grandfathering） | 存量不受约束 | 写清"谁被豁免、豁免到哪天" |

**四条铁律**：

1. "已刊登"≠"已生效"，"已生效"≠"已执行"。
2. 法规要查**两处**：`Federal Register`（刊登）与 `eCFR`（现行并入文本），并记版本时点。
3. 有诉讼就写诉讼状态；有过渡期就写时间表。
4. 引用他国规则必须标法域与机构，不许用"国际惯例"。

## 2. 四类政策域（每类的关键变量不同）

| 域 | 典型文书 | 关键变量 | 谁被迫动 | 常见误判 |
|---|---|---|---|---|
| **贸易与出口管制** | 实体清单、外国直接产品规则、关税（301/232/IEEPA 等） | 税率/清单范围、许可要求、域外效力 | 出口商、代工厂、渠道、最终用户 | 只看税率不看"许可制"；忽略转口 |
| **反垄断与消费者保护** | 诉讼、和解、经营者集中审查 | 相关市场界定、救济方式（行为/结构） | 交易双方、同业、渠道 | 把"调查"当"处罚" |
| **数据与 AI 立法** | 隐私法、AI 法案、内容责任 | 适用范围（模型/平台）、义务类型（披露/审计/禁止） | 平台、模型提供方、企业用户 | 把"原则性条款"当"硬义务" |
| **补贴与产业政策** | 法案、税收抵免、拨款 | 补贴额度、本地化要求、申领门槛 | 制造商、供应链、选址 | 把"授权额度"当"已拨付" |

**跨域共性**：真正的约束力来自"**许可 + 罚则 + 执法资源**"三件，而不是"表态"。三者缺一，影响要打折。

## 3. 政策不确定性（本身就是一种影响）

**逻辑**：政策未定会压投资、拖决策、抬风险溢价——不需要等落地就已经有影响。

**可观察形式**：

- 政策不确定性指数（新闻词频 + 税码到期 + 预测分歧合成的月度序列）
- 企业电话会里"不确定性/监管"词频
- 资本开支指引的推迟表述

**写法**：遇到提案期/诉讼期，写"**不确定性通道**：决策推迟 → 资本开支延后 → 何时可见取决于 X"，不许写"等落地再说"。

---

## 4. 事件研究（判断"市场是否已反应"）

**做法**：

1. 定事件日（刊登日/生效日/宣判日/新闻首现日）
2. 取窗口（事件前 5 日到后 5 日；政策类可放宽到 ±20 日）
3. 看异常收益与成交量（相对基准）
4. 记录同日其他事件（避免混淆）

**三种结论**：

| 现象 | 结论 | 处理 |
|---|---|---|
| 窗口内显著异动 | 已部分定价 | 修正幅度要扣掉已反应部分 |
| 窗口内无异动 | 未定价，或未被读懂 | 写"未定价"并说明是哪种 |
| 异动方向与预期相反 | 可能读错了通道 | 回第 3 步重找通道 |

**限制**：政策常分多批落地，单一窗口可能抓不到；重大政策要看"累计异动"。

## 5. 五步在本册的落法

| 步 | 本册的具体动作 |
|---|---|
| 1 有没有新信息 | 与上一版规则逐条比：新增什么、删了什么、改了阈值没有 |
| 2 定位与状态机 | 域 → 机构 → 文书号 → 状态格 → 生效日/过渡期 |
| 3 找通道 | 轴（管什么）→ 范围（管谁）→ 主体（谁被迫改）→ 动作（改道/申请/排查/披露） |
| 4 落主体与动作 | 四层逐层过；标"强制"还是"裁量"；写截止日 |
| 5 量级定价证伪 | 受影响收入/成本占比；已定价判断；证伪条件 |

## 6. 必须过一遍的项（美国向）

### 3.1 先判"轴"（第一步，不能跳）

| 轴 | 它管什么 | 美国的例子（出口管制） |
|---|---|---|
| 按用途 | 用途本身被禁，不论买家是谁 | 核、导弹与无人机、化生武器、先进计算与半导体制造设备、超算、AI 模型权重 |
| 按对象 | 对象在名录上、或属于特定用户群体 | 实体清单、未核实清单、军事最终用户 |
| 按行为 / 主体 | 特定主体的行为被禁，不限于物项 | "美国人"条款：禁止"支持"特定用途，含"促成"，且能覆盖不受管辖的物项 |

**多条可以同时命中**。同一笔交易可能同时踩到好几条，许可要求按所有适用条款叠加确定。
重叠管制时，只有在满足所有适用政策时才可能签发许可。所以不能只写"命中其中一条"。

### 3.2 许可要求是怎么被触发的（三层，缺一层就判错）

```
第一层：物项有没有命中分类（清单编码、条目、税则行）
第二层：目的地落没落进这个条目对应的国别组或国别列
第三层：有没有叠加用途或用户条件（名录、特定用途、特定主体）
三层合起来，才决定要不要许可
```

**国别组是官方定义的名单**（出口管制里是 `Supp. No. 1 to Part 740`），例如 `A:1` 到 `A:6`、`D:1` 到 `D:5`、`E:1`、`E:2`。
引用国别组必须写清组号。"某个国家组"不等于"某个国家"。

**常见的列口径**（举几例）：

- `CB:1`：所有目的地，包括最亲密的盟友。
- `NS:1`、`MT:1`、`RS:1`：除澳大利亚、加拿大、英国之外的全部。
- `RS:2`：除 `A:1` 组和印度之外的全部。
- 对澳门或 `D:5` 内的专门段落：管半导体制造设备等。
- 另有"全球任何目的地"的段落；也有专门管阿联酋、`D:1`、`D:4`、`D:5` 的段落。

说"需要许可"时，必须同时写出**列名**和**国别组**，否则别人没法复核。

### 3.3 审查政策与例外（决定"能不能拿到"）

| 政策 | 意思 | 实务上的含义 |
|---|---|---|
| 逐案审查 | 一件一件看因素 | "逐案"不等于"容易批" |
| 推定批准 | 默认倾向批准 | 例外可用空间大 |
| 推定拒绝 | 默认倾向拒绝 | 要有实质理由才可能推翻 |
| 拒绝政策 | 原则上拒绝 | 实际上等于断供 |

**例外与豁免**：很多条款明确写"无许可例外可用"，或者只留极窄的例外。不能默认"总能申请到"。

**合同神圣（祖父条款）**：部分条款允许在某个截止日前签的合同继续履行。
如果涉及既有合同，必须核该条有没有这个日期。没有就写"该条无合同神圣"。

**多边还是单边**：有些管制对应多边安排（核供应国集团、导弹技术控制制度、瓦森纳安排等），有些是美国的单边管制。
要说明是哪一种，因为这决定"盟国会不会一起办"。

### 3.4 名录类（管"谁"）

| 名录 | 管什么 | 关键口径 |
|---|---|---|
| 实体清单 | 未经许可不得向清单主体（或用高风险地址的）出口、再出口、境内转移**该条目"许可要求"栏写的物项** | 例外原则上不可用；审查政策逐条目而定；不发"未列入证明" |
| 未核实清单 | 因为没法完成最终用途核查，所以要多交声明和记录 | 被列入本身就是程序性信号 |
| 军事最终用户类名录 | 面向军事用途、军事用户的专门管制 | 与"民用"的宣称可能打架，见到就上报 |
| 制裁名单（SDN） | 冻结。注意是冻结，不是没收——所有权仍归被冻结的人 | 50% 规则：被制裁方单独或合计、直接或间接持股 50% 及以上的实体，同样被冻结，**不管它自己有没有被列名** |
| 行业类制裁名单 | 非冻结类限制（某些行业禁止交易） | 与冻结名单不是一回事，不能混用 |

**谁必须遵守（美国制裁）**：所有美国公民和永久居民（不管人在哪）、所有在美国境内的人和实体、美国注册的实体及其海外分支。
某些项目还管到它拥有或控制的外国子公司。
非美国人也不是没事：导致或共谋导致美国人违规、以及规避行为，都在禁止范围内。
所以"我们不是美国公司"不能当作不用查的理由。

**穿透要看持股链**。报"受限主体"时必须查持股。
外国直接产品类规则（footnote 型）会把在境外生产的产品也纳进来，不能只看"在哪里造"。

### 3.5 关税类（美国有四种工具，授权和程序都不一样）

| 工具 | 典型形式 | 生效与程序要点 |
|---|---|---|
| 国家安全关税（`Section 232`） | 商务部调查后由总统发公告 | 以公告加联邦公报为准；有豁免和排除程序 |
| 对特定国家的不公平贸易关税（`Section 301`） | 贸易代表办公室调查后发公告 | 有排除程序，也有到期复审 |
| 紧急权力关税（`IEEPA`） | 总统行政令加机构实施 | 授权范围和司法挑战并存，引用必须写当前有效状态 |
| 国际收支关税（`Section 122`）、歧视性贸易（`Section 338`） | 备用工具 | 期限和上限由法条限定，引用要写清 |

**三条硬口径**：

1. 税则变化以联邦公报和海关公告为准。分类落在 `HTSUS` 行上，行号就是引用单位。
2. 同一件商品可能同时叠加几种关税，必须写清叠加关系和例外。
3. "税率"不是唯一变量。生效日、适用范围、排除清单、报关时点都要记——报关时点决定适用哪一版。

### 3.6 反垄断与消费者、数据保护（管"行为"和"交易"）

| 主题 | 美国要点 | 必须过一遍的 |
|---|---|---|
| 并购申报 | 申报门槛和申报费**每年调整** | 报"要不要申报"必须写当年门槛和适用年度；等待期届满或获准提前终止前不得交割 |
| 等待期计算 | 遇到联邦假日怎么顺延，分两种情形（假日当天、还是次日补休） | 结果不一样，写"等待期哪天到期"要带计算规则 |
| 政府关门、机构停摆 | 停摆期间不收申报，但已经到期的等待期不受影响 | 不能拿"停摆"推断交割会延期 |
| 审查升级 | 收到二次要求，等于实质审查开始 | 见到就报"审查期会明显拉长" |
| 程序效力 | 申报表格和规则的效力可能被诉讼改变（曾出现过"地区法院撤销、上诉法院暂缓、再撤销"的反复） | 报"该用哪张表、哪版规则"必须写明查询时点，这类状态会变 |
| 消费者保护、数据与未成年人 | 联邦层面以禁止不公平或欺骗性行为为核心；未成年人数据有专门规则；各州另有立法 | 合规状态要写联邦和各州两层，州法可能更严 |
| 执法文书形态 | 典型有：不予行动函、警示函、违法认定、民事罚款、和解、刑事移交 | 引用执法时要写清是哪一种。和解不等于判决，罚款不等于认定违法 |

### 3.7 生效与状态（美国最容易栽的地方）

| 项 | 必须做到的 | 常见坑 |
|---|---|---|
| 生效日看哪里 | 联邦公报是生效日和文本修订的权威刊载 | 拿机构网页口径当生效日 |
| 分清三层 | "已在联邦公报刊登"不等于"已并入现行法规"，也不等于"确定已生效"。官方文本会挂"交叉引用"提示，说另有会修改它的联邦公报文件 | 只读现行法规就下结论 |
| 技术性未并入 | 官方文本的编注会说明某项修订因技术原因没能并入 | 默认现行文本已是最终状态 |
| 中止或待生效 | 明确写"中止至某日"或"生效日待定"的条款，必须照写状态 | 把中止的条款当已生效 |
| 过渡期与祖父条款 | 新规对既有合同、在途交易的特别安排 | 只看新规生效日 |
| 版本定位 | 引用条文必须记查询日期和条文版本时点（可按日期比对） | 引用不带版本，别人没法复核 |
| 程序状态 | 已生效、待批准、上诉中、被法院暂停——判决不等于终局 | 把一审判决当定局 |

### 3.8 罚则与执法机构

要记：罚则上限（民事罚款按通胀每年调整）、主管机构、自愿自我披露的减轻作用、报告义务的期限（例如资产被冻结后要在限定期限内报告）。
自愿披露不是免费的，只能写"可以作为减轻情节"，不能写成"披露就免责"。

### 3.9 敞口（必须算，不许口算）

| 项 | 拿到什么算过 | 常见坑 |
|---|---|---|
| 受限地区或业务占比 | 分子、分母、基期、算式都要有，落到 `derived/` | 口算；不记基期 |
| 合规成本、受影响业务 | 逐项写：什么项、怎么估的、假设是什么 | 把"估算"写成"已发生" |
| 生效日与披露的时间差 | 规则已生效而公司未披露影响，就记"已生效但未披露" | 写成"影响可忽略" |

## 7. 问句表

## 8. 红线

1. 不许拿媒体转述当生效依据，不许用"已刊登"当"已生效"。
2. 不许把提案期政策算成确定影响（只能走不确定性通道）。
3. 不许只看税率不看许可制与域外效力。
4. 不许把"授权额度"当"已拨付"。
5. 不许把"调查"当"处罚"。
6. 不许漏四层影响面。
