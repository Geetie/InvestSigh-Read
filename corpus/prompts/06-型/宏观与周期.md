# 读法册 · 宏观与周期（**读数侧**）
> **输出格式 = 本册模板** `corpus/templates/06-宏观与周期.md`：抄一份到 `output/<标的>/<材料 id>/material.md` 再填；**采不到的栏目整节删掉，不呈现空项**（模板由 `system/scripts/env/gen_templates.py` 从本册生成，勿手改模板）。

适用于：官方统计（GDP、CPI、就业、PMI、零售、工业产出）、央行决议与预测、周期判定、权威行业统计。

**这一册只做一件事**：把一个读数变成"相对于预期的偏离 + 分项结构 + 体制定位"，而不是"数据好坏"。

---

## 1. 五步详解

| 步 | 做什么 | 具体做法 |
|---|---|---|
| 1 取数 | 指标名、数值、期间、口径、发布方 | 口径要写"季调年化""同比""环比折年"中的哪一个；初值与修订值分开记 |
| 2 算意外 | 实际 − 共识，标准化 | `意外 = (实际 − 共识中位数) / 历史意外标准差`；记共识来源（哪家调查、中位数、样本量） |
| 3 分解 | 这个数由哪几项贡献 | 至少两组：核心 vs 食品能源；商品 vs 服务；sticky vs flexible；新订单 vs 生产 vs 就业 |
| 4 定体制 | 增长格位 × 通胀格位 × 金融条件 | 四象限（过热/滞胀/复苏/衰退）+ 条件松紧 |
| 5 传导定价 | 折现率、融资成本、需求三条路径 | 每条写"幅度 + 滞后 + 已定价判断" |

**关键区分**：`意外` 是"相对预期"，`水平` 是"绝对读数"，`趋势` 是"连续三个期间的方向"。三者不能互相替代。

## 2. 六个指标族（每个族只记三件：看什么、口径坑、领先性）

六族各测一件事，**族与族打架不是噪声**：增长强、就业弱说明复苏不均衡；通胀降、工资涨说明是服务端黏性。
看表时先找「哪两族打架」，再决定要不要动体制判断——**单族数据永远不改体制**。


### 2.1 增长

| 指标 | 看什么 | 口径坑 | 领先性 |
|---|---|---|---|
| GDP（初值/修正/终值） | 环比折年 vs 同比；消费/投资/库存/净出口分解 | 库存变动会大幅摆动；净出口是减项 | 滞后（季末后 4 周起） |
| 官方 nowcast（GDPNow 类） | 实时 GDP 跟踪估计 | 是模型估计不是官方数据，会随新数据跳变 | 同步/领先 1–2 月 |
| PMI / ISM | 50 分界；新订单分项领先总体 1–2 月 | 扩散指数不是量；制造业与服务业分开 | 领先 |
| 工业产出与产能利用率 | 产能利用率分位 | 产能利用率高 ≠ 供给紧（要看瓶颈环节） | 同步 |
| 零售与个人消费 | 名义 vs 实际；含不含汽车 | 名义增长可能全是价格 | 同步 |

### 2.2 通胀（分解是本册最重要的技能）

| 层 | 分法 | 为什么重要 |
|---|---|---|
| 第一层 | 总体 vs 核心（剔除食品能源） | 核心才是趋势 |
| 第二层 | 商品 vs 服务 | 商品受供应链，服务受工资 |
| 第三层 | 住房 vs 非住房服务（supercore） | 住房滞后 12–18 个月；supercore 看工资传导 |
| 第四层 | **sticky vs flexible** | 粘性项决定通胀是否持久；单月 flexible 波动大 |

| 口径坑 | 说明 |
|---|---|
| CPI vs PCE | 权重不同、覆盖不同；政策目标通常看 PCE |
| 环比折年 vs 同比 | 单月环比折年会把噪声放大 12 倍 |
| 季调 vs 未季调 | 未季调有强季节性 |
| 修订 | 季调因子每年更新，历史序列会变 |

### 2.3 就业

| 指标 | 看什么 | 口径坑 |
|---|---|---|
| 非农就业 | 三个月均值比单月可靠；注意罢工与天气 | 初值与修订可差数万 |
| 失业率（U3/U6） | U6 含灰心与兼职 | 参与率变化会同时改变分子分母 |
| JOLTS | 空缺数、离职率（quits） | 滞后约 1 个月；空缺 ≠ 招聘 |
| 周度失业金 | 初请与续请 | 季节性调整与假期 |
| 裁员公告 | 领先于非农 | 公告 ≠ 实际裁员时点 |

### 2.4 金融条件

| 指标 | 看什么 | 口径坑 |
|---|---|---|
| 金融条件指数（NFCI/FCI 类） | 松紧分位（0 = 平均） | 各机构权重不同，跨源不可比 |
| 信用利差（HY OAS、IG OAS） | 风险溢价 | 利差收窄可能是"风险偏好升"也可能是"供给少" |
| 期限利差 | 2s10s、3m10y | 倒挂的预测力随周期变 |
| 美元指数 | 对出口与海外收入 | 名义 vs 实际有效汇率 |
| 银行信贷标准（SLOOS 类） | 收紧/放松净占比 | 季频、滞后 |

### 2.5 信用与流动性

| 指标 | 看什么 | 口径坑 |
|---|---|---|
| 央行资产负债表 | 规模与结构（准备金/逆回购） | 规模下降不等于紧（可能只是逆回购回落） |
| 银行准备金 | 充裕程度 | 需与需求对比，单看余额无意义 |
| 货币供应（M2 类） | 增速 | 口径多次调整，历史不可直接连 |

### 2.6 外部与财政交叉

| 指标 | 看什么 | 口径坑 |
|---|---|---|
| 贸易差额 | 货物 vs 服务 | 转口与统计归属 |
| 经常账户 | 占 GDP 比例 | 季度、滞后 |
| 财政赤字 | 占 GDP 比例；基本赤字 vs 总赤字 | 含利息与否差很多 |
| 国债发行 | 净发行 vs 到期滚动 | 见《财政与国债供给》 |

## 3. 意外指数（把单点变成序列）

**定义**：把多个指标的"实际 − 共识"按历史波动标准化，再加权平均，做三个月加权移动（含时间衰减）。

**读法**：

- 指数 > 0：数据流系统性好于预期；< 0：差于预期。
- **指数会均值回归**：连续多周同向后，反转概率上升。
- 指数高不等于经济好——它只说明"比预期好"，而预期可能已经很悲观。

**用途**：判断"这一轮数据流的方向"，而不是判断单个数据。催化剂卡里的"意外"栏，用单指标；宏观读数卡的第 4 栏，可以引意外指数作背景。

## 4. 体制四象限（决定"这个数该往哪个方向读"）

| | 通胀上行 | 通胀下行 |
|---|---|---|
| **增长上行** | 过热：政策偏紧，久期受压 | 复苏/金发女孩：风险资产友好 |
| **增长下行** | 滞胀：最难受，股债双杀 | 衰退：政策转松，久期受益 |

**定位方法**：

- 增长维：PMI/nowcast/就业三个月方向
- 通胀维：核心与 supercore 三个月方向
- 金融条件：NFCI 分位（松/中/紧）

**纪律**：体制是"当前格位 + 是否在切换"，不是预测。写"滞胀 → 过渡中"，不写"明年复苏"。

## 5. 政策反应函数（只写路径，不写预测）

| 参考 | 怎么用 | 限制 |
|---|---|---|
| 泰勒规则类 | 用增长缺口与通胀缺口算"规则利率"，与政策利率对比 | 参数选择不同结论不同 |
| 央行预测（点阵图/SEP） | 委员中位数路径 | 非承诺 |
| 市场定价（OIS/期货） | 隐含路径 | 含风险溢价，见 `07` |

**写法**：`规则利率 X%（参数：…）、政策利率 Y%、市场隐含 Z%`，三者并列，不取舍。

## 6. 必须过一遍的项（美国向）

### 3.1 口径与版本（缺一项，这个数就不能写进结论）

| 项 | 拿到什么算过 | 常见坑 |
|---|---|---|
| 估计层次和版本 | 写清是首次、第二次、第三次估计，还是年度更新或基准修订之后的 | 混用不同版本，变化率就算错 |
| 季调还是未季调 | 写清是季调还是原口径 | 拿季调数做跨年比较，忘了年度会重算 |
| 同比还是环比，期间多长，基期是什么 | 三项都写全 | 把同比当环比；换基之后不可比 |

**美国官方口径有四件事，写报告时要带上**：

1. 官方统计同时发布"未季调"和"季调"两套（季调用季节因子调整）。
2. 季节因子每年集中更新一次，并据此回溯修订此前若干年的季调序列。
   所以同一指标的季调序列，跨年不是同一串数。长期比较优先用未季调或同比；季调数不适合用于长期指数化或长期合同口径。
3. 估计分层次，而且能回溯的时间跨度递增：当前估计（当季，范围最小）到年度更新（可回溯数年），再到基准修订（大约每五年一次，回溯更长）。
   引用"历史序列"必须写是哪一层之后的版本。
4. 同一季度会发好几轮（首版、二版、三版），年度还有年度估计。版本信息不能省。

### 3.2 机构与指标的对应（真源在检索表册，这里不复制）

逐族指标（机构、频率、口径要点）见 `system/env/meta/prompts/06-型/宏观与周期细目.md`。

这一册只保留两条操作性规则：

1. 引用"将于何时发布"必须回该机构的日程表，不能用第三方汇总当依据。
2. 同一指标有多个机构版本时不要混用。比如物价有 `CPI` 和 `PCE` 两套，引用必须写清是哪一套。

### 3.3 央行件的四个分身（引用时必须写明是哪一份）

| 件 | 给什么 | 关键口径 |
|---|---|---|
| 决议、政策声明 | 利率目标区间，加投票结果和异议（异议具名，并写明主张） | 用区间，不用点位。票数形态（比如 12 比 0、11 比 1、10 比 2）本身就是信息 |
| 实施说明 | 政策工具怎么落地（准备金余额利率、贴现率、隔夜逆回购等） | 它才说清"怎么落地" |
| 会议纪要 | 讨论过程和各方的分歧 | 发布时点等于政策决定日加 3 周（跟下次会议无关）；不是逐字记录，逐字记录 5 年后才公布 |
| 经济预测 | 增长、失业、通胀的预测（含中位数、集中趋势、区间），加利率预测和点阵图 | 只有部分会议随发，不是每次都有一份；点阵图是各个参与者的路径，不是委员会决议 |

**会议节奏**：每年 8 次例会。委员会成员在当年第一次例会时更替。会议日期在紧邻前一次会议确认之前都是暂定的，引用未来日期要标明"暂定"。

**三件不能混成一句"央行认为"**：决议是决定，纪要是过程，预测是分布。

### 3.4 周期位置（美国有"判定人"，但它不是政府机构）

| 项 | 必须做到的 | 常见坑 |
|---|---|---|
| 谁在判 | 全国经济研究局的周期判定委员会（私人研究机构，但被当作官方口径） | 随口说"衰退" |
| 依据什么 | 一组指标（实际 GDP 与国民总收入、就业、产出、收入），不是只看 GDP | 拿"连续两个季度负增长"当定义，那不是官方定义 |
| 什么时候能知道 | 判定和宣布明显滞后，是事后判定，当期无法确认 | 把"尚未宣布"读成"不会发生" |
| 记录在哪 | 起止时点以该委员会的公告为准 | 拿媒体口径当判定 |

因为判定滞后，这一册只写"当前位置的读数与依据"，不写"现在是衰退"，除非该委员会已经公告。

### 3.5 行业周期源（是行业一手，不是官方统计）

| 主题 | 典型来源 | 要注意的 |
|---|---|---|
| 半导体销售额与预测 | 行业协会（月度销售、季度与年度预测） | 标明"行业一手"；记发布频率和时点（月度还是季度） |
| 半导体设备出货与订单比 | 设备行业协会 | 标明"行业一手"；记口径（出货、订单、还是比值） |
| 算力与数据中心周期 | 优先用公司法定披露的资本开支和合同（那属于事实层） | 不能用第三方估算冒充公司口径 |

**可信度怎么标**：政府统计算能逐行核的一种；行业协会、交易所、私营数据商要看它是不是原始发布者；二手转述更低一档。

**这一册不许问**：管什么、名录上有谁、罚多重、许可例外怎么用（那是另一册的事）。
**不许由读数下"某只票会怎样"的结论。**

**答不上来不等于跳过**：要写清为什么答不上来（官方未标、未发布、只给了中位数、尚未判定、需要跨批）。

## 8. 红线

1. 不许把水平当意外、把单月当趋势、把修订当新信息。
2. 不许用同比与环比混着比；不许用未季调与季调混着比。
3. 不许只报总量不报分解。
4. 不许由宏观读数直接下"单票"结论（那是催化剂系统的活）。
5. 不许把行业统计当政府统计。
6. 不许把 nowcast 当官方数据。
