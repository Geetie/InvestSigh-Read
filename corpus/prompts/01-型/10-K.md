# `01` · **10-K**（年报）—— 这一类怎么读

> 本件是 `system/env/meta/prompts/01-监管一手披露.md` 的**分册**：主件说**这是哪一类**，本件说**怎么读、必须过哪些项、问什么、有哪些坑、见到什么要上报**。
> **边界**（本册可能被单独交付，故自带）：**可读＝仓库根以下全部（只读）**；**可写＝仅 `output/<标的>/<材料 id>/`**；其余禁写（`README §3.1.1`）。
> **本册自包含**：只拿到本册也要能干活 —— 跨类**只写"口径差异提醒"，不引用别的册**（别册可能不在手）。
> **落点 = `system/env/meta/valuation-model.md` 上的格**（本册问句的"填哪一格"列就是它）；**篮子只是存放答案的地方**。档位口径（**Ⅰ 可逐行复核 / Ⅱ 二手 / Ⅲ 未核**）见该文件。
> 报告**给人看**：认知增量先行、说人话、**不出现段号与回执计数**（那些只落 `覆盖回执.csv`）。输出表达六条纪律见 `RUN-PARALLEL §2.4`；本册特有：审计意见与内控意见（ICFR）只此一份，出处写到报告名。
> **输出格式 = 本册模板** `corpus/templates/01-10-K.md`：抄一份到 `output/<标的>/<材料 id>/material.md` 再填；**采不到的栏目整节删掉，不呈现空项**（模板由 `system/scripts/env/gen_templates.py` 从本册生成，勿手改模板）。

## 0. 它是什么

**认它的痕迹**：`DocumentType=10-K`，`DocumentFiscalPeriodFocus=FY`，正文含 `Part I–IV` 的 `Item 1–16`。

| 别问 | 为什么问了也没用 |
|---|---|
| `8-K` / `EX-99.1` 的问句 | 那些件**没有完整三表与附注**，"指引三要素""桥"在别处 |
| `10-Q` 的"单季 vs 年初至今"问句 | 年报是**年度口径**，混用会把年度数字当季度 |
| `委托书` / `招股书` / `13D·G` / `Form 4` 的问句 | 那些是治理、募资、行为事实，**年报里拿不到** |

**反向也要守**：年报的 `Item 10–14` 在很多公司是"**并入委托书**"（法定允许）⇒ 那不是缺口，要写"**并入委托书（指针）**"。

## 1. 怎么读（回执单元是**可数**的）

**读法的依据（不是自己定的规矩）**：

- **每一段都要有交代**。读了、有理由的略读、或者对本文不适用，都写明。不许只记"必过项"。（依据：`撰写规范 §1.9`；守卫 `system/scripts/checks/material_spans_guard.py`）
- **抄下来的必须有数字**。量名、数值、期间、口径，缺一样就不算数。实在没有数可写，就写"放不进任何篮子"的理由。（依据：`撰写规范 §1.8`）
- **数字分级 ＋ 两条数据纪律**。Ⅰ 可逐行复核，Ⅱ 二手带链接，Ⅲ 未核。同一个数字要有两个以上独立来源，偏差超过 2% 就要报警。自定义口径（non-GAAP 等）必须建定义卡。（依据：`撰写规范 §7.5`）
- **值得报 ＝ 定量 ＋ 定性**。定量只是起点。掩盖趋势、掩盖未达预期、亏损转盈、涉及重要分部、影响监管或契约合规、增加管理层薪酬——这些定性因素可以让金额小也照样重大。中期也要评。（依据：SEC `SAB 99`）

所以：`Item` 和附注只是**去哪儿找**（定位）。落库的单位是**段**——每段有决定，段的并集等于全文。

**官方建议的读序**：`Item 1` → `1A` → `7` → `8` → `9 / 9A` → `Part III` 靠委托书补。
**多数人不看但要看**：`1B`、`7A`、`9`（会计分歧）、审计意见的非标准类型、`Exhibit 31/32` 的 SOX 认证（取方法，条目以现行规则为准）。

### 1.1 读的单元 = **三块，可数**

| 块 | 单元 | 数量 | 回执要求 |
|---|---|---|---|
| **`Item` 块** | `Part I–IV` 的 `Item 1 · 1A · 1B · 1C · 2 · 3 · 4 · 5 · 6 · 7 · 7A · 8 · 9 · 9A · 9B · 9C · 10 · 11 · 12 · 13 · 14 · 15 · 16` | **23** | 每个单元一条回执 **+ 一句人话**（"本单元最硬的一处事实 / 无"） |
| **附注块** | 该件的**全部附注**（家数因公司而异，**要把编号数出来**） | 按件数 | 同上 |
| **报表块** | 资产负债表 / 利润表 / 综合收益表 / 现金流量表 / 股东权益变动表 | **4–5** | 同上 |

**为什么这样切**：`Item` 与附注序列是**法定骨架**（`Reg S-K` / `Reg S-X`）—— 它是**位置全集**，不是"重要位置子集"
⇒ 走完骨架**不存在"必过项之外的藏身处"**；而单元数是**两位数**（不是几千段）⇒ **可行**。

### 1.2 三层读法（越往下越深，**只在命中处加深**）

| 层 | 用在哪 | 怎么读 |
|---|---|---|
| **骨架层** | 全部单元（§1.1） | Item 1 的 Business 段末尾或 MD&A 首段会给关键运营指标的定义：抄清它把哪些主体并进这个数（含不含新并入的业务）、分母取平均还是期末。定义或分母与上年不同，单独写一句「跨年不可直接比」，不要自己换算补齐。数取 Item 8 的表格，不取 MD&A 的复述。 |
| **自由段层** | **无固定骨架的叙述段**：`Item 7` 的归因段 · `Item 1A` 风险 · 附注里的"承诺与或有" | MD&A 的 Results of Operations 看收入有没有拆成量与价（销量或用户数×单价这类口径）：有就分项抄，只给总增速写「未拆分」，不许用「量价齐升」代替分项。新产品或新业务单列才记，合并进总量的注明被并进哪一行。分项数取 MD&A 对照表，不取正文形容词。 |
| **升级层** | 命中**信号词**：重述 · 减值 · 审计师变更 · **变更估计** · 诉讼 · 契约 · 重大缺陷 · 网络安全事件 | 看收入附注（Revenue 或 Segment）有没有按主要产品或服务拆成多行：记主营之外第二、第三条收入腿的金额、增速与占比。只在正文提一句而无表格行的，写「未单列」，并把那句话抄进依据。 |

### 1.3 停止条件

**不是"读完了"**，而是：**§1.1 的单元全部有回执**（已答 / 具名缺口 / 不适用），且 §4 问句表**每条都有答案或具名缺口**。
**不许截断 / 抽样**：不看"前 N 页"、不用摘要代替正文、不因太长跳过任何单元。
例外只有一种，且**必须写理由**：`Item 6`（已 `[Reserved]`）· `Item 4 / 9C / 16`（常年 "Not applicable" / "None"）。

## 2. 结构上必然携带（Q1：这类文书**必然**有什么）

| 必然携带 | 别处拿不到的是什么 |
|---|---|
| ① **经审计的三表 + 全部附注**（含政策、估计、承诺、或有、税、租赁、债务） | **一手口径**：金额、期限、假设、重分类说明 |
| ② **`Item 7` MD&A**：上年同期对比 + **流动性与资本资源**（短/长期分开）+ **关键会计估计** | **管理层对"为什么"的解释**，以及**估计的不确定性与敏感性**（法定要求） |
| ③ **`Item 1A` 风险因素**（按重要性排序，前几条是管理层真在意的） | **风险增量**（与上一份年报比，哪条变强/新增） |
| ④ **治理与内控**：审计意见 + **关键审计事项（CAM）** + **ICFR 意见** + 审计费 | **红灯的法定落点**（内控、审计师、重述） |
| ⑤ **`Item 5` 股本与回购**（含**授权额度**与月度回购）+ **`Item 15` 展品索引** | **资本配置的硬事实**；**重大合同的线索** |

## 3. 必过项（穷举）

### 3.1 `Part I–IV × Item 1–16`

| Item | 去哪儿看 | 拿到什么算过 | 常见坑 |
|---|---|---|---|
| **1** 业务 | 全文 + 分部/产品段 | 收入来源与结构 · **客户集中度** · 竞争与季节性 · **人力资本** | 只抄"我们是谁"，不抄**结构数字** |
| **1A** 风险 | 按顺序读 | ①监管/诉讼/供应链类；②**任何带数字或期限**的风险句 | 把"样板风险"当新息；漏**带数字**那几条 |
| **1B** 未决员工意见 | 该项 | **有无** | 无也要**回执"无"** |
| **1C** 网络安全 | 该项 | 治理流程 · 重大事件 · 是否量化 | 模型可能**没有对应格** ⇒ 见 §6 |
| **2** 物业 | 该项 | 数据中心**自有 vs 租赁**与规模 | 与**资本开支 / 租赁附注**对不上 |
| **3** 诉讼 | 该项 + 或有附注 | 逐条：**案由 · 阶段 · 求偿额** | 与附注**一处详一处略** |
| **4** 矿山安全 | 该项 | **回执"不适用"** | 直接跳过不写 |
| **5** 股本与回购 | 该项 + 封面股本 | **回购授权额度与已用** · **月度回购表** · 稀释股数 | 只看现金流量表回购行 ⇒ **漏授权余额** |
| **6** `[Reserved]` | —— | 回执"已废止" | 按旧模板找"五年财务摘要" |
| **7** MD&A | 全文 | ①**量价 / 数量 / 新产品的分解**；②**流动性**（短期 12 个月内 vs 长期分开）；③**资本资源**（资本支出承诺 + 资金来源与用途）；④**关键会计估计**（不确定性 + 假设期间变化 + 敏感性） | 只读"亮点"不抄归因数字；**漏关键会计估计段** |
| **7A** 市场风险 | 该项 | 利率/汇率敞口的**量化** | 与债务附注的利率、到期对不上 |
| **8** 报表与附注 | 见 §3.2 | 三表 + **审计报告** | **最大的漏**：只读三表、跳过附注 |
| **9** 会计师变更 | 该项 | **有无**（有 ⇒ 红灯） | 与 `8-K` 的对应条目冲突时要点出 |

| **9C** 阻碍检查辖区 | 该项 | 回执（通常"不适用"） | 跳过不写 |
| **10–14** 治理/薪酬/持股/关联/审计费 | 该项**或**"并入委托书"的指针 | ①董事与高管 · ②**薪酬挂钩指标** · ③**激励池余额** · ④关联交易**条款** · ⑤**审计费四类与非审计费占比** | 只读年报就写"无治理信息" ⇒ 应写"**并入委托书，需配对读**" |
| **15** 展品索引 | 逐条 | **哪几份是重大合同**（`10.x`）、信贷协议、股权激励计划；**`Exhibit 31/32` 的 SOX 认证**（CEO / CFO 对准确性的认证） | 只看"有没有"，**不记是哪份**；漏 **31/32**（官方点名的"多数人不看但要看"） |
| **16** 摘要 | 该项 | 回执（通常"None"） | 跳过不写 |

### 3.2 财报与附注（常规序列）

> 顺序与家数**随公司而异** ⇒ **先数出编号，再逐条过**；下表是"常见家数"，**缺哪条要回执"该件未设此附注"**。

| 附注（常见） | 拿到什么算过 | 常见坑 |
|---|---|---|
| **重要会计政策与估计** | 收入确认 · 合并原则 · **估计与判断**（含**寿命 / 残值 / 减值假设**） | 只读"政策名"，不抄**估计数值** |
| **收入确认与分解** | 分解维度（区域 / 产品 / 线上-线下）· **量价或驱动因子** | 拿"总增速"当分解 |
| **分部信息** | 各分部**收入 / 营业利润 / 资本开支** + **定义是否变更** | 重分类不给对照 ⇒ **不得与上期相减** |
| **企业合并 · 商誉与无形** | 商誉与无形**余额 · 减值测试假设 · 本期减值** | 漏**减值测试假设** |
| **固定资产 · 折旧** | **寿命与残值逐字**（是否分档）+ 在建工程 + 折旧行 | 只看折旧金额，不看**寿命表述** |
| **租赁** | 使用权资产 · 租赁负债 · **未来最低租赁付款** | 把租赁负债当"债务"直接加总（口径不同） |
| **债务** | 各类债务**余额 · 利率（固定/浮动）· 到期表 · covenants** | 漏浮动利率敞口与到期集中度 |
| **承诺与或有** | **采购承诺（含期限）** · 诉讼/和解 · 许可 · 担保 | 年报**最容易撞出"缺行"**：金额 ＋ **期限/生效日** |
| **所得税** | 有效税率 · **税率桥构成项** · 递延税 | 只看税率不看**一次性税负落在哪一行** |
| **股份支付** | 费用额 · **稀释股数** · 未确认费用与摊销年限 | 漏"未确认费用摊销期" |
| **公允价值与衍生品** | 层级（1/2/3）· 衍生品名义额 | 忽略 Level 3 假设 |
| **关联方交易** | 对象 · 金额 · **条款** | 只看金额不写条款 |
| **审计师报告** | ①意见类型；②**关键审计事项（CAM）**；③**ICFR 意见** | 只抄"无保留意见"，漏 CAM 与 ICFR |

### 3.3 条件项（**不一定有**，但必须有回执）

| 条件项 | 回执怎么写 |
|---|---|
| **剩余履约义务（`RPO`）** | 该公司业务模式若无此概念 ⇒ 写"**该公司无此披露**"（**不是缺口**） |
| **期后事项附注** | 该件未单设 ⇒ 写"**未单设此附注**"（**不是缺口**） |
| **`Item 1B / 4 / 9C / 16`** | "**不适用 / 无 / None**" 也是回执 |
| **`Item 10–14`** | "**并入委托书（指针）**" |

## 4. 问句表

每条都要给六样：**问什么 · 去哪找 · 拿到什么算过 · 答不上来怎么写 · 频次 · 落哪一格**。
**最后一列给的就是落点**（`valuation-model.md` 的模型行）；括号里是**篮子**。**挂不上格 ⇒ 报"缺格"**（不是噪声）。

| # | 问什么 | 读法 | 拿到什么算过 | 答不上来怎么写 | 频次 | 落哪个篮子 |
|---|---|---|---|---|---|---|
| Q1 | **用户与参与度的口径**是什么？**含不含新东西**（如 AI 会话）？与上期**同口径**吗？ | Item 1 的 Business 段末尾或 MD&A 首段会给关键运营指标的定义：抄清它把哪些主体并进这个数（含不含新并入的业务）、分母取平均还是期末。定义或分母与上年不同，单独写一句「跨年不可直接比」，不要自己换算补齐。数取 Item 8 的表格，不取 MD&A 的复述。 | 口径原文 + 是否可比 | "**未说明口径**" ⇒ 该格仍半填 | 年 | M-1 用户与注意力（`用户与参与度口径`） |

| Q5 | **人力成本与股份支付**怎么拆（提效体现在哪一行）？ | 人力成本拆两处看：cost of revenue 与 R&D/SG&A 中的人员费用；股份支付取现金流量表补充披露的总数。两者口径不同（现金 vs 非现金），不要把 SBC 加进人力成本总额凑一个数。 | 费用额 + 未确认摊销期 | "**未拆分**" | 年 | M-6 成本·人力（`费用与人力结构`） |
| Q6 | **资本支出的承诺**是多少？**钱从哪来、干什么用**？ | 取 purchase obligations / contractual commitments 表：总金额与到期分布（一年内、1–3 年、3 年以上），另抄资本开支指引的原话。表里没有的年份不要插值。 | 承诺金额 + **期限 / 时间区间** + 资金来源与用途 | "**未给金额或期限**" ⇒ 常是**缺行** | 年 | M-7 资本开支（`资产与资本开支` · `承诺与或有事项`） |
| Q7 | **回购**做了多少？**授权还剩多少**？股本是**净增还是净减**？ | 三样一起记：授权总额、已回购金额、剩余额度；再对股本变动表（期初/期末 shares outstanding）与回购均价。回购金额很大但股本没降，要指出是抵了 SBC 稀释。 | 期内回购 + **授权余额** + 股本净变动 | "**本期回购为 0**"——**这也是答案** | 年 | M-8 资本配置（`回购与股本变动`） |
| Q8 | **亏损业务分部**的收入与亏损**环比方向**？分部**定义改了吗**（能否相减）？ | 分部附注里找常年亏损或单独列示的那一块（常写作 Corporate / Other / Unallocated）：记收入、营业亏损，以及分部定义与费用分摊是否变过。定义变了写「因口径调整不可比」，不要拿新旧数字算增速。 | 各分部收入/营业利润 + 定义是否变更 | "**重分类未给对照**" ⇒ 该期**不得相减** | 年 | M-9 拖累项（`分部与区域结构`） |
| Q9 | **诉讼与监管**的**阶段与求偿额**？会不会变成可计量负债？ | 按 contingencies 附注逐条记：案件名、阶段（立案/上诉/和解）、是否已计提、求偿额或区间。只有「可能发生」而无金额的，写「未计提、无金额」。 | 逐条：案由 + 阶段 +（有则）金额 | "**未给金额**" | 年 | M-10 或有负债（`诉讼与和解` · `监管与合规事项`） |
| Q10 | **治理与内控**有无红灯（审计意见 / **CAM** / **ICFR** / 审计师变更 / 重述）？ | 看三处：审计意见类型（是否标准无保留）、ICFR 结论（是否有效）、有无重大缺陷或重述。任一处非标准，直接写进结论第一句，不要埋在中段。 | 明确"有 / 无" +（有则）**哪一段、什么内容** | "**无异常**（已过：`Item 8` 报告 + `9 / 9A`）" | 年 | 守门（不填格，拦错；`内控与审计事项`） |

**不许出现别类的问句**（见 §0）；**年报里没有的项，就不答那一项的问**。
**答题规矩**：**答不上 ≠ 跳过** —— 写"**为什么答不上**"（披露未含 / 附件未在手 / 载体不可读）。**具名缺口远比一个像样的猜测有用**。
**禁止把问题答成"我读过没有"** —— 那只是回执；**回执是机器账，答案是报告**。

## 5. 特有的坑（只写年报才有的）

这一节列**只有这类材料才会踩的坑**——踩了不会报错，但结论会错。按下面的顺序看：**前一半是「读错」**（把 A 当成 B、把旧数当新数），**后一半是「算错」**（口径混用、净额化、时间错配）。读错比算错更难发现，因为它不影响数字的算术正确性。

1. **内控套话 ≠ 内控缺陷**：`material weakness` 这类词会出现在**审计"程序描述"段**（"评估是否存在重大缺陷的风险"）
   ⇒ 判红灯**看段落归属**（审计师报告的 CAM 段 / ICFR 意见段才是真），**不是看有没有出现这个词**。
2. **`RPO` / 期后事项可能根本不存在** ⇒ 写"该公司无此披露"，**不是缺口**，也别硬找（见 §3.3）。
3. **`Item 7` 关键会计估计 与 附注会重复**：法定要求"**补充、不得重复**"附注 ⇒ 两处**口径不同**（前者讲不确定性，后者讲政策）
   ⇒ **两处都要读，且必须标出读的是哪一处**。
4. **`Item 10–14` 常"并入委托书"** ⇒ 别写"无治理信息"。
5. **`Item 6` 已废止** ⇒ 别按旧模板找"选定财务数据"。
6. **附注家数随公司变** ⇒ **先数编号**，缺哪条写"未设此附注"，别按"应该有"报缺口。
7. **`Item 15` 的展品索引是"重大合同"的唯一线索** ⇒ 不看索引，后面所有契约类事实都找不到。

## 6. 红灯（见到就"喊人"上报）

这一节列**见到就必须停下来喊人**的信号。判断标准不是「数字大不大」，而是**「我能不能独立复算」**：复算不了的、两处对不上的、只有结论没有依据的，都要上报。上报时写清三件事——**在哪一段、多少、和什么比**；判断留给主控，你只负责把它摆出来。

| 红灯 | 判据（**看段落归属，不看关键词**） |
|---|---|
| **审计师变更 / 财报重述** | `Item 9`（及对应的事件类披露）⇒ **一票上报** |
| **ICFR 重大缺陷** | `Item 9A` 的 ICFR 结论 / 审计师的**内控意见段**（不是"程序描述"段） |
| **关键审计事项（CAM）** | 审计师报告里**明确列出**的 CAM 条 ⇒ **逐条照抄它在说什么** |
| **估计变更动了利润** | `Item 7` 关键会计估计 + 政策附注：寿命 / 残值 / 减值假设变了 ⇒ 写清**方向与量级** |
| **利润没变成现金** | 现金流量表 vs 利润表 ⇒ 应计方向异常 |
| **"一次性"常态化** | 连续多期同类费用反复出现 |
| **`Item 1C` 网络安全事件** | 有重大事件，而**模型没有对应格** ⇒ **报缺格** |
| **`Item 9B` 的 `Rule 10b5-1` 交易安排** | 高管交易计划新设/终止 ⇒ 可能**模型没有对应格** |

红灯**不是结论**，是**上报信号**：写清"**在哪一段 / 哪一附注 / 多少 / 与上期比变没变**"，判断留给主控。

## 7. 跨类照应（只写"口径差异提醒"，**不引用别的册**）

| 提醒 | 内容 |
|---|---|
| **年度口径 ≠ 季度口径** | 年报是**年度**；拿到季报时别把年度数字当单季，也别把"年初至今"当单季 |
| **年报的"关键会计估计"是唯一法定讲不确定性的地方** | 业绩发布件里通常只有"桥"，**没有估计的敏感性** ⇒ 不要指望别处补 |
| **"并入委托书"不是缺口** | 治理与薪酬若被并入 ⇒ 记"指针"，**不要**当成"年报没有" |
| **年报的展品索引 ≠ 展品本身** | 索引告诉你"有哪份合同"，**合同正文可能不在手** ⇒ 写"附件未在手" |
| **同业口径不可直接借** | 别家公司同样的 Item 名字，口径（分部定义、DAP 定义、寿命分档）都可能不同 ⇒ **只用本件自己的口径** |
