> 本件是 `system/env/meta/prompts/01-监管一手披露.md` 的**分册**：主件说**这是哪一类**，本件说**怎么读、必须过哪些项、问什么、有哪些坑、见到什么要上报**。
> **边界**（本册可能被单独交付，故自带）：**可读＝仓库根以下全部（只读）**；**可写＝仅 `output/<标的>/<材料 id>/`**；其余禁写（`README §3.1.1`）。
> **本册自包含**：跨类**只写一句"口径差异提醒"**，不引用别的册。
> **落点 = `system/env/meta/valuation-model.md` 上的格**（问句的"填哪一格"列就是它）；篮子只是存放答案的地方。档位口径（**Ⅰ 可逐行复核 / Ⅱ 二手 / Ⅲ 未核**）见该文件。
> 报告**给人看**：认知增量先行、说人话、**不出现段号与回执计数**（那些只落 `覆盖回执.csv`）。输出表达六条纪律见 `RUN-PARALLEL §2.4`；本册特有：单季与累计两个口径并列写，禁混。
> **输出格式 = 本册模板** `corpus/templates/01-10-Q.md`：抄一份到 `output/<标的>/<材料 id>/material.md` 再填；**采不到的栏目整节删掉，不呈现空项**（模板由 `system/scripts/env/gen_templates.py` 从本册生成，勿手改模板）。

## 0. 它是什么

**认它的痕迹**：`DocumentType=10-Q`，`Focus=Q1/Q2/Q3`，正文含 `Part I`（财务信息）与 `Part II`（其他信息）。

**这些别问它**：

| 别问 | 为什么问了也没用 |
|---|---|
| `10-K` 的问句 | 季报**没有审计意见、没有 `CAM`、没有 ICFR 意见、没有完整附注全套**（附注是**增量**，见 §3.2） |
| `8-K` 的"指引三要素" | 季报**不含**业绩发布件那种"区间 ＋ 基数 ＋ 期间"的正式指引 |
| `委托书 / 招股书 / 13D·G / Form 4` 的问句 | 那些内容季报里没有 |

**最要命的一个坑（口径）**：**把"年初至今"当成"本季"**（会把所有同比都算错）。

## 1. 怎么读（与 10-K 同属"长表"，但**多一条双口径纪律**）

**读法的依据（不是自己定的规矩）**：

- **每一段都要有交代**。读了、有理由的略读、或者对本文不适用，都写明。不许只记"必过项"。（依据：`撰写规范 §1.9`；守卫 `system/scripts/checks/material_spans_guard.py`）
- **抄下来的必须有数字**。量名、数值、期间口径（**本季还是年初至今**，必须写清）。实在没有数可写，就按"装不进篮子"写理由。（依据：`撰写规范 §1.8`）
- **数字分级 ＋ 两条数据纪律**。Ⅰ 可逐行复核，Ⅱ 二手带链接，Ⅲ 未核。同一个数字要有两个以上独立来源，偏差超过 2% 就要报警。自定义口径必须建定义卡。（依据：`撰写规范 §7.5`）
- **什么值得报 ＝ 定量 ＋ 定性**。定量只是起点。掩盖趋势变化、掩盖未达预期、亏损转盈、涉及重要分部、影响监管或契约合规——这些定性因素可以让金额小也照样重大。**季报这一层同样要评，不能只在年末评**。（依据：SEC `SAB 99`）

所以：`Part / Item` 和附注只是**去哪儿找**（定位）。落库的单位是**段**——每段有决定，段的并集等于全文。

### 1.1 读的单元 ＝ **三块，可数**

| 块 | 单元 | 数量 | 回执要求 |
|---|---|---|---|
| **`Item` 块** | `Part I` 的 `Item 1 / 2 / 3 / 4` ＋ `Part II` 的 `Item 1 / 1A / 2 / 5 / 6` | **9** | 每单元一条回执 **＋ 一句人话** |
| **附注块** | 该件的全部附注（**先数编号**；通常**少于**年报，因为只更新变化） | 按件数 | 同上 |
| **报表块** | 简式资产负债表 / 收益表 / 综合收益表 / 现金流量表 | **4** | 同上；**每张表都要标是"单季"还是"年初至今"** |

### 1.2 三层读法

| 层 | 用在哪 | 怎么读 |
|---|---|---|
| **骨架层** | 全部单元（§1.1） | 10-Q 只有单季与年初至今两列：两列都抄，标明各自期间起止。成本取利润表的 cost of revenue，不要用「总成本费用」；自己相减得出的数要标「计算值」。 |
| **自由段层** | `Item 2` MD&A 的归因段 · `Item 1A` 风险更新 · 附注里的"承诺与或有" | 10-Q 通常不给量价拆分，只给同比百分比。有拆分就记；没有就写「本期未披露量价拆分」，只留同比，不要拿年报口径顶替。 |
| **升级层** | 命中**信号词**：会计变更 · 审阅 · ICFR 变化 · 追溯调整 · 非经常性调整 · 流动性缺口 · 诉讼更新 | 对照上年 10-K 的 significant accounting policies：只记本期新增或修订的那一项（新准则采用、估计变更），抄生效日与影响金额。没有变更就写「无变化」。 |

### 1.3 双口径纪律（季报独有的硬要求）

| 报表 | 法定期间要求（别自己猜） |
|---|---|
| **资产负债表** | 最近财季末 ＋ **上一财年末**（**不要求**上年同季末） |
| **收益表** | 最近财季 ＋ **自上年末至最近财季末（年初至今）** ＋ **上一财年相应期间** ⇒ **单季与累计两套并列** |
| **现金流量表** | **只有"自上年末至最近财季末"＋上年同期** ⇒ **本表没有单季口径，别去拆单季** |

所以：凡引用收益表数字，**必须写清是"本季"还是"年初至今"**；凡引用现金流数字，**天然是累计口径**。

### 1.4 什么时候可以停

**§1.1 的单元全部有回执** ＋ §4 问句表**每条有答案或具名缺口** ＋ **双口径都标清了**。
**不许截断 / 抽样**（季报常超长）；唯一可略的是**样板与程序条款**，而且**必须写理由**。

## 2. 它结构上必然带着什么

| 必然带着 | 别处拿不到的是什么 |
|---|---|
| ① **未经审计的简式三表 ＋ 增量附注**，**单季与累计两个口径** | **当季**的一手数字（比年报新、比业绩发布件更"有账"） |
| ② **`Item 2` MD&A**：与上年同期的**期间对比** ＋ **流动性（短期、长期分开）** ＋ **关键会计估计** | **当季变化的官方解释**与**估计的不确定性**（法定要求） |
| ③ **会计政策的"增量声明"** | **本期唯一被改动的政策**（法定写法是"除……外无重大变化"，那句"except for"就是要点） |
| ④ **`Item 4` 内控**：披露控制结论 ＋ **ICFR 有无变化** | 内控**变化的当期信号**（年报给的是年度结论） |
| ⑤ **`Part II` 的诉讼更新与风险更新** | **相比年报"新增 / 强化"的部分**（法定只在有实质变化时更新） |
| ⑥ **`Part II Item 2` 回购与未注册股权出售明细**、`Item 5` 的 **`Rule 10b5-1` 安排** | 资本配置与内部人安排的**当期**事实 |

**法定性质要记住**：季报是**"年报的增量"** —— 规则**推定读者已经读过上一财年的经审计财报**（`Reg S-X 10-01(a)(5)`）。
所以**季报单独看并不完整**：政策原文、账户明细、多数长期承诺的**完整表述在年报里**。

## 3. 必须过的项（穷举）

### 3.1 `Part I` / `Part II` 的条目

| 位置 | 去哪儿看 | 拿到什么算过 | 常见坑 |
|---|---|---|---|
| **`Part I Item 1`** 财报 | **简式**三表 ＋ **增量附注** | ① **单季**与**累计**两个口径；② 附注**编号逐个**；③ 有没有**审阅**声明与**审阅报告** | 拿年初至今当本季；把"附注少"当缺口（见 §3.2） |
| **`Part I Item 2`** MD&A | 期间对比段 ＋ 流动性段 ＋ 关键会计估计 | ① **量价 / 数量 / 新产品**分解；② **流动性**（短期 12 个月内 vs 长期分开、义务类型与时间区间）；③ **资本资源**；④ **关键会计估计**的不确定性与敏感性 | 只读"亮点"，不抄归因数字；漏关键会计估计段 |
| **`Part I Item 3`** 市场风险 | —— | 利率 / 汇率**敞口的实质变化** | 空着就跳过；它只在**有实质变化**时才写 |
| **`Part I Item 4`** 内控 | —— | ① 披露控制与程序的**结论**；② **ICFR 有无变化** | 与年报的 ICFR **结论**混同（季报问的是"**变化**"） |
| **`Part II Item 1`** 诉讼 | —— | **新增 / 进展**的案件 | 只写"无重大变化"就完事 |
| **`Part II Item 1A`** 风险 | —— | **有实质变化**才更新 ⇒ 回执"未更新"**是合法答案** | 找不到就报"缺口" |
| **`Part II Item 2`** 未注册股权出售与回购 | —— | 发行 / 回购明细（含**为 0**） | 与现金流量表的回购行对不上时不点出 |
| **`Part II Item 5`** 其他信息 | —— | 含 **`Rule 10b5-1` 交易安排**（与内部人申报呼应） | 漏 10b5-1（影响内部人判读） |
| **`Part II Item 6`** 附件 | —— | 附件清单 | 跳过不写 |

### 3.2 附注：哪些"没写"是**法定允许**的（季报最容易误报缺口的地方）

**官方规则**：中期信息须充分披露以**不致误导**；但**可以推定使用者已读过上一财年的经审计财报**。
所以下列与年报实质重复的内容，允许省略：
- 重要会计政策与实务的说明；
- 自上年末以来金额或构成无重大变化的账户明细；
- 明细披露要求。
另外三组**允许合并"细项"**的门槛（法定）：

| 报表 | 允许合并的门槛 |
|---|---|
| 资产负债表项 | **低于总资产 10%** 且自上年末变动 **不超过 25%** |
| 收益表项 | **低于最近三年平均净利 15%**（亏年不计入）且同比变动 **不超过 20%** |
| 现金流量表项 | 投资 / 筹资活动变动 **未超过最近三年经营现金流均值的 10%** |

**所以判据写死为三条**：
1. 某附注 / 某细项**没写** ⇒ **先判它是不是"法定允许省略"**（前提：**与年报一致或无重大变化**）⇒ 回执写"**法定允许省略**"；
2. **若本期发生了重大变化却没写** ⇒ 那才是**问题**（要报，并点名与年报的哪一处不一致）；
3. **不许**把上述两种情况混成一句"披露未含"—— **两者性质不同**。

**必查的"增量声明"**（季报里最值钱的一句）：会计政策段里**必须**写清"相比年报有无变化" ⇒
**盯住"除〔某项〕外无重大变化"里的那一项**，那就是本期**唯一被改动的政策**。
若发生**会计变更**：**变更后的第一份 10-Q 须附审计师函**（说明是不是更可取的替代原则；**响应新准则的变更不附**）。
未审计的中期报表须声明**"已反映管理层认为公允列报所必需的全部调整"**；若全部为**正常经常性**要说明；**非正常经常性的调整须详述性质与金额**。
**重大追溯性前期调整**须披露对**净利（总额与每股）与留存收益**的影响。

### 3.3 条件项（季报不一定有，但必须有回执）

| 条件项 | 回执怎么写 |
|---|---|
| **审阅报告** | **只有声明"已由独立会计师审阅"时才附** ⇒ 未见声明 ⇒ 写"**本期未附审阅报告**"（**不是缺口**） |
| `Part I Item 3` 市场风险 | "**本期未更新**"（只在有实质变化时写） |
| `Part II Item 1A` 风险 | "**本期未更新**"（合法答案） |
| 会计变更的审计师函 | "**本期无会计变更**" 或 "**变更系响应新准则，依法不附函**" |

**它不许被问的四样**：审计意见、`CAM`、ICFR 意见、正式指引区间（见 §0）。

## 5. 特有的坑（只写季报才有的）

这一节列**只有这类材料才会踩的坑**——踩了不会报错，但结论会错。按下面的顺序看：**前一半是「读错」**（把 A 当成 B、把旧数当新数），**后一半是「算错」**（口径混用、净额化、时间错配）。读错比算错更难发现，因为它不影响数字的算术正确性。

1. **年初至今当本季**：季报收益表**两套口径并列** ⇒ 引错一次，**所有同比全错**。
2. **把"附注少 / 细项少"当缺口**：法定**允许**省略与合并（§3.2）⇒ **先判是不是许可的省略**，再谈缺口。
3. **现金流量表没有单季口径**（法定只有累计 ＋ 上年同期）⇒ 别去"拆单季"，也别把累计当单季。
4. **漏掉会计政策段的"except for"**：那是**本期唯一被改动的政策**，漏了等于漏了本期最重要的会计信号。
5. **把季报当"已审计"**：季报财报**未经审计**；**审阅报告只在声明已审阅时才附**（未见声明 ⇒ 无报告，不是缺口）。
6. **`Item 3` / `Item 1A` 的"没写"是正常的**：法定**只在有实质变化时**才更新 ⇒ "未更新"是答案，不是缺口。
7. **`Item 4` 问的是"变化"**，不是年度结论 ⇒ 别把年报的"内控有效"抄过来当季报的答案。
8. **季报单看是"半张账"**：完整政策与长期明细在年报 ⇒ 引用时要标"**以年报为准 / 需与年报配对**"。

## 6. 红灯：见到必须上报

这一节列**见到就必须停下来喊人**的信号。判断标准不是「数字大不大」，而是**「我能不能独立复算」**：复算不了的、两处对不上的、只有结论没有依据的，都要上报。上报时写清三件事——**在哪一段、多少、和什么比**；判断留给主控，你只负责把它摆出来。

| 红灯 | 判据 |
|---|---|
| **会计变更** | 会计政策段出现变更；且要看**第一份 10-Q 是否附了审计师函**（响应新准则可不附） |
| **ICFR 变化** | `Part I Item 4` 明确有变化 |
| **重大追溯性前期调整** | 附注声明 ⇒ 须带**对净利与留存收益的影响** |
| **非正常经常性调整** | 附注的调整声明为"**非**全部正常经常性" ⇒ 须有性质与金额 |
| **流动性缺口** | `Item 2` 流动性段出现**重大资金缺口**及补救措施 |
| **重述 / 财报不可依赖** | 任何形式的追溯更正声明 |
| **估计变更动了利润** | 关键会计估计段的假设变化 ⇒ 写清方向与量级 |
| **契约 / 承诺类事实，而模型没有对应格** | 附注里的期限类事实 ⇒ **报缺格** |

红灯**不是结论**，是**上报信号**：写清"**在哪一段 / 哪一附注 / 多少 / 与年报比变没变**"。

## 7. 跨类照应（只写"口径差异提醒"，**不引用别的册**）
这一节只写**与其他类的口径差异提醒**：一句带过，不展开别类的判读。季报最容易被拖进「业绩会口径」（那是 02）或「一次性事项」（那要看 8-K），遇到时只写一句「此项口径属 X 类」，不在这里分析。


| 提醒 | 内容 |
|---|---|
| **季报是"年报的增量"** | 法定**推定读者已读年报** ⇒ **季报单独看不完整**；政策原文、账户明细、长期承诺的完整表述在**年报**里 |
| **年度口径 ≠ 季度口径** | 同一科目在年报是年度数、在季报里是季度 / 累计数 ⇒ **别直接相减**，也别拿它当年度数 |
| **"无重大变化"是相对年报说的** | 回执要写清**是跟哪一期比**（上一年末 / 上年同期），否则"无变化"没有意义 |
| **审计层级不同** | 年报有审计意见与 ICFR 意见；季报**未经审计**，且**审阅报告只在声明时才有** ⇒ 引用措辞不得同级 |
| **内控的两种问法** | 季报问"**变化**"；年报问"**结论**"（含缺陷）⇒ 两个问题不可互替 |
| **指引不在季报里** | 正式"区间 ＋ 基数 ＋ 期间"的指引在业绩发布件里 ⇒ 别在季报里找它 |
