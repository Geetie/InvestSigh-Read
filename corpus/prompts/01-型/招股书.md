## 0. 它是什么

**认它的痕迹**：`DocumentType=S-1 / S-3 / S-11`（含生效后的 `424B` 系列招股说明书）。

| 别问 | 为什么问了也没用 |
|---|---|
| `10-K` 的完整附注问句 | 招股书的财务信息是**申报当期的**（含**备考**），不是年度附注全套 |
| `8-K` 的指引问句 | 招股书**不含**业绩指引 |
| `委托书` 的薪酬全套 | 招股书只在涉及股权激励计划发行时**部分**涉及 |

**它和年报的关系有两层**：
- 它的风险因素，要与年报的风险因素比增量；
- `S-3`（简易注册）常并入已提交的定期报告——看到"并入"不是缺口。

## 1. 怎么读

**读法的依据（不是自己定的规矩）**：

- **每一段都要有交代**。读了、有理由的略读、或者对本文不适用，都写明。不许只记"必过项"。（依据：`撰写规范 §1.9`；守卫 `system/scripts/checks/material_spans_guard.py`）
- **抄下来的必须有数字**。量名、数值、期间、口径。实在没有数可写，就写"放不进任何篮子"的理由。（依据：`撰写规范 §1.8`）
- **数字分级 ＋ 两条数据纪律**。Ⅰ 可逐行复核，Ⅱ 二手带链接，Ⅲ 未核。同一个数字要有两个以上独立来源，偏差超过 2% 就要报警。备考口径、调整后口径必须建定义卡。（依据：`撰写规范 §7.5`）
- **值得报 ＝ 定量 ＋ 定性**。摊薄、募资用途、持续经营这类措辞，本身就是定性重大项。（依据：SEC `SAB 99`）

所以：招股书章节只是**去哪儿找**（定位）。落库的单位是**段**——每段有决定，段的并集等于全文。

**读法的特点**：

| 块 | 长相 | 怎么读 |
|---|---|---|
| **风险因素** | **自由作文**（无骨架） | **全读**；与年报的风险段**逐条比增量**（新增 / 强化 / 删除） |
| **募资用途与发行安排** | 段落 + 表 | 全读；用途要**具体到比例或金额**；"一般公司用途"要记缺口 |
| **摊薄表** | **算式**（有形账面净值） | **必须复算**：分配前 / 后每股有形账面净值 · 增加额 · 即时摊薄额 |
| **财务与备考** | 表 + 简式附注 | 全读；**备考（`pro forma`）与历史必须分开写** |
| 升级层 | 命中信号词：**持续经营 · 重大摊薄 · 重大出售股东 · 备考调整异常 · 承销折价异常 · 锁定条款松** | 逐句读 + 出红灯（§6） |

**停止条件**：**风险段逐条比过增量** + **摊薄表复算过** + §4 问句表**每条有答案或具名缺口**；不许截断（可**有理由的略读**的是：法律事项样板、承销协议样板条款）。

## 3. 必过项（穷举）

### 3.1 风险因素（`Reg S-K 105` / 前置条款）

| 项 | 拿到什么算过 | 常见坑 |
|---|---|---|
| 风险**分标题**结构 | 按标题列全，识别**通用风险**与**本公司特有风险** | 只读前几条就下结论 |
| **与年报的增量** | 逐条：**新增 / 强化 / 删除 / 措辞升级** | 不做差集 ⇒ 等于没读（这是本块的核心价值） |
| **带数字或期限的风险句** | 逐条摘出（金额 / 期限 / 触发条件） | 漏"带数字"的那几条 |
| **持续经营 / 流动性类**措辞 | 是否出现"持续经营重大疑虑"类表述 | 当套话略过 |

### 3.2 募资用途与发行（`Reg S-K 504 / 505 / 508 / 509 / 511`）

| 项 | 拿到什么算过 | 常见坑 |
|---|---|---|
| **用途** | 具体用途 **+ 比例或金额**；含营运资金占比 | 只写"一般公司用途"就完事 ⇒ 这正是要记的缺口 |
| 发行价确定 | 依据（市场价 / 谈判 / 公式） | 忽略 |
| 分配计划与承销 | 承销方式（包销 / 代销）· **折价与佣金** · 费用总额 | 漏承销折价（真实成本） |

### 3.3 摊薄（`Reg S-K 506`）—— **有法定触发条件与三项披露**

**触发条件（两类之一）**：
① 公开发行价与内部人（高管 / 董事 / 发起人 / 关联人）**过去五年内**取得或有权取得的普通股**实际现金成本**之间存在**重大悬殊**，且申报前**不受**报告义务约束；
② 最近**三个财年均亏损**，且存在**重大摊薄**。

**必披露三项**（**一律要复算**，禁口算）：
1. **分配前**与**分配后**的**每股有形账面净值**；
2. 因**本次购买者现金支付**导致的每股有形账面净值**增加额**；
3. 购买者承担的**即时摊薄金额**（相对公开发行价）。

**注意（别把惯例当法定）**：条文要求的是**摊薄金额**；**"占发行价的百分比"是实务常见做法，不是条文强制列示项** ⇒ 报告里可以给百分比，但**不要写成"法定要求"**。

### 3.4 出售股东与其他（`Reg S-K 507 / 503 / 502`）

| 项 | 拿到什么算过 | 常见坑 |
|---|---|---|
| **出售股东** | 谁在卖 · 卖多少 · 卖后还剩多少 | 只看发行规模，不看**老股东套现比例** |
| 摘要（`503`） | 与正文一致 | 与正文冲突不点出 |
| 封面与内封（`501/502`） | 发行量 · 价格区间 · 承销商 | 忽略 |

### 3.5 财务与备考（`Reg S-X`）

| 项 | 拿到什么算过 | 常见坑 |
|---|---|---|
| 申报当期财报 | 期间与口径（**是否为最新期**） | 拿旧期数据 |
| **备考信息** | 调整项逐条 + 调整后数字 | 把备考当历史；不看调整项 |
| 会计政策 | 与年报是否一致 | 忽略 |

### 3.6 条件项（招股书不一定有，但必须有回执）

| 条件项 | 回执怎么写 |
|---|---|
| **锁定（lock-up）** | 是**承销协议的合同条款**，不是规则强制 ⇒ 有则记期限与范围；无则写"**未披露锁定安排**" |
| **并入（`S-3` 常见的 by reference）** | "**并入已提交的定期报告**"——**不是缺口** |
| 外国发行人表格 | 对本模型对象**通常不适用** ⇒ 回执"不适用" |

## 4. 问句表

| # | 问什么 | 读法 | 拿到什么算过 | 答不上来怎么写 | 频次 | 落哪个篮子 |
|---|---|---|---|---|---|---|
| Q1 | **这次发行摊薄多少**（分配前后每股有形账面净值、增加额、即时摊薄额）？ | 三件取自摊薄表（Item 506）：发行价、发行前与发行后每股有形账面净值，摊薄额＝发行价减发行后值。发行后股数含优先股按比例转普通，不含未行权期权与认股权证，漏了摊薄被低估。 | **三项都要，且复算过** | "**未按此编制摊薄表**"（如不触发法定情形） | 事件 | M-8 资本配置（`股权激励与稀释` · `回购与股本变动`） |
| Q2 | **风险因素比年报新增了哪些**？有没有"持续经营"类措辞？ | 按 Item 105 的骨架读：风险因素超过 15 页必须在前部给不超过两页的摘要，通用风险一律归到末尾 General Risk Factors 标题下。先挑摘要里点名且带数字的（客户集中、单一供应商），再与最近年报对：哪条新增、哪条加了量化、哪条删了。 | 逐条差集（新增 / 强化 / 删除） | "**无法对照**（年报不在手）" ⇒ 记缺口 | 事件 | M-10 或有负债 · 守门（`风险因素与集中度`） |
| Q3 | **募资用途**具体是什么？各占多少？ | 募资用途（Item 504）按优先级列各项金额与占比，用净额不用毛额；先分清新股与老股。用于偿还近一年内新增债务的，要说明利率、期限与原用途；写「一般公司用途」的，直接说这笔钱没有指向。 | 用途 + **比例或金额** | "**只写'一般公司用途'**"——**这本身是结论** | 事件 | M-7 资本开支 · M-8 资本配置（`债务与融资结构`） |
| Q4 | **谁在卖**（出售股东）？卖后剩多少？ | 出售股东表（Item 507）逐行：股东名、发行前持股、本次注册卖出、卖后持股与占比。转售注册公司一分钱拿不到，这句写在第一行；卖后清零的单独标出。占比分母是发行后总股本。 | 名单 + 数量 + 剩余 | "**无出售股东**"——是答案 | 事件 | M-8 资本配置（`股东事项与分红`） |
| Q5 | **发行成本**多少（承销折价 / 佣金 / 费用）？ | 封面表加承销章节（Item 508）：每股承销价差、总佣金、超额配售权比例、公司应付发行费用。净募资＝毛募资减佣金减费用，自己算的标「计算值」；超额配售权是选择权，不算已募金额。 | 折价与费用总额 | "**未给折价**" | 事件 | M-8 资本配置（`费用与人力结构`） |
| Q6 | **备考口径**下财务状况变成什么样？调整项是什么？ | 找资本化表的 pro forma 与 pro forma as adjusted 两列：前者只调优先股转普通等已确定事项，后者再加本次净募资。备考不含「若多募到钱」的情形，把管理层愿景写进备考是最常见的错。 | 调整项 + 调整后 + 期间 | "**无备考信息**" | 事件 | M-7 资本开支（`资产与资本开支`） |
| Q7 | **锁定**安排是什么（期限 / 范围）？ | 锁定期不在 SEC 规则里，在承销协议的 lock-up 条款与承销章节：期限（常见 180 天）、覆盖谁（董监高、主要股东、公司自身）、有无价格触发的提前解禁、有无例外（如 10b5-1 计划内卖出）。 | 期限 + 覆盖人员 | "**未披露锁定**" | 事件 | M-8 资本配置（`股东事项与分红`） |

**它不许被问的三样**：年度附注全套、业绩指引、薪酬全套（见 §0）。
**答不上 ≠ 跳过**：写清"**为什么答不上**"（未触发法定情形 / 未披露 / 招股书里没有这一项）。

## 5. 特有的坑（只写招股书才有的）

这一节列**只有这类材料才会踩的坑**——踩了不会报错，但结论会错。按下面的顺序看：**前一半是「读错」**（把 A 当成 B、把旧数当新数），**后一半是「算错」**（口径混用、净额化、时间错配）。读错比算错更难发现，因为它不影响数字的算术正确性。

1. **摊薄的百分比不是法定列示项**：条文要的是**金额** ⇒ 别把实务惯例写成"法定要求"；但**三项披露缺一不可**（分配前 / 后净值 · 增加额 · 即时摊薄额）。
2. **摊薄有法定触发条件**：不是每份招股书都要编摊薄表 ⇒ **别因为"没看到摊薄表"就报缺口**，先判是否触发。
3. **备考 ≠ 历史**：备考数字是"假设交易已完成"的样子 ⇒ 两套必须分开写，**不得混用**。
4. **风险因素的价值在"增量"**：不与年报做差集，本块基本白读。
5. **锁定是合同条款**，不是规则强制 ⇒ 与"法定披露"不是一个层级。
6. **`S-3` 常"并入"定期报告** ⇒ 看到并入**不是缺口**；但**要看它并入了哪一份**（否则读的是旧期数据）。
7. **"一般公司用途"是缺口信号**，不是"没内容"。

## 6. 红灯：见到必须上报

这一节列**见到就必须停下来喊人**的信号。判断标准不是「数字大不大」，而是**「我能不能独立复算」**：复算不了的、两处对不上的、只有结论没有依据的，都要上报。上报时写清三件事——**在哪一段、多少、和什么比**；判断留给主控，你只负责把它摆出来。

| 红灯 | 判据 |
|---|---|
| **重大摊薄** | 摊薄表结果显示购买者承担即时摊薄显著 |
| **持续经营类措辞** | 风险段或财务附注出现持续经营重大疑虑 |
| **大量出售股东** | 出售股东段中老股东占比高（套现而非融资） |
| **募资用途模糊** | 只写"一般公司用途"且无比例 |
| **备考调整异常** | 备考调整项金额巨大或口径不明 |
| **承销条款异常** | 折价 / 佣金 / 费用显著高于常规，或含非常规条款 |
| **锁定缺失或过短** | 无锁定 / 短期锁定 + 大量老股 ⇒ 供给冲击 |
| **风险增量出现"新类型"** | 与年报比出现全新风险类别（如监管禁令、供应链断供） |

红灯**不是结论**，是**上报信号**：写清"**哪一段 / 哪个表 / 多少 / 与什么比**"。

## 7. 跨类照应（只写"口径差异提醒"，**不引用别的册**）

| 提醒 | 内容 |
|---|---|
| **风险因素的两种读法** | 年报是"**当前风险全集**"；招股书是"**发行时的风险 ＋ 增量**" ⇒ **必须配对比较**才知道什么变了 |
| **摊薄 vs 回购授权** | 招股书给**一次发行的稀释**；定期报告给**授权额度与已用** ⇒ 两者**不能互相替代** |
| **备考 vs 历史** | 招股书会同时出现两套 ⇒ 引用**必须标清哪一套** |
| **并入 ≠ 缺失** | 简易注册常并入定期报告 ⇒ 追问"并入了哪一份、是哪一期" |
| **财务期间** | 招股书的财务信息**截至申报当期**（可能是旧期） ⇒ 用之前先确认期间 |
