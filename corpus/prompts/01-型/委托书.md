## 0. 它是什么

**认它的痕迹**：`DocumentType=DEF 14A`（或 `PRE 14A`），正文是**股东大会议案 ＋ 治理与薪酬披露**。

**这些别问它**：

| 别问 | 为什么问了也没用 |
|---|---|
| `10-K` 的报表与附注问句 | 它的财务信息**极少**（通常只有若干精选数字或交叉引用） ⇒ 完整财报**不在委托书里** |
| `8-K` 的"指引三要素" | 委托书**不含**业绩指引 |
| `招股书` 的问句 | 它**不涉及募资与摊薄表**（除非恰好含股权激励计划的新股登记，那也要按委托书的激励池口径读） |

**它和年报是一对**：年报的 `Item 10–14`（治理、薪酬、持股、关联、审计费）**法定允许"并入委托书"**，
所以**年报里那一段常常只是空壳指针** ⇒ **必须把两份配对读**，而且**判别"并入"不算缺口**。

## 1. 怎么读

**读法的依据（不是自己定的规矩）**：

- **每一段都要有交代**。读了、有理由的略读、或者对本文不适用，都写明。不许只记"必过项"。（依据：`撰写规范 §1.9`；守卫 `system/scripts/checks/material_spans_guard.py`）
- **抄下来的必须有数字**。量名、数值、期间、口径。实在没有数可写，就写"放不进任何篮子"的理由。（依据：`撰写规范 §1.8`）
- **数字分级 ＋ 两条数据纪律**。Ⅰ 可逐行复核，Ⅱ 二手带链接，Ⅲ 未核。同一个数字要有两个以上独立来源，偏差超过 2% 就要报警。自定义口径（比如"调整后薪酬""核心经营利润"这类目标）必须建定义卡。（依据：`撰写规范 §7.5`）
- **值得报 ＝ 定量 ＋ 定性**。定量只是起点。涉及重要分部、影响契约或监管合规、增加管理层薪酬——这些定性因素可以让金额小也照样重大。（依据：SEC `SAB 99`）

所以：议案和主题块只是**去哪儿找**（定位）。落库的单位是**段**——每段有决定，段的并集等于全文。

**读法的特点（与长表那几类不同）**：

| 层 | 用在哪 | 怎么读 |
|---|---|---|
| **纲：议案** | 股东大会议案清单 | **先列全议案**（含薪酬建议性投票与其频率），**逐案给一句人话**（"投什么、公司要什么、有无异议"） |
| **目：主题块** | ① 董事与高管 ② 薪酬 ③ 持股与稀释 ④ 关联交易 ⑤ 审计费 | **每块全读**；薪酬块的**叙述（`CD&A`）与表要配对读**（表是结果，叙述是规则） |
| **升级层** | 命中信号词：**薪酬追回 · 目标值调整 · 关联交易未经审批 · 独立性争议 · 审计费结构异常 · 十年内法律程序** | 该段**降为逐句读** + 出红灯（§6） |

**停止条件**：**议案逐条有回执** + **五块主题各自过完** + §4 问句表**每条有答案或具名缺口**；不许截断（可**有理由的略读**的是：会议流程与法定样板、公司章程条文）。

## 3. 必过项（穷举）

### 3.1 议案与治理

| 项 | 去哪儿看 | 拿到什么算过 | 常见坑 |
|---|---|---|---|
| 议案清单 | 通知与议案段 | 逐案：**投什么 · 董事会建议 · 有无异议股东** | 只看"通过"不看**反对比例** |
| 薪酬建议性投票 | 议案段 | 是**年度还是多年一次**（频率投票） | 当成**约束性**决议（其实**建议性**） |
| 董事与高管 | `Reg S-K 401` | 姓名 · 职位 · 任期 · **独立性判断** · 委员会 · **五年业绩历** · **十年内法律程序** | 只抄名单，漏**独立性依据**与**法律程序** |
| 治理事项 | `Reg S-K 407` | 董事独立性标准 · 各委员会构成 · **审计委员会财务专家** · **薪酬顾问与利益冲突** | 漏"顾问是谁、有无冲突" |
| 道德准则 | `Reg S-K 406` | 有无 · 本期**豁免** | 豁免才是信号 |
| 内部人交易安排 | `Reg S-K 408` | 政策与实务（含**对冲与质押**） | 漏**允许对冲/质押**这类松绑 |

### 3.2 薪酬（委托书最核心的一块）

| 项 | 拿到什么算过 | 常见坑 |
|---|---|---|
| `CD&A` 讨论 | ① 目标（挂什么指标）② 每个薪酬要素"为什么" ③ **是否参考最近一次 `say-on-pay` 结果** ④ **追回 / 调整政策** ⑤ **持股指引与对冲政策** ⑥ 是否**对标（benchmarking）**及对标组 | 只读表不读 `CD&A`（规则在叙述里） |
| 薪酬汇总表 | 近**三个财年**逐列：工资 / 奖金 / **股票奖励** / **期权奖励** / 非股权激励 / 养老金变动 / 其他 / **合计** | **这是"授予日公允价值"，不等于当年到手现金**（易误读成"发了多少钱"） |
| 授予表 · 年末未归属表 | 阈值 / 目标 / 最高三档 · 未归属股数与市值 | 只看目标档，不看**最高档缺口** |
| 离职与控制权变更 | 各触发情形下的**量化**金额（按"财年最后营业日"假设） | 当成"已发生"（其实是**假设**） |
| 董事薪酬 | 逐项（现金费 / 股票 / 期权 / 其他） | 与高管薪酬混读 |
| 缩表披露 | 小型报告公司 / 新兴成长公司有**简化档** | 按完整档去找 ⇒ 误报缺口 |

### 3.3 持股与稀释

| 项 | 拿到什么算过 | 常见坑 |
|---|---|---|
| 5% 以上实益所有人 | 名称 · 股数 · **比例 + 计算基数 + 日期** | 只抄比例不抄基数与日期 |
| 董事与高管持股 | 同上 + 合计 | 与"内部人申报"口径混用（**那属别的类**） |
| 股权激励计划信息 | **池余额 / 可用股数 / 已授未行权** | 漏池余额 ⇒ 稀释判断没依据 |

### 3.4 关联交易（有法定门槛，别自己猜）

**门槛 = 交易金额超过 `$120,000`**（小型报告公司取 `$120,000` 与**最近两个财年末总资产平均值 1%** 的**较小者**）；
**时间范围 = 上一财年年初以来（含拟议交易）**。
**必披露五要素**：
- 关联人姓名与关联依据；
- 其利益（含在交易对方中的职位 / 关系 / 所有权）；
- 交易金额（近似）；
- 关联人利益金额（不计盈亏）；
- 债务类另须本金、利息、利率、未偿余额。
**程序披露**：审查 / 批准 / 追认的**政策与程序**，并**点名"未被程序覆盖或程序未被遵守"的交易**。
**豁免**（别当缺口）：竞争性投标与法定费率 · 银行存托与过户代理类服务 · 按比例同等受益 · **间接利益 <10% 持股 / 有限合伙非普通合伙人** · 已按薪酬规则报告的雇佣薪酬（含**薪酬追回**情形）。

### 3.5 审计费（`Reg S-K Item 9` 体系）

| 项 | 拿到什么算过 | 常见坑 |
|---|---|---|
| 费用四类 | **审计费 / 审计相关费 / 税费 / 其他** 各自金额与说明 | 只抄总额，不拆四类 |
| 预批政策 | 审计委员会对**审计与非审计服务**的预批政策与程序 | 漏预批政策 |
| 非审计费占比 | **须算**（禁口算） | 占比异常高不点出 |

### 3.6 条件项（委托书不一定有，但必须有回执）

| 条件项 | 回执怎么写 |
|---|---|
| 小型报告公司 / 新兴成长公司的**缩表** | "**按缩表档披露**"（**不是缺口**） |
| 外国私人发行人 | "**按本国口径替代披露**"（本模型对象通常不适用，但别报缺口） |
| 薪酬**目标值未披露** | "**援引竞争损害豁免**"（法定允许）⇒ 但须看它是否**说明了达标难度** |

**它不许被问的三样**：三表与附注全套、业绩指引、募资摊薄（见 §0）。
**答不上 ≠ 跳过**：写清"**为什么答不上**"（援引豁免 / 未披露 / 委托书里没有这一项）。

## 5. 特有的坑（只写委托书才有的）

这一节列**只有这类材料才会踩的坑**——踩了不会报错，但结论会错。按下面的顺序看：**前一半是「读错」**（把 A 当成 B、把旧数当新数），**后一半是「算错」**（口径混用、净额化、时间错配）。读错比算错更难发现，因为它不影响数字的算术正确性。

1. **薪酬汇总表不是"到手现金"**：股票与期权按**授予日公允价值**计 ⇒ 与"实际实现"是两回事（要找行权与归属表）。
2. **`CD&A` 是规则，不是数字**：目标怎么定、指标挂什么、有无对标、有无追回政策——**全在叙述里**，只看表等于没读。
3. **目标值可以依法不披露**（竞争损害豁免）⇒ 先看是不是**法定允许**，再判缺口；但**达标难度说明**通常是必须给的。
4. **非 GAAP 的业绩目标不受 non-GAAP 规则约束**，但**必须说明该数字如何从经审计财报算出** ⇒ 拿不到这条说法要记缺口。
5. **持股口径 ≠ 内部人申报口径**：委托书给的是"**截至某日的实益持股**"，与逐笔交易不是一回事（后者属别的类）。
6. **`say-on-pay` 是建议性投票** ⇒ 不能当成"被否决即失效"，它的意义在**支持率与后续调整**。
7. **"并入"机制**：年报的治理与薪酬段若写"并入委托书"，**那不是缺失**；反之，只看委托书而不回年报配对，也会漏掉年报独有的事实。
8. **缩表档**（小型报告公司 / 新兴成长公司）⇒ 按完整档找会误报缺口。

## 6. 红灯：见到必须上报

这一节列**见到就必须停下来喊人**的信号。判断标准不是「数字大不大」，而是**「我能不能独立复算」**：复算不了的、两处对不上的、只有结论没有依据的，都要上报。上报时写清三件事——**在哪一段、多少、和什么比**；判断留给主控，你只负责把它摆出来。

| 红灯 | 判据 |
|---|---|
| **薪酬与业绩脱钩** | 业绩指标未达标而薪酬上升，或指标被**改口径/下调目标** |
| **`say-on-pay` 支持率显著偏低** | 议案结果 + 有无后续调整 |
| **追回（clawback）政策被触发** | 薪酬相关段与追回披露 |
| **关联交易未经审批程序** | `Item 404(b)` 点名"程序未覆盖或未遵守" |
| **非审计费占比异常** | 审计费四类拆分结果 |
| **董事独立性受损** | 治理段的独立性结论与依据冲突 |
| **十年内法律程序披露** | `Reg S-K 401(f)` 的任一事件 |
| **允许高管对冲 / 质押** | 持股指引与对冲政策段 |
| **激励池不足** | 池余额接近耗尽而拟新增授权 ⇒ 稀释压力 |

红灯**不是结论**，是**上报信号**：写清"**哪一段 / 哪个表 / 多少 / 与上期比变没变**"。

## 7. 跨类照应（只写"口径差异提醒"，**不引用别的册**）

| 提醒 | 内容 |
|---|---|
| **与年报是一对** | 年报的治理与薪酬段**常"并入"委托书** ⇒ 读年报那段发现是空壳时，**去找委托书**；反之亦然 |
| **持股的三种口径** | 委托书的"实益持股（截至某日）" · 财报附注的"股份支付" · 逐笔交易披露 —— **三者不能互相替代** |
| **薪酬 vs 股份支付费用** | 委托书给的是**授予安排**，财报附注是**会计费用**（摊销规则不同） ⇒ 要对账但别混用 |
| **年度节奏** | 委托书通常**一年一次**（年度股东大会） ⇒ 与季报的期间口径不同 |
| **"建议性"≠"约束性"** | `say-on-pay` 与部分议案是**建议性** ⇒ 措辞不得写成"公司必须……" |
