# `01` · **其他法定表格与红灯** —— 这一类怎么读

> 本件是 `system/env/meta/prompts/01-监管一手披露.md` 的**分册**，装两样东西：
> **① 不属于前面各类的法定表格**（`8-K` 的**非业绩**条目 · `20-F / 6-K` · 其他单点表格）；
> **② 本类的"红灯"总表**（把各类的上报信号收在一处，便于对照）。
> **边界**：**可读＝仓库根以下全部（只读）**；**可写＝仅 `output/<标的>/<材料 id>/`**；其余禁写（`README §3.1.1`）。
> **本册自包含**：跨类**只写"口径差异提醒"，不引用别的册**。
> **落点 = `system/env/meta/valuation-model.md` 上的格**；篮子只是存放答案的地方。档位口径（**Ⅰ 可逐行复核 / Ⅱ 二手 / Ⅲ 未核**）见 `system/reports/撰写规范.md §7.5`。
> 输出表达六条纪律见 `RUN-PARALLEL §2.4`；本册特有：外国发行人件（furnish 级）引用措辞必须降级。
> **最重要的一句**：**`Form 4` / `13D` / `13G` / `13F` 不属本类**（它们讲"谁在持股、谁在买卖"）⇒ **归 `04-资金与持仓`**；拿到就记"**归类纠正**"，**不套本类的问句**。
> **输出格式 = 本册模板** `corpus/templates/01-其他条目与红灯.md`：抄一份到 `output/<标的>/<材料 id>/material.md` 再填；**采不到的栏目整节删掉，不呈现空项**（模板由 `system/scripts/env/gen_templates.py` 从本册生成，勿手改模板）。

## 1. 怎么读

**读法的依据（不是自己定的规矩）**：

- **每一段都要有交代**。读了、有理由的略读、或者对本文不适用，都写明。不许只记"条目号"。（依据：`撰写规范 §1.9`；守卫 `system/scripts/checks/material_spans_guard.py`）
- **抄下来的必须有数字**。量名、数值、期间、口径。实在没有数可写，就写"放不进任何篮子"的理由。（依据：`撰写规范 §1.8`）
- **数字分级 ＋ 两条数据纪律**。Ⅰ 可逐行复核，Ⅱ 二手带链接，Ⅲ 未核。同一个数字要有两个以上独立来源，偏差超过 2% 就要报警。自定义口径必须建定义卡。（依据：`撰写规范 §7.5`）
- **值得报 ＝ 定量 ＋ 定性**。契约类的事实哪怕金额小，也可能重大——影响契约或监管合规，就是定性重大。（依据：SEC `SAB 99`）

所以：条目和段落只是**去哪儿找**（定位）。落库的单位是**段**——每段有决定，段的并集等于全文。

**读法的特点**：无骨架、件短，所以主体是"全读"。
正文样板（免责与程序条款）可有理由的略读。
命中 §6 信号词的那一段，逐句读。

**停止条件**：**本件条目逐条有回执** + **附件清单逐条** + §4 问句表**每条有答案或具名缺口**。

## 5. 特有的坑（只写这类单点件才有的）

这一节列**只有这类材料才会踩的坑**——踩了不会报错，但结论会错。按下面的顺序看：**前一半是「读错」**（把 A 当成 B、把旧数当新数），**后一半是「算错」**（口径混用、净额化、时间错配）。读错比算错更难发现，因为它不影响数字的算术正确性。

1. **`6-K` 是 `furnish` 不是 `filed`** ⇒ 引用措辞**低于"已提交"**；它**没有固定截止日**（母国披露时"及时"报）⇒ 别按"季度应该有一份"报缺口。
2. **`20-F` 与 `10-K` 不能混读**：条目体系与口径不同 ⇒ 按哪本读，取决于**发行人类型**。
3. **条目号 ≠ 重要性**：`8.01`（其他事件）常装**重要计划**；`1.04` 常年"不适用"⇒ **没有的也要回执"，但别为它花篇幅。
4. **契约 / 承诺 / 期限类事实最容易"挂不上格"** ⇒ 那是**缺格（模型结构可能要改）**，**不是噪声**。
5. **`7.01` 看起来"非正式"**，但常含**指引修正** ⇒ 别略过。
6. **邻近件不要硬塞进本类**（`Form 4` / `13D·G` 等）⇒ 记"归类纠正"即可，**别套本类问句**。

## 6. 红灯总表（**本类跨类的上报信号**，见到即"喊人"）

> 判据来源：**官方条目 / 官方规则**（下方每条注明）+ **`SAB 99` 的定性判据**（定量只是起点；掩盖趋势 / 掩盖未达预期 / 亏损转盈 / 涉及重要分部 / 影响监管或契约合规 / 增加管理层薪酬 等可使小额也重大）。

| 红灯 | 典型出处 | 判据要点 |
|---|---|---|
| **审计师变更 / 财报不可依赖（重述）** | `10-K Item 9` · `8-K 4.01 / 4.02` | 看**条目本身**，不是看是否出现"缺陷"字样 |
| **ICFR 重大缺陷** | `10-K Item 9A` · 审计师的**内控意见段** | 判据 = "存在合理可能性，重大错报不会被及时防止或发现" |
| **关键审计事项（`CAM`）** | 审计师报告明确列出的 `CAM` 段 | 逐条照抄它在说什么 |
| **重大减值** | `8-K 2.06` · 附注减值测试 | 资产类别 · 金额 · **假设** |
| **重大网络安全事件** | `8-K 1.05` · `10-K Item 1C` | 性质 · 范围 · 时间 · 或有影响 |
| **退出 / 处置成本** | `8-K 2.05` | 与重组费用行对账 |
| **估计变更动了利润** | `10-K Item 7` 关键会计估计 · 附注政策 | 寿命 / 残值 / 减值假设变了 ⇒ 方向与量级 |
| **"一次性"常年出现** | 业绩件的**非 GAAP 桥** | **法定判据：该项目两年内合理可能再现，或前两年曾出现类似项** |
| **利润没变成现金** | 现金流量表 vs 利润表 | 应计方向异常 · 现金转换 <1 |
| **契约 / 承诺 / 期限类事实而模型接不住** | `8-K 1.01 / 2.03` · 附注承诺与或有 | **报"缺格"**（模型结构可能要改） |
| **薪酬与业绩脱钩 / 目标值改口径** | 委托书的 `CD&A` 与薪酬表 | 业绩未达标而薪酬升，或目标被下调 |
| **关联交易未经审批程序** | 委托书的关联交易段 | 点名"程序未覆盖或未遵守" |
| **非审计费占比异常** | 委托书的审计费四类 | **须算**占比 |
| **重大摊薄 / 持续经营类措辞** | 招股书的摊薄表与风险段 | 购买者承担的即时摊薄；持续经营重大疑虑 |
| **募集资金用途模糊** | 招股书的用途段 | 只写"一般公司用途"而无比例 |
| **流动性缺口** | 中期报告的流动性段 | 出现重大资金缺口及补救措施 |

**红灯不是结论，是上报信号**：写清"**在哪一段 / 哪一附表或附注 / 多少 / 与什么比变没变**"，**判断留给主控**。
