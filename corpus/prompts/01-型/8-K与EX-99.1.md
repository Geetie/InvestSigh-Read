## 0. 它是什么

**认它的痕迹**：`DocumentType=8-K`，正文是**事件条目编号**（`Item 1.01` … `Item 9.01`）；**业绩那一条 ＝ `Item 2.02`**。

**这些别问它**：

| 别问 | 为什么问了也没用 |
|---|---|
| `10-K` 的问句 | 它**没有完整三表、没有附注全套、没有审计意见、没有 ICFR** |

**反向也要守**：`20-F / 6-K`（外国私人发行人用）与 `6.x`（资产支持证券）**对本模型对象不适用** ⇒ **回执"不适用"**，**别按"应该有"报缺口**。

## 1. 怎么读（与"长表"那几类**完全不同**）

**读法的依据（不是自己定的规矩）**：

- **每一段都要有交代**。正文和附件全文的每一段，读了、有理由的略读、或者不适用，都写明。不许只记"条目号"。（依据：`撰写规范 §1.9`；守卫 `system/scripts/checks/material_spans_guard.py`）
- **抄下来的必须有数字**。量名、数值、期间、口径；给的是区间，就写上下限和基数。实在没有数可写，就写"放不进任何篮子"的理由。（依据：`撰写规范 §1.8`）
- **数字分级 ＋ 两条数据纪律**。Ⅰ 可逐行复核，Ⅱ 二手带链接，Ⅲ 未核。同一个数字要有两个以上独立来源，偏差超过 2% 就要报警。
- **自定义口径（non-GAAP、调整后指标）必须建定义卡**——定义、GAAP 桥、历史变更、同业差。**这是 8-K 里最容易出事的一项**。（依据：`撰写规范 §7.5`）
- **值得报 ＝ 定量 ＋ 定性**。定量只是起点。掩盖趋势、掩盖未达预期、亏损转盈、涉及重要分部、影响契约合规、增加管理层薪酬——这些定性因素可以让金额小也照样重大。（依据：SEC `SAB 99`）

所以：条目和附件段落只是**去哪儿找**（定位）。落库的单位是**段**——每段有决定，段的并集等于全文。

### 1.1 本件的两块，读法各异

| 块 | 长相 | 怎么读 | 为什么 |
|---|---|---|---|
| **正文（`Item` 条目）** | **极短**（通常 1 页上下），多为**空壳**：只有条目号 + 一句事实 + 附件指向 | 先看封面勾的 Item：只有 2.02 加 EX-99.1 才是业绩原件，申报期限是事件后四个工作日，且 2.02 只是 furnished。指引在稿末展望段：抄上下限、对应财季、GAAP 还是 non-GAAP、假设含不含回购与汇率。 | 它是"**事件索引**"，不是内容 ⇒ 只看它 = **等于没读** |
| **业绩附件 `EX-99.1`** | **自由格式**（无固定骨架）：业绩稿、指引、桥、分部、评论 | 取非 GAAP 对账表逐项抄：股份支付、并购摊销、重组、税影响各多少，以及调整后税率。只有口径没有对账表的写「未给对账表」；前瞻性 non-GAAP 允许不给对账，这种要单独标出。 | 无骨架可依 ⇒ **只能全读**；件本身短（数页），可行 |

### 1.2 三层读法（8-K 只用后两层）

| 层 | 用在哪 | 怎么读 |
|---|---|---|
| 骨架层（**不适用**） | —— | 业绩稿一般只给同比，量价拆分多在电话会或 10-Q 的 KPI 附注里；稿内没有就写「稿内无量价拆分」。不要用总收入增速反推量价，那等于自己造数。 |
| **自由段层** | **主体方法**：`EX-99.1` 全文 + 正文条目 | 分部表照抄收入与营业利润，注明是补充材料、未经审计，并核对利润里含不含分摊；本期改过分部或分摊方式的，写「口径变更、同比不可比」，不要拿两期数字直接算增速。 |
| **升级层** | 命中**信号词**：审计师变更 · 重述 · 减值 · 退出成本 · 重大协议 · 加速义务 · 网络安全事件 · 需要以现金结算的费用 | 资本开支在现金流量表投资段是现金购置数；指引里的资本开支常含融资租赁与在建工程转入，两个口径不能直接比。抄指引原句，注明含不含融资租赁与土地。 |

### 1.3 停止条件

**§3.1 的条目**逐条有回执，且 **`EX-99.1` 全文过完**（含**桥**与**指引**两段），且 §4 问句表**每条有答案或具名缺口**。
**唯一可略的**：正文里的**免责与程序样板**（"shall not be deemed filed"这类）—— **略也要写理由**。
**不许**：只看正文、只看业绩稿标题与首段、只看新闻稿不看桥。

## 2. 结构上必然携带（Q1）

| 必然携带 | 别处拿不到的是什么 |
|---|---|
| ① **当期实际数与上年同期对比**（收入 / 成本 / 利润 / 现金流），**带分部** | 一手口径的当期数字（比电话会转述更硬，比年报更**新**） |
| ② **指引**：区间 **＋ 基数/假设**（汇率、口径）＋ **期间** | **唯一**能拿到"公司自己给的未来区间与它依赖的假设"的地方 |
| ③ **非 GAAP 与 GAAP 的调节表（桥）** | 调整项的**构成与措辞**（"一次性"的定义权在公司手里，桥是它的自认） |
| ④ **量价与参与度**（展示量 / 单位价格 / 用户口径） | 变现率的两条腿 |
| ⑤ **资本开支与费用指引、回购与股息** | 资本配置与工具投入的当期口径 |
| ⑥ **单点事件的硬事实**（协议 / 发债 / 减值 / 退出成本 / 高管变动） | 契约与期限类事实（最易撞"模型没有对应格"） |

**它的法律性质要记住**：`EX-99.1` 是**随附**的业绩发布件，**通常声明"不被视为已申报"**（Section 18 免责）。
所以**它的措辞层级与年报不同**：引用时写"**公司于〔日期〕称……**"，**不是**"已申报事实"。

## 5. 特有的坑（只写 8-K 才有的）

这一节列**只有这类材料才会踩的坑**——踩了不会报错，但结论会错。按下面的顺序看：**前一半是「读错」**（把 A 当成 B、把旧数当新数），**后一半是「算错」**（口径混用、净额化、时间错配）。读错比算错更难发现，因为它不影响数字的算术正确性。

1. **只读正文 = 没读**：正文是**事件索引 + 空壳**，实质在 `EX-99.1`。
2. **`EX-99.1` 不是"已申报事实"**：它通常声明"**不被视为已申报**"（Section 18 免责）⇒ 引用措辞用"**公司称**"，**不得**写成法定申报事实。
3. **`non-GAAP` 的"一次性"有法定判据，不是凭感觉**：
   官方口径禁止**抹平"非经常性"项目**，前提是该项目**两年内合理可能再现**、或**前两年内曾出现类似项目**
   ⇒ 判"常态化"**以这个两年口径为底线**（更严的观察口径可另记，但不能替代它）。
4. **桥必须引用桥本身**：只抄 non-GAAP 数字、不看 GAAP 对账 ⇒ 等于采信了一个没有来源的数字。
5. **指引的"基数与假设"最容易漏**：区间不带基数与汇率等假设 ⇒ **换算出的增速必错**。
6. **回购的两个口径**：8-K 里的当期回购金额 **≠** 年报里的**授权额度与已用**（§7）。
7. **附件清单（`9.01`）是唯一能发现"重大合同 / 发债文本"的地方** ⇒ 不看清单，后面全找不到。
8. **`7.01` 的内容常常不是"正式"，但含指引修正** ⇒ 别因条目名像"非正式"就略过。

## 6. 红灯：见到必须上报

这一节列**见到就必须停下来喊人**的信号。判断标准不是「数字大不大」，而是**「我能不能独立复算」**：复算不了的、两处对不上的、只有结论没有依据的，都要上报。上报时写清三件事——**在哪一段、多少、和什么比**；判断留给主控，你只负责把它摆出来。

| 红灯 | 判据 |
|---|---|
| **审计师变更** | `Item 4.01` 明确出现（看**条目本身**，不是看词） |
| **财报不可依赖（重述）** | `Item 4.02` 明确出现 |
| **重大减值** | `Item 2.06` |
| **重大网络安全事件** | `Item 1.05` |
| **退出 / 处置成本** | `Item 2.05`（与重组费用行对账） |
| **"一次性"常年出现** | `EX-99.1` 的桥里，同一调整项**两年内合理可能再现 / 前两年曾出现类似项**（§5 第 3 条） |
| **指引被撤回或大幅改口** | 指引段与口径声明 |
| **回购口径与年报冲突** | 8-K 里的当期回购与年报的授权/已用对不上 ⇒ 上报（别自己选一个） |
| **协议 / 义务类事实，而模型没有对应格** | `1.01 / 2.03` 的条款 ⇒ **报缺格** |

红灯**不是结论**，是**上报信号**：写清"**哪个条目 / 哪一段 / 多少 / 与什么比**"。

## 7. 跨类照应（只写"口径差异提醒"，**不引用别的册**）

| 提醒 | 内容 |
|---|---|
| **8-K 是"当期 ＋ 前瞻"，年报是"年度 ＋ 审计"** | 同一科目两处数字**口径与期间不同**，**别直接相减**，也别拿 8-K 的数当年度数 |
| **回购** | 8-K 给**当期金额**；年报给**授权额度与已用** ⇒ 两个口径都要，**不能互相替代** |
| **非 GAAP 的用法** | 8-K 的桥是**自愿沟通**；年报里的同类披露受申报文件规则约束（醒目度、位置） ⇒ **同一调整项的措辞可能不同** |
| **指引** | 8-K 是**唯一**给区间与假设的地方；年报通常**不给前瞻区间** ⇒ 别在年报里找指引 |
| **分部定义** | 8-K 里的分部口径与年报**可能重分类过**，拿来比之前先确认定义 |
