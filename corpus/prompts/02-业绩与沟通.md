## 一、定位：它给「**公司怎么说**」和「**接下来会怎样**」

`01` 给**法定事实**（已发生）；本类给**另外两样**，别处拿不到：**管理层对变化的解释**（意图）+ **指引与承诺**（区间 / 基数 / 假设）。

★★ **本类 = 故事，`01` = 账，故事必须拿去和账对**（「净利润是管理层讲的故事，现金流才是审计」）
⇒ ★ 本类**不能单独下结论**；可信度要回 `01` 的报表与现金流核（见 §三 3.4）。

| 要拿的 | 影响的是**哪个判断** |
|---|---|
| 量价的官方解释 + 拆分 | 广告变现率的动力是"**看的人更多**"还是"**每人更值钱**" |
| 用户与参与度的口径与叙事 | 用户与注意力（规模在不在长、口径可不可比） |
| 变现率的约束（体验 / 广告负载） | 广告位还能不能继续加 |
| 对费用与折旧的解释 | **算力的折旧吃多少毛利** · 人力成本是压下去还是变天价薪酬 |
| 前瞻指引及基数与假设 | **算力要花多少钱** · Reality Labs 亏损斜率 · 广告之外的收入能否站住 |
| 资本配置的表述（回购 / 融资 / 稀释） | 每股的引擎是缩股还是增股 |
| 对诉讼与监管的立场 | 会不会变成可计量负债或结构性改动 |

★ 括号里的 `M-x`（如 `M-7`）**只是模型内部行号**：写给人看时**一律写含义**，编号最多放括号里。

## 二、先分型：本类 **58 份不是一种文体**

| 型 | 是什么 | 子型 | 允许的说法 |
|---|---|---|---|
| **公司自己的话** | 管理层逐字 | **准备稿**（他要你听什么）· **问答**（压力下的反应）· **法定发布件**（`8-K Item 2.02` + `EX-99.1`：指引原文与非 GAAP 桥的法定发布地） | "**公司于〔日期〕称……**"；★ **"将 / 计划 / 目标" ≠ "已 / 达"** |
| **别人的解读** | 他人结论 / 他人假设 | **假设表**（可复算）· **点评**（只有结论）· **预览**（事前预测，最易打脸） | "**某机构认为 / 据……称**"；★ **不得当事实用** |
| **旁证与读穿** | 同业与上下游 | — | 只能当**旁证或反证**（"同一时间 xx 也这么说"）；★ **禁当 Meta 的事实**；对下游的拉动属催化剂侧，本类不推 |

★ **三档口径（本文件内定义）**：**Ⅰ = 本地语料可逐行复核** · **Ⅱ = 二手（须标机构）** · Ⅲ = 未核待核。
★ **公司自己的话 = Ⅰ**；**假设表 = Ⅰ**（数据文件、可复算）；**点评与预览 = Ⅱ**；**旁证不单独支撑结论**。
★ **判错型的代价（实测）**：把假设表当公司披露 ⇒ 把**别人的推算**署成公司原话；把预览当点评 ⇒ 把**事前猜测**当**事后解读**。

**认完型先打开对应的那一册，按那册的"怎么读"走**；问句表仍以本文件 §4 为真源（分册不复制，避免两处漂移）。

| 文体 | 分册 | 一句话边界 |
|---|---|---|
| **公司自己的话**（管理层逐字） | `02-型/公司自己的话.md` | 主语是公司与管理层；**唯一能拿到"承诺"的地方**；承诺句不得当已发生 |
| **别人的解读**（他人结论／假设） | `02-型/别人的解读.md` | 主语是他方；★★ **本型无问答 ⇒ §4.1 问句禁用** |

## 三、本类有什么

### 3.1 各型**结构上必然**携带什么

| 型 | 必然携带 | 别处拿不到的 |
|---|---|---|
| 公司自己的话 | ① 本季 / 全年**实际数字**（收入、成本、费用、利润、现金）② **对变化的解释** ③ **下期与全年指引**（区间 + **基数** + 期间）④ **口径变动声明**（定义 / 分部 / non-GAAP 桥）⑤ **问答**：分析师反复追的那件事 | **动机与承诺**；★ 唯一能拿到"承诺"的地方 |
| 别人的解读 | ① **别人的假设取值**（收入增速、折旧、算力开支、税率、回购、股数）② 与共识的差 ③ 它认为最关键的单一变量 ④ 情景区间；★ **假设表有内部一致性（可复算），点评没有** | **别人的答案**——做**逐行对照**（"他 2027 年增速 / 折旧是多少，和我差在哪一项、哪一年"） |
| 旁证与读穿 | 同业同期读数、行业资本开支追踪 | **横向锚** |

### 3.2 三个载体陷阱（实测，踩了就白读）

1. **电话会不能只读准备稿** —— 重点在**问答**（同一问题的措辞变化是**领先信号**）；
2. ★★ **`xlsx` 模型不能读抽取正文** —— 实测（`02s外-big1`）：抽取正文 **1,240,782** 字符里 **98.1%** 是公式与引用串（单行最大 **609,523** 字符），`Meta` 只出现 **1** 次 ⇒ **必须回原生表读**（否则照抄 `#REF!`、给不出载位）；
3. ★ 别用"某个词出现几次"判断讲的是谁 —— 同实测：该件通篇是 Meta 本体模型，却被词密度判成"外部材料"。

### 3.3 本类**读不到**的（写死，别乱找）

**产品线级收入拆解** · **广告负载的数值**（实测公司材料都无数值披露） · **会计假设的完整口径**（使用寿命、残值；去申报稿找）。

### 3.4 ★★ 四条会计硬判据（"调整后 / 一次性"能不能采信）

| # | 判据 | 阈值 / 信号 |
|---|---|---|
| 1 | **有没有桥** | 非 GAAP **必须配 GAAP 对账**（法定发布地 `8-K Item 2.02` + `EX-99.1`；Reg G 要求**不得比 GAAP 更醒目**）；**无桥 ⇒ 不得采信** |
| 2 | **"一次性"是不是经常性** | 最近 **8 个季度**的 GAAP→调整对账：**同类费用出现在 ≥5 季 ⇒ 结构性成本，不是例外** |
| 3 | **利润有没有变成现金** | **应计比率 =（净利润 − 经营现金流）/ 平均总资产**：**>0.05 观察 · >0.10 深入**；**现金转换（经营现金流 / 净利润）<1** 同为红旗 |
| 4 | **收入有没有被提前** | **应收增速连续 ≥2 季快于收入** · **递延收入下降而报告收入上升** · 季末收入尖峰 |

★ **一票升级**（见到就上报）：**更换审计师 · 财报重述 · 内控重大缺陷**。
★ ★ 这四条**全要回 `01` 核** —— 本类**只负责把话说清楚，判真假是 `01` 的活**；★ 但漏了它们，就会把"调整后的故事"当事实递上去。

## 四、★★ 主表（问句 · 去哪找 / 算答了 · 频次 · 落篮）

★ 三类问的**不是同一件事**：**公司自己的话问"他为什么这么说、兑现了没有" · 别人的解读问"他的假设和我差在哪一行" · 旁证问"同期别人说了什么、能不能反证他"**。
★ **公司原话的问句禁用于别人的解读**（实测：`02s外-big1` 是卖方模型，被"被追问最多的一项"**误伤**）。
★ **频次列**：`季` = 本批可做；`跨 2 季 / 跨 4 年 / 跨 4–6 期` = **本批做不到** ⇒ 报告里写"**需跨批（交主控）**"（`RUN-PARALLEL §1`：一批一跑，**禁自己编造跨期对照**）。
★ **两条跨期硬对照**（同样只能标"需跨批"）：**毛利率与成本结构看最近 4 个季度**（每季 100bp 的压缩会复利）；**应计与现金转换看最近 4 年**。

## 五、阅读路线（按型）与停止条件

**公司自己的话 —— 读到"问答"为止**：准备稿 → **全部问答**（不许只读准备稿）→ 幻灯片 / 法定发布件（`8-K Item 2.02` + `EX-99.1`，比转述可信）→ **同一问题的上季回答**。
　★ 停止条件：问答里**每一个被重复问到的问题**都有落点（答案或具名缺口）。

**别人的解读 —— 先修正、后假设、再情景**：首页（评级 / 目标价 —— **只作背景，不作依据**）→ **预测修正** → 论点要点（能否**映射到模型的某一行**）→ **假设表逐行**（`xlsx` 必须回原生表）→ 估值与情景 → 风险章（有无挂数字）→ 图表（收入增速 / 利润率趋势 / 同业对比 / 竞争地位）。
　★ 停止条件：**每一处与我方不同**的假设都已点出。

**旁证 —— 只取原话 + 数量级**：**只读结论页 / 摘要，不深读全文**。
　★ 停止条件：能反证本体的那一句已取到。

**通用硬规则**：★ **公司原话与别人的解读禁抽样**（不许只看摘要 / 前 N 页 / 因太长而抽样）；★ **旁证按上条只读结论页即算读全**（唯一豁免——理由是旁证**不支撑结论、只做旁证**）；★ 单份超单窗（本环境单份最大 **124 万字符**）必须**分段遍历**、每段一条段回执；★ **载体先探针**：`xlsx` 回原生表；**扫描件 / 音频**如实报"**读不到**"（不得写成"无关"）。

## 六、回执 · 处置 · 自检

这一节是**收尾三件事**：回执（哪些段落读过了）、处置（读到的怎么处理）、自检（有没有带病交付）。三件事的顺序不能反——先回执再处置，否则会漏段；自检放在最后，是因为它要拿前两步的结果对账。

1. **回执（机器账，不进报告正文）**：逐条问句都要有回执 ⇒ ★ **只落 `覆盖回执.csv`**（含 `段总数 / 已过段数 / 跳读段号 + 理由`，与**应回执 / 已回执 / 未回执**三个读数）；★ **未回执逐条列**（既不写答案、也不写具名缺口 = **漏报**）。
2. **能填的进哪**：★ **能填 ⇒ 写进报告正文**（§四 主表的答案）；★ **回执与统计 ⇒ 只进 `.csv`**。
3. **处置三类**：**能填**（写进报告 + 标 **Ⅰ / Ⅱ** 档）· **噪声**（删掉模型任何一行都不变、且本身不是可观察事实 ⇒ `drop_reason` 写"**删掉不影响〔哪个判断〕**"，**不写编号**）· **缺篮 / 缺行**（本身可观察 / 可计量 ⇒ 出对应报告，**不得当噪声**；本类高发：**新产品线的独立收入口径 · 组织与人事变动 · 对外供货 / 许可条款**）。
4. **信源分流留痕**：每句结论标 **公司称 / 某机构认为 / 旁证**。★ **本类两种特有失败**：把**别人的解读**写成**公司原话**（信源层级混淆，`撰写规范 §9.6` 末条）；把"**将 / 计划**"写成"**已**"（`撰写规范 §9.6`）。
5. **必须喊人 zoom-in**：① 指引的**基数与假设没给**；② 口径改了无对照；③ 首见的新指标无基线；④ 缺篮 / 缺行且判不出挂哪层；⑤ ★ **问答里被追问多次却始终没正面回答**（最值得人看的信号）。
6. **不得做**：① 禁把别人的解读与旁证当 Meta 事实；② 禁在**本层**下"利好 / 利空"（方向属下一层，`test_findings DF-7` 第 6 条）；③ 禁口算；④ 禁为填格而找信息；⑤ 禁把缺篮当噪声；⑥ **禁截断 / 抽样 / 不给回执就下"没有"的结论**。
7. **空样本如实**：本类无材料 ⇒ 报 **0 份**（不得用他类顶替）；★ **未回执 > 0 ⇒ 逐条列**，不得写成"本批无增量"。
8. **落篮缺口（`2026-10-13` 已写入真源）**：沟通面 5 类 = `指引与兑现` · `话与数是否一致` · `问答动态与措辞演变` · `他人假设与预期差` · `同业旁证与反证`（② 类 **7 → 12**）。★ **前两类供进模型假设；后三类供验证与反证**（价值侧 / 催化剂侧共用）。
