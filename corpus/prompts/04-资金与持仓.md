# `04-资金与持仓` —— 摄入提示词（**读数 ≠ 方向**；篮子 `2026-10-13` 起**有据豁免新建 5 类**）

## §0 一页速查（先读这 20 行，再读下面）

**这一类只回答一件事**：**谁在动、动多少、在什么价位、是不是主动**。它不出方向结论（"谁在买 ≠ 利好"）。

**三种型，纪律不同**：

| 型 | 材料 | 它给的是 | 最大陷阱 |
|---|---|---|---|
| 内部人申报 | Form 3/4/5 | **事件流**（某天某人买了/卖了多少） | 把代扣税、行权、赠与当增减持 |
| 机构持仓申报 | 13F/13D/13G | **季末存量快照**（滞后 45 天） | 看不到空头与债券；把期权名义当持股 |
| 做空与期权读数 | 空头余额、借券、期权 | **拥挤度与对冲需求** | 把做市商对冲当方向性做空 |

**五个核心概念**：

1. **交易代码决定性质**：P 买入 / S 卖出 / A 授予 / F 代扣税 / M 行权 / G 赠与。读 code 优先于读股数。
2. **一笔 ≠ 一行**：同一人同日多账户会拆成多行，先合并到人。
3. **10b5-1 勾选框**：勾了 = 计划性交易，信号弱；没勾的机会性交易才可能含信息。
4. **集群 > 单人**：30 日内 ≥3 位内部人各自买入，是最强形态。
5. **四件套才算空头**：SI % float + days to cover + 借券费 + utilization，单看一个必误判。

**三对最容易混的**：内部人申报（事件）≠ 13F（快照）；净额 ≠ 逐笔（净额会抹掉反向多笔）；空头余额 ≠ 方向性看空（可能是对冲）。

**只记三件事**：① 先读 code 再读数字；② 逐笔写方向、价位、是否主动；③ 聚合口径的读法不许当申报级证据。

**编号约定**：本书断点号只在本类有效，别与 05/06/07 的同号混用。

## 一、定位：它给的是「**谁在动、动多少、在什么价位**」——纯行为读数

`01` 给事实、`02` 给解释、`03` 给别人的算法，本类给**行为**：**谁在买 / 卖、什么价位、是不是主动、量级多大**，以及**公司把现金挪到哪儿去了**。

**本类的立类纪律（逐字）**：`system/skills/aichain-fund-flow/SKILL.md` 的定位段与 `§8` —— 「**谁在买 ≠ 利好**」。
**读数是事实，方向判定不属本类。**

| 要拿的 | 影响的是**哪个判断** |
|---|---|
| 内部人成交（股数 / 均价 / 总额 / 持股变化） | **每股的引擎是缩股还是增股**（内部人在增还是在减）· 模型行号 `M-8` |
| 回购与融资（回购是否为 0 / 是否增发） | 同上：**分母在缩还是在胀** · 模型行号 `M-8` |
| 机构持仓结构（谁增谁减、拥挤度） | 共识基线：**这只票被谁拿着、有多挤** |
| 裁员 / 组织调整的现金含义 | 人力成本是压下去了还是变成天价薪酬 · 模型行号 `M-6` |
| 期权与做空读数（如可得） | 见 §三 3.3：**期权流尚未接入**，**不得**当作已覆盖 |

## 二、先分类：本类**分三种**，纪律不同

**本类 = 谁在动钱**（EDGAR 级**行为事实**）—— 只有**申报 / 披露**才算读数；"谈到资金"的研报不是。
**若材料不属于本类 ⇒ 按 `README.md §3.1.2` 分流**（例：只是"谈到资金"的研报属 `03`；法定披露件属 `01`）。

**判定四问**（拿任何一份材料，按序问；判定"它是不是本类的资金读数"）：
1. **主体是行为，还是观点？**——"谁买了 / 卖了多少 / 持有多少"是行为；"资金面转暖""筹码集中"是形容，不是读数。
2. **有没有申报级结构？**——逐笔的 code / 股数 / 价 / 交易后余额，或持仓明细表（13F 的持仓行）。只有"净流入 X 亿"一个数，没有结构，就不是读数。
3. **能不能回溯申报源？**——聚合站的表要能对上 EDGAR 原始件（Form 4 的 XML / 13F 的持仓 XML）；回溯不到就只能当二手线索。
4. **读的是流量还是存量？**——Form 4 是**事件流**（某天某人交易了），13F 是**存量快照**（季度末某时点持有多少）。两者口径不同，**不得互相当对方用**。
四问过半是"是"，才进下面的三型表；过不了，按分流走。

| 型 | 识别线索 | 是什么 | 子类 / 纪律 |
|---|---|---|---|
| **真资金读数**（本类核心） | **内部人申报件（Form 4 逐笔）** · **公司的回购 / 股本行（法定附件）** · **持仓申报（13F / 13G / 13D）** | **EDGAR 级行为事实** | 可用"**已发生**"措辞；**必须逐笔看 `transaction code`** |
| **资本配置与股本（别人的解读）** | **研报 / 追踪框架**谈现金去向与成本侧（算力开支挤占回购 · 裁员与组织调整） | **现金去向 / 成本侧** | 填"人力成本"与"每股引擎"两处；属**他人结论**的部分须标"**某机构认为**" |
| **旁证研报与财报稿** | 其余**卖方 / 行业媒体件** | **不是资金读数** | 只能作**背景**；**禁**用它充当"资金流"（那是 `03` 的内容） |

**三档口径（本文件内定义）**：**Ⅰ = 本地语料可逐行复核** · **Ⅱ = 二手（须标机构）** · Ⅲ = 未核待核。
**真资金读数**：聚合站件须**回溯 EDGAR 原始件**后才可为 **Ⅰ**（见 §三 3.2）；**别人的解读**：填进来时是 **Ⅱ**；**旁证**不单独支撑结论。
**判错型的代价（实测）**：把**税务代扣**读成减持信号（本类已点名）；把**研报"资金异动"**当资金读数（那是 `03` 的篮子）；把 **13F** 当"当前持仓"。

**真资金读数再分三本分册**（先认细类，再打开对应册，按那本册的读法走；"别人的解读"与"旁证"两型不设分册，读法就在本件）：

| 细类 | 认它的痕迹 | 该读哪本分册 |
|---|---|---|
| **内部人申报** | EDGAR **Form 3/4/5**；聚合站 Form 4 表格件（二手） | `system/env/meta/prompts/04-型/内部人申报.md` |
| **机构持仓申报** | **13F-HR**（≥$1 亿机构季末快照）· **SC 13D**（主动举牌）· **SC 13G**（被动持有） | `system/env/meta/prompts/04-型/机构持仓申报.md` |
| **做空与期权读数** | 做空余额 / 借券费率 / 期权 flow·OI（**当前无源**，先做三态登记） | `system/env/meta/prompts/04-型/做空与期权读数.md` |

## 三、本类有什么

### 3.1 各类**结构上必然**携带什么

| 型 | 必然携带 | 别处拿不到的 |
|---|---|---|
| 真资金读数 | ① **逐笔**：方向 · `transaction code` · 股数 · 价 · 金额 ② **持股变化后的余额** ③ 回购 / 股本 / 稀释行 ④ 13F / 13G / 13D 的申报日与持仓 | **被动 vs 主动的区分**（本类独有）—— 同一批"卖出"，**税务代扣 / RSU 归属 / 10b5-1 计划性减持**与**公开市场主动卖出**含义完全不同；**成交价位**是模型里本来没有的维度（"他成本在哪"） |
| 别人的解读 | 现金去向（回购 / 分红 / 算力开支 / 裁员计提） | 公司把现金挪到哪儿去了 |
| 旁证 | 研报与财报稿的结论 | 只能作**共识基线**的背景 |

### 3.2 三个来源与口径陷阱（本类实测）

1. **聚合站是二手** —— **第三方 Form 4 聚合站**（非 EDGAR 原始件）属二手 ⇒ `tier=secondary_tertiary`；
   要当事实用**必须回溯 EDGAR 原始 Form 4**。
2. **不得把 A 股资金栏目套到美股**（龙虎榜 / 北向 / 筹码，`§S5`）；**不得把做空余额当日内做空压力**（`§S4`）；**不得把 put/call 汇总当"大单"**。
3. **"净额"会掩盖方向相反的多笔** ⇒ **必须附逐笔明细**（本类硬要求）。

### 3.3 本类**读不到 / 未实测**的（`absence_note`，必须如实登记）

| 项 | 现况（契约 `§5` / `§6` 逐字） | 必须怎么写 |
|---|---|---|
| 期权流 | **有源未装** | 写"**尚未接入**"，**不得**当作已覆盖 |
| 做空余额 | **免费源存在（FINRA，双周），本次 API 未接通**（`2026-10-14` 实测返回空） | 写"**有源未接通**"，**不得**写"无做空风险" |
| 治理 / 薪酬 / 质押 / 回购（`governance-and-ownership-reader`） | **尚未实测** | **不得**称"治理 / 质押已覆盖" |
| 逐笔期权流 / 个股真实资金流 | 免费不可得 | 写"**缺口：××未登记**"，**不得**写"影响可忽略" |

### 3.4 本类判据（**有源则用、无源则如实登记**）

| # | 判据 | 阈值 / 信号 |
|---|---|---|
| 1 | **主动 vs 被动** | 只有 `code = S` **且非代扣**的才可读作减持；**同日全员代扣** ⇒ **被动** |
| 2 | 内部人交易的"质量" | 只看**公开市场买入**（行权 / 薪酬转移不算）；**routine vs opportunistic**（同月连续 ≥3 年交易过 ⇒ routine，噪声大）；**cluster buy**、长期无买入后的首次买入 ⇒ 信号强 |
| 3 | **13F 时滞** | **季度 + ≤45 天** ⇒ **不得**当"当前持仓"；超 45 天仍被当"当前" ⇒ **判红** |
| 4 | 13G ≠ 13D | 前者**被动**、后者**主动**，**语义不同**，不得混用；**`<5%` 无申报义务** ⇒ 不得由"无 13D"推"无人举牌" |
| 5 | 做空（如可得） | **回补天数（DTC）比占用率更重要**，且**须用 30 日均量自算**；**借券费率看变化率**，不看时点值 |
| 6 | 期权（如可得） | **flow = 变化信号，OI = 历史背景**；**大额打印 = 风险转移的证据，不是方向性下注的证明**；须看 **gamma 环境**（正 gamma 抑制波动、负 gamma 放大） |

## 四、主表（问句 · 去哪找 / 算答了 · 频次 · 落进哪个篮子）

## 五、阅读路线与停止条件

**申报读数 —— 逐笔读，不许只看净额**：`transaction code` → 股数 / 价 / 金额 → **持股占比（须算）** → 是否**同日全员代扣** → 13F / 13G / 13D 的**申报日与性质**。
　停止条件：**每一笔**都有"主动 / 被动"标注与依据；**凡有相反方向的多笔，必须逐笔列出**。

**别人的解读 —— 先现金去向、后每股口径**：回购 / 分红 / 算力开支 / 裁员计提 → **每股的引擎（缩股还是增股）**。
　停止条件：现金去向已成表；属他人结论处已标"某机构认为"。

**旁证**：只作**背景 / 共识基线**，**禁**充当资金流读数。

**通用硬规则**：**本类为月 / 季频且滞后** —— 拿到读数先看**申报日**；**禁抽样**（不许只看摘要 / 前 N 页）；**载体先探针**：`xlsx` 回原生表；**PDF 一律先解析成文本再读**（解析产物在 `system/env/meta/raw/batches/<date>/_extracts/`，由提取层负责，**禁止**因格式跳过），扫描件解析不出才如实报"**读不到**"（并写明试过什么，不得写成"无关"）。

## 六、回执 · 处置 · 自检

这一节是**收尾三件事**：回执（哪些段落读过了）、处置（读到的怎么处理）、自检（有没有带病交付）。三件事的顺序不能反——先回执再处置，否则会漏段；自检放在最后，是因为它要拿前两步的结果对账。

1. **回执（机器账，不进报告正文）**：逐条问句都要有回执 ⇒ **只落 `覆盖回执.csv`**（含 `段总数 / 已过段数 / 跳读段号 + 理由` 与**应回执 / 已回执 / 未回执**三读数）；**未回执逐条列**（既不写答案、也不写具名缺口 = **漏报**）。
2. **能填的进哪**：**能填 ⇒ 写进报告正文**（§四 主表的答案）；**回执与统计 ⇒ 只进 `.csv`**。
3. **处置三类**：
   - **能填**：写进报告，标 Ⅰ / Ⅱ 档。
   - **噪声**：删掉模型不动，且本身不是可观察事实（"资金面转暖"这类无出处的形容）。`drop_reason` 写"删掉不影响〔哪个判断〕"，不写编号。
   - **缺篮 / 缺行**：本身可观察 / 可计量，出对应报告，不得当噪声。本类高发：成交价位的分布、借券 / 融券与质押、表外义务。本环境样本里"7300 亿 / 表外义务 1.65 万亿"就属此类，不得硬塞。
4. **信源层级**：**第三方聚合站件**须**回溯 EDGAR 原始 Form 4** 才可当事实；标 `tier=secondary_tertiary`。
5. **必须喊人 zoom-in**：
   - 单笔金额异常大，而对手方 / 原因不明。
   - 同一期间多笔方向相反（增持与减持并存），不得净额化。
   - 13F 超过 45 天仍被用作"当前持仓"。判红并上报。
   - 缺篮 / 缺行，且判不出挂哪层。
6. **空样本如实**：本类无材料 ⇒ 报 **0 份**；**不得**用 `03` 类研报里的"资金异动"凑数（那是 `03` 的篮子）；有材料但抽不出可核读数 ⇒ 报"**本批无可用资金读数**"。
7. **不得做**：
   - 禁把税务代扣读成减持信号。
   - 禁把 13F 当"当前持仓"。
   - 禁把市场级读数当单票证据。
   - 禁把读数写成方向判定（谁在买 ≠ 利好）。
   - 禁把 A 股资金栏目（龙虎榜 / 北向 / 筹码）套到美股（`§S5`）。
   - 禁把做空余额当日内做空压力（`§S4`）。
   - 禁把 put/call 汇总当"大单"。
   - 禁截断 / 抽样 / 不给回执就下"没有"的结论。
   - 禁把"无源"写成已覆盖。
8. **新增的篮子（`2026-10-13` 有据豁免）**：④ 类**新建 5 类篮子** —— `内部人交易（仅公开市场）` · `机构持仓与拥挤度` · `做空与借券` · `期权与衍生品定位` · `资金流（被动 vs 主动）`；
　**依据**：真源 ④ 行原写「**明确无方法论骨架**…**不得自造分类**」，其 `no_skeleton_reason` 的语境是 **`westockdata` 这个数据 skill**（"纯读数清单 / CLI 命令速查"），**不是**"本信息类无骨架"；且调研实证该类**框架很硬**（阈值与噪声清单齐备）。
　**原冻结表述保留留痕**（真源里未删）；契约 `aichain-fund-flow` 若仍写"一切走 `unclassified_reason`"，需同步（登记在 `system/env/meta/test_findings.md` DF-13）。

## 七、断点（本类专用编号，勿与 05/06/07 同号混用）

这八条断点的共同点是：**都不是「读不懂」，而是「读到了却没落到底」**。断一断二出在取值（拿聚合页当原件、把代扣当减持），断三断四出在口径（净额抹掉方向、把滞后数据当当前），断五断六出在标记（期权名义当持股、空头单看股数），断七断八出在归属（market-wide 当单票、主动被动没据）。

**顺序是刻意的**：前四条几乎每批都会碰到，后四条只在特定件上出现。先看断一，它最常见。

| 断点 | 断在哪 | 怎么处理 |
|---|---|---|
| 断一 | 只有聚合站口径，没回溯 EDGAR 原始件 | 可登记，标 `secondary_tertiary`，不许当事实层 |
| 断二 | 把代扣税（F）/行权（M）/赠与（G·C·Z）当增减持 | 退回重判 code，禁出方向 |
| 断三 | 净额化（买入−卖出合成一个数） | 拆回逐笔，相反方向必须并列 |
| 断四 | 13F 超过 45 天仍当"当前持仓" | 写"截至季末 + 滞后 N 天"，禁写"当前" |
| 断五 | 13F 里把期权名义股数当持股 | 先判方向（put/call）与是否替代持股 |
| 断六 | 只有空头股数，没有 days to cover / CTB / utilization | 四件套缺一 ⇒ 只写"空头余额"，不判挤压 |
| 断七 | 把市场级读数（指数资金流）当单票证据 | 降为背景，不落单票篮子 |
| 断八 | 写不出"这一笔是主动还是被动"的依据 | 卡不完整，退回补 |

**最容易自欺的三处**：断二（F 当减持）、断三（净额掩盖方向）、断四（滞后当当前）。
