# `01-监管一手披露` —— 摄入提示词

> 路径从**仓库根**写起（`README.md §3.1`）；通用纪律（未归类 / 未回执清单 · 禁口算 · **逐段回执**）见 `README.md §3.2`。
> **边界**：**可读＝仓库根以下全部（只读）**；**可写＝仅 `output/<标的>/<材料 id>/`**；其余一律禁写（逐条见 `README.md §3.1.1`）。
> 输入：批次投递物 `system/env/meta/raw/batches/<date>/` → `raw/inbox/`（命令与停点见 `system/env/STAGES.md §3`）。
> **投递清单里的 `info_class` 是"机器初判"，可以错** ⇒ **不得据它决定读法**；**以本件 §二 的判据为准**，判错就写一句"**归类纠正**"。
> **两侧都算失败**：**A 面**——该找的没找（漏）；**B 面**——回执勾满了却答不出人话（空）。
> **本类材料不止一种**：**先看它属于哪一张法定表格（§二），再打开对应的分册，按那本册的读法走**。
> **禁止跨类套问句**（各分册开头已写明）：`8-K` 没有完整三表 · `10-Q` 没有审计意见与内控 · **`Form 4 / 13D·G` 不属本类**（归 `04-资金与持仓`）。

---

## 一、定位：它给的是**法定事实**——一手、可逐行复核

本类**只干一件事**：把**公司法定披露里的一手事实**挖出来，落到**估值模型**上。
**落点 = `system/env/meta/valuation-model.md` 上的格**；**篮子只是存放答案的地方**；**"为填格而找信息" = 判失败**。
**与相邻类的分界**：本类给**"是什么"**（多少、什么口径）；`02` 给**"公司怎么解释"**；`03` 给**"别人怎么算"**。

| 要拿的（人话） | 影响**哪一个**模型格 |
|---|---|
| 用户与参与度的**口径** | 规模在不在长、口径可不可比 |
| 变现的**量价两条** | 变现率靠"看的人更多"还是"每人更值钱" |
| **成本与折旧**的口径与假设 | 算力这台生产工具的经济寿命 |
| **资本开支与承诺**（含期限） | 未来 1–3 年的工具投入上限 |
| **资本配置**（回购 / 股本 / 稀释） | 每股的引擎是缩股还是增股 |
| **分部**与拖累项 | 亏损业务的斜率 |
| **承诺 · 或有 · 诉讼 · 监管** | 会不会变成可计量负债或结构性改动 |
| **控制权与内部人行为** | 谁在动、在什么价位 |

## 二、本类只收什么，以及这是哪一类（决定打开哪本分册）

**监管一手披露 = 发行人依法定义务向监管机构提交并公开的、关于本公司经营与财务的正式文件及其法定附件。**

**判据三条（三条同时成立才算本类）**：
1. **法定** —— 有法定表格与提交 / 公开义务（见下表）；
2. **一手** —— **发行人自己或监管机构发布的原文**（不是转述、点评、转载）；
3. **关于本公司的经营与财务事实** —— 含**口径与附注**（这才是本类的价值所在）。

**法定附件也算本类**（如业绩发布件的随附附件）；**看错类的代价**：拿电话会当法定披露（口径与措辞层级都不同）；拿媒体调查当一手。

### 2.1 先看是哪一类（先认痕迹，再看该打开哪本分册）

| 法定表格 | 认它的痕迹 | **别做的事**（别拿别类的问句来套） | **该读哪本分册** |
|---|---|---|---|
| **`10-K`** 年报 | `DocumentType=10-K`，`Focus=FY`，含 `Item 1–16` | **禁**把年报口径当季度口径 | `system/env/meta/prompts/01-型/10-K.md` |
| **`10-Q`** 季报 | `DocumentType=10-Q`，`Focus=Q1/Q2/Q3` | **禁**把"年初至今"当"本季"；**禁**套年报的审计意见与内控项 | `system/env/meta/prompts/01-型/10-Q.md` |
| **`8-K`（含业绩附件）** | `DocumentType=8-K`；业绩那条 = **`Item 2.02`** | **禁**套年报 / 季报的报表与附注项（**8-K 没有完整三表**） | `system/env/meta/prompts/01-型/8-K与EX-99.1.md` |
| **委托书**（`DEF 14A`） | `DocumentType=DEF 14A` | 它是**治理与薪酬的主源**；年报的 `Item 10–14` 常"**并入此处**" ⇒ 两份配对读 | `system/env/meta/prompts/01-型/委托书.md` |
| **招股书**（`S-1 / S-3`） | `DocumentType=S-1 / S-3`（含 `424B`） | 主战场是**风险增量与摊薄**，不是常规经营数据 | `system/env/meta/prompts/01-型/招股书.md` |

**一处必须记牢的归属（真源优先）**：**`Form 4` / `13D` / `13G` / `13F` 不属本类** ——
本类判据第三条是"**关于本公司的经营与财务事实**"，而它们讲的是"**谁在持股、谁在买卖**"，所以归 `04-资金与持仓`（分流真源 = `README.md §3.1.2`）。
因此本手册的归类表里**没有**"内部人申报"这一行；拿到这类件，就**记"归类纠正"并归 `04`**，**不要套本类的财报问句**。

**每一本分册都自成一体**：只拿到那一本也能干活（跨类只写一句"口径差异提醒"）。

### 2.2 不属于本类的怎么办（按信息类别分流）

**分流表真源 = `README.md §3.1.2`**；拿到不属于本类的材料，**仍按本件纪律读**（读全 · 留痕），
但**结论归到正确类别**，并在报告里写一句"**归类纠正**"。

## 三、这批材料怎么读

**① 派发**：逐件看它是哪一类（§2.1），再打开对应分册，**按那本册的"怎么读"一节走**（每一类的读法都不同，本件不设"通用读法"）。

**② 两条**跨类底线（只有这两条对本类所有类都成立）：

| 底线 | 含义 |
|---|---|
| **不许截断 / 抽样** | 不看"前 N 页"、不用摘要代替正文、不因太长跳过任何单元；**有理由的略读必须写理由**（如样板与程序条款） |
| **没读过的不许说"没有"** | 回执是下结论的**必要条件**；"**披露未含**"（具名缺口）与"**我没读到**"（载体 / 未在手）**必须分开写** |

**③"回执单元"是什么**：**结构化件 = 法定单元**（`Item` / `Part` / 附注 / 表项）；**自由格式件 = 自然段**。
具体单元集合**由各分册给出**（可数、可核）。

## 四、报告怎么写（**给人看**）

> **本系统对内产出对一家公司的认知，对外产出估值模型。**
> 带日期的催化剂清单、与市场价的对比、错误定价判断，**都是这张图的派生物** ⇒ **本报告不写它们**。

**报告开头先放情景卡**（这是什么材料、谁发的、什么时间、讲什么事、为什么值得看——五要素逐字见 `RUN-PARALLEL §2.2`），随后才是下面四节。

**报告骨架（六段，顺序固定；真源 = `RUN-PARALLEL.md` §2.3）**：

| 段 | 写什么 |
|---|---|
| **① 情景卡（定位）** | 这份是什么 + 谁发的 + 什么时间 + 讲什么事 + 为什么进这批（人话标题 + 括号内原始文件名） |
| **② 认知增量**（对内） | **一句人话结论** + 数字 + 口径 + 出处（出处写"**章节名**"，如"关键会计估计段""附注：承诺与或有"——**不写内部段号**）。**这一节禁表格** |
| **③ 缺格 / 缺篮 / 缺行** | 三类接不住的东西：格表没有对应行（缺格）、篮子装不下（缺篮）、应当拆行（缺行）。每类先一句判断标准再列 |
| **④ 答不上来的（具名缺口）** | 哪一格、**为什么**（披露未含 / 附件未在手 / 载体不可读）—— **不是"没有"** |
| **⑤ 要人看（红灯）** | 红灯一条 + 为什么我判不了（§五 第 5 条） |
| **⑥ 变更提案指针**（对外） | 表格：**格 / 现在（取值·档位）/ 改成 / 依据 / 确信度**。**"核过了、不用改"也要写**——不改也是结论 |

**三条写作硬规矩**：
1. 报告三铁律见 `RUN-PARALLEL §2.1`（逐字真源在彼，此处不复制）。
2. 输出表达六条纪律见 `RUN-PARALLEL §2.4`；本册特有：法定表格名是名字不是代号（如 `Item 1–16`），出处写章节名不写内部段号。

**"给人看"与"给机器看"分账**：

| 进**报告** | 只进 **`覆盖回执.csv`** |
|---|---|
| 答案（人话）· 数字 + 口径 + 章节名出处 · 具名缺口 · 要改的模型取值 · 红灯 | 单元编号 · 回执行 · **条数（应 / 已 / 未）** · 跳读理由 · 处理的机器码 |

一句话判据：**"这句是给人读报告用的，还是给机器对数用的？"** —— 后者**不进报告正文**。

**跨期与频次**：本环境**一批一跑** ⇒ **禁自己编造跨期对照**；需要比上期 / 上季的，报告写"**需跨批（交主控）**"。

## 五、回执 · 处理三类 · 自检

1. **回执（机器账）**：**只落 `覆盖回执.csv`**（含 `段/单元总数 / 已过数 / 跳读 + 理由` 与**应 / 已 / 未回执**三读数）；**未回执逐条列**。
2. **能填的进哪**：**能填 ⇒ 写进报告正文**（§四 的 ① ②）；**回执与统计 ⇒ 只进 `.csv`**。
3. **处理三类**：
   - **能填** ⇒ 写进报告 + 标档位；
   - **噪声**：两条**同时**成立。① 删掉它，模型任何一行都不变；② 它本身不是可观察 / 可计量的事实（形容词、无桥前瞻、二手转述、单季偶然项）。
     `drop_reason` 必须写"删掉不影响〔哪个判断〕"，不得只写"无价值"；
   - **缺格 / 缺篮子** ⇒ 它本身**可观察 / 可计量**（有日期、有物理量、能追到一手来源），只是**模型没有一行接得住**（⇒ 出**缺格报告**）或**篮子装不下**（⇒ 出**缺篮子报告**）—— **不得当噪声、不得硬塞**。
   本类最容易撞出前者：**契约 / 承诺 / 期限类事实**。
4. **漏报 ≠ 误判**（两个都判失败）：**漏报** = 该找的**根本没读到 / 没回执**；**误判** = 读了也回执了，却**把"缺格"当噪声丢掉**。
5. **红灯：见到必须上报**（各分册 §6 有各自的上报清单）。典型：**审计师变更 · 财报不可依赖（重述）· 内控重大缺陷 · 重大减值 · 重大网络安全事件 · 估计变更动了利润 · "一次性"常年出现 · 契约类事实而模型接不住**。
   红灯**不是结论**，是**上报信号**：写清"**在哪一段 / 哪一附注 / 多少 / 与什么比**"，判断留给主控。
6. **空样本如实**（`G-03`：判不了 ≠ 通过）：本类无材料，就报"**该类无源**"（**不得**用别类顶替）；有材料但读数全空，就报"**通道缺口**"；**未回执 > 0 ⇒ 逐条列出**，**不得**算成"本批无增量"。
7. **不得做的事**：
   - 禁自造分部 / 口径。
   - 禁把"披露没写"写成"不存在"。
   - 禁跨跳下结论（传导属催化剂侧）。
   - 禁为填格而找信息。
   - 禁把"缺格 / 缺篮子"当噪声丢掉。
   - 禁截断 / 抽样。
   - 禁不给回执就下"没有"的结论——没读过的段，无权说它没内容。
   - 禁跨类套问句。
   - 禁自造篮子名，也不得把没落地的篮子写成已落地的样子。篮子名必须逐字取自 `system/rules/baskets.yaml` 本类 `baskets`。

---

**本件最后一句，务必记住**：**先看是哪一类，再打开对应分册，按它的读法走完单元 → 每条问句都要有答案或具名缺口 → 回执只进 `.csv`，答案才进报告（给人看）。**
