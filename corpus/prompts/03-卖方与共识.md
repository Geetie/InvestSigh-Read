## §0.5 术语表（全文反复用到，但此前从未定义）


这一节把全文高频使用、但你此前可能没见过的词一次讲清——**先扫一眼，读到再回来查**。

| 词 | 在这里是什么意思 | 用错会怎样 |
|---|---|---|
| **格** | `valuation-model.md` 里的一行，共 9 个：用户与注意力 / 变现率 / 收入结构 / 成本与折旧 / 成本·人力 / 资本开支 / 资本配置 / 拖累项 / 或有负债（编号沿用设计稿 M-1 至 M-10，中间有跳号，原因见 aluation-model.md 表头说明） | 把"评级"当格、把"某个数"当格——格是**模型的科目**，不是观点也不是指标名 |
| **篮子** | 存放答案的容器（`baskets.yaml`），一格可以对应多个篮子；**篮子不是格** | 以为填了篮子就等于填了格，最后模型还是空的 |
| **档位 Ⅰ/Ⅱ/Ⅲ** | Ⅰ = 本地语料可逐行复核；Ⅱ = 二手、须标机构；Ⅲ = 未核待核 | 把 Ⅱ 当 Ⅰ 写进事实层，等于给二手观点背书 |
| **假设取值** | 他模型里的一个具体设定：某年收入增速 X%、毛利率 Y%、算力开支 Z 亿——**必须带期间与口径** | 只抄结论（目标价）不抄假设，等于什么都没拿到 |
| **预测修正** | 他这次把哪个假设从多少改到多少 | 只看新值不看改动，会把"一直这么想"误读成"刚转多" |
| **离散度** | 多家机构对同一指标预测的分布宽度（最高−最低、标准差） | 用均值代替分布，会把"分歧巨大"读成"高度一致" |
| **口径** | 同比/环比、GAAP/non-GAAP、分部/合并、季调/未季调——同一个数在不同口径下不可比 | 混口径相加，是最常见的"看起来对、其实错" |

**一条总规矩**：以上任何一个词，第一次在报告里出现时，**用一句人话带过**（例：「变现率（每用户广告收入 ÷ 人均 GDP）」），
不要假设读者已经知道它是什么——**"读者应该懂"是写作者最常犯的错**。


## §0 一页速查（先读这 25 行，再读下面）

**这一类干两件事**：

| 活 | 拿什么 | 落到哪 |
|---|---|---|
| **拆假设**（主活） | 他把收入/毛利/折旧/算力开支/税率/EPS 各设成多少、哪一年 | 逐行填进 `valuation-model.md` 的格，与我的数并排看差多少 |
| **看修正**（副活） | 改了哪一项、从多少改到多少、往哪个方向 | 判断分歧在收敛还是发散 |

**第一纪律**：**只抽数据与假设，评级与目标价一律弃**。评级、目标价、"买入理由"是他人的结论，**只作背景，不入事实层**。

**六个核心概念**：

1. **假设取值**：必须带期间与口径（FY26E 收入增速 18% vs 1Q26 同比 18% 是两件事）。
2. **预测修正**：比绝对值更有信息——从 15% 改到 18%，方向与幅度都要记。
3. **一致预期的分布**：看**离散度**，不是均值。均值告诉我"市场怎么看"，离散度告诉我"哪一格最不确定"。
4. **评级档位**：只用来量"卖方口径的一致性程度"，不是买卖建议，也不是事实。
5. **证据层级**：研报里的数是他算的；他引的公司披露才是一手——**转述要标转述**。
6. **模型格**：一条信息值不值得展开，只问"它改得动哪一格"。

**三对最容易混的**：评级 ≠ 目标价（一个是档位，一个是数）；覆盖 ≠ 推荐（有覆盖不代表有观点）；均值 ≠ 离散度（分歧藏在分布里）。

**只记三件事**：① 只抽数据与假设，评级不入事实层；② 改不动模型格的不展开；③ 逐段回执，跳读必须写理由。

**编号约定**：本书的断点号只在本类有效，别与 04/05/06/07 同号混用。


## 一、定位：本类给的是**别人怎么算** —— 用来找出**我这一项与市场差最多**

**本类的第一纪律（逐字，`全貌认知研究系统_三问诊断与重定义方案.md §6.3`）**：**"③ 类抽其数据与假设、弃其评级"**。
所以**评级 / 目标价 / "买入理由"是他人结论**，**只作背景，不得入事实层**；**它的数据与假设拆解才是本类的价值**。
**落点 = `system/env/meta/valuation-model.md` 上的格**；篮子只是存放答案的地方。**"为填格而找信息" = 判失败**。

**本类在系统里的位置（动手前先想清楚）**：
- 全貌认知研究系统研究的是**一家公司的本质**，从本质建立**估值模型**；**其他一切信息需求都从这份模型派生**。
- 本类材料只有一个去处：**拆出他的数据与假设，填进模型的格，供修正提案比较**。带日期的催化剂清单是**派生的附带品**；"错误定价"＝**市场价与估值模型的差额**，是系统赚钱的方式，**不是研究对象**——做这个对比的是催化剂系统，不是本类。
- 所以判一条信息值不值得提，只问一句：**它改得动模型哪一格**。改不动的，登记即可，不值得展开。

| 要拿的（人话） | 影响**哪一个**模型格 |
|---|---|
| 他的**关键假设取值**（收入增速 / 毛利 / 折旧 / 算力开支 / 税率 / 每股收益） | **逐行对照**：我这项与市场差多少、差在哪一年 |
| 他的**预测修正**（改了哪一项、从多少改到多少） | 分歧在收敛还是发散 |
| **一致预期的分布**（离散度，不是均值） | 哪一格最不确定 ⇒ **最该去一手源核** |
| **外部估算的物理量**（机架数 / 份额 / 单位算力成本） | 公司未披露口径的旁证（仍不是公司事实） |
| **评级档位分布**与投行关系占比 | 卖方口径的**一致性程度**（不是买卖建议） |

**本类与相邻类的分界**：本类全是**他人的判断**。**公司自己的话归 `02`，法定披露归 `01`，谁在动钱归 `04`，规则与约束归 `06`，市场在定价什么归 `07`**。

## 四、报告怎么写（**给人看**）

> **本系统对内产出对一家公司的认知，对外产出估值模型。**
> 带日期的催化剂清单、与市场价的对比、错误定价判断，**都是这张图的派生物** ⇒ **本报告不写它们**。

**报告骨架（六段，顺序固定；真源 = `RUN-PARALLEL.md` §2.3）**：

| 段 | 写什么 |
|---|---|
| **① 情景卡（定位）** | 这份是什么 + 谁发的 + 什么时间 + 为什么进这批（人话标题 + 括号内原始文件名，双写） |
| **② 认知增量**（对内） | **一句人话结论** + 数字 + 口径 + 出处（出处写"**机构名 + 报告名**"这种**能追的位置**，不写内部段号）。**这一节禁表格**——它是讲"新知道了什么"，不是数据陈列；数据密集时选 3 个最重要的数写进正文，其余进附录 |
| **③ 缺格 / 缺篮 / 缺行** | 三类接不住的东西：格表没有对应行（缺格）、篮子装不下（缺篮）、应当拆行（缺行）。每类**先一句判断标准**再列，且必须写清"为什么不能硬塞" |
| **④ 答不上来的（具名缺口）** | 哪一格、**为什么**（他没给 / 材料里没有 / 载体不可读）—— **不是"没有"** |
| **⑤ 要人看（红灯）** | 红灯一条 + 为什么我判不了（§五 第 5 条） |
| **⑥ 变更提案指针**（对外） | 表格：**格 / 现在（取值·档位）/ 改成 / 依据 / 确信度**。**"核过了、不用改"也要写** |

**先写观点，再写清单（这条最重要，实测最容易违反）**：

报告不是字典。**每一节开头先用 2–3 句人话把结论与因果讲完**，再跟数字与表格。例：

> Meta 一季度广告收入同比增长 33%，其中展示量贡献 19 个点、单价贡献 12 个点，
> 两者相乘正好还原 33%——说明这一轮增长**不是单纯放量，也不是单纯提价，而是量价齐升**，
> 且提价那部分更依赖 AI 排序带来的转化率提升。

**只有清单、没有观点段的节，算没写完**：读者要自己把三条 bullet 拼成一句结论，就等于你没给结论。
表格可以留（它是证据），但表格**前面必须有一段话说明"这张表回答什么问题"**。

**数字必须带约束条件（实测漏项）**：

凡是"供给 / 产能 / 需求"类数字，**总量与可售（可用）部分要一起给**。
实测漏例：报告写了「TPU 总供给 400–450 万颗、60–70% 内部自用」，却漏了原文同段的
「**对外可售仅 100–150 万颗**」——而后者才是客户真正能拿到的量，前者只说明"谷歌很大"。

凡是**推算出来的单位或量级**，把推断过程写进算式与正文（例：原文写「7,133 亿元」，
按字面读会小于 Google 单家的六成 ⇒ 判为"亿美元"，推断过程要留痕，不许悄悄改单位）。

**跨件引用必须写出处**：

一个数字若来自本批**另一件**材料，写「据第 N 件（件名）」。
实测错例：把第五件的「OpenAI 200 美元档烧 4,000 美元」写进第四件 Muse 那一节，
读者会以为这是 Muse 件给的对照。

**目录行不是丢段**：

带时间戳或小节索引的行（如 `39:00–40:17｜把实验循环从"一周"压到"一小时"`）是**导航**，
正文常在数万字符之后。判"抽取丢段"之前，必须**用该行里的关键词全文搜一遍**；
搜到就只有"索引与正文分离"，不是载体损失。

**三条写作硬规矩**：
1. 报告三铁律见 `RUN-PARALLEL §2.1`（逐字真源在彼，此处不复制）。
2. 输出表达六条纪律见 `RUN-PARALLEL §2.4`；本册特有：他人观点一律写"某机构认为 / 据〔机构〕"，他人结论档位标 Ⅱ。

**本类特有的一条**：**所有他人观点一律写"某机构认为 / 据〔机构〕"**，**不得写成事实句**，**不得把预测写成已发生**（`撰写规范 §9.6`）；**档位一律 Ⅱ**（他人结论），但其**数据若指向 `01` / `02` 的一手来源，该条可为 Ⅰ**。

**"给人看"与"给机器看"分账**：

| 进**报告** | 只进 **`覆盖回执.csv`** |
|---|---|
| 答案（人话）· 数字 + 口径 + 机构与报告名 · 具名缺口 · 要改的模型取值 · 红灯 | 段号 · 回执行 · **条数（应 / 已 / 未）** · 跳读理由 · 处理的机器码 |

**跨期与频次**：本环境**一批一跑** ⇒ **禁自己编造跨期对照**（"预测修正""离散度收敛"这类**跨期问句**），报告写"**需跨批（交主控）**"。

---

## 五、回执 · 处理三类 · 自检


这一节讲两件事：**哪些算读完（回执）**、**见到什么必须喊人**；机器账与人话的分界线在这里。

1. **回执（机器账）**：**只落 `覆盖回执.csv`**（`段总数 / 已过数 / 跳读 + 理由`，与**应 / 已 / 未回执**三读数）；**未回执逐条列**。
2. **能填的进哪**：**能填的写进报告正文**；**回执与统计只进 `.csv`**。
3. **处理三类**：
   - **能填** ⇒ 写进报告 + 标 **Ⅱ**（写"某机构认为"）；
   - **噪声**：两条**同时**成立。① 删掉它，模型任何一行都不变；② 它本身不是可观察 / 可计量的事实（"买入理由：AI 长期趋势"这类口号）。
     `drop_reason` 必须写"删掉不影响〔哪个判断〕"，不得只写"无价值"；
   - **缺格 / 缺篮子** ⇒ 本身**可观察 / 可计量**（有数字、有出处、能追到来源），只是**模型没有一行接得住**（出**缺格报告**）或**篮子装不下**（出**缺篮子报告**）—— **不得当噪声、不得硬塞**。
4. **漏报 ≠ 误判**：**漏报** = 该找的没读到 / 没回执；**误判** = 把"缺格 / 缺篮子"当噪声丢掉。
5. **红灯：见到必须上报**（各分册 §6 有各自的上报清单）：
   ① **同一事实、两类方向相反**（投行 vs 独立 / 媒体）⇒ 出"**对立来源对照**"；
   ② **偏离共识 > 5% 而无书面辩护**；
   ③ **只有结论、没有数据与假设** ⇒ 标"**无法核**"上报；
   ④ **同一机构预测被两处转述而数字不一致** ⇒ 口径冲突上报；
   ⑤ **专家纪要触及重大非公开信息**（或与公开披露冲突）⇒ 上报并**以 `01` / `02` 为准**；
   ⑥ **媒体件被当"已发生"引用**（回溯不到一手）⇒ 上报。
6. **空样本如实**（`G-03`：判不了 ≠ 通过）：本类无材料，就报"**该类无源**"（**不得**用别类顶替）；**只有评级、抽不出数据与假设**，就报"**本批无可用数据与假设**"，**不得**用评级凑产出；**未回执 > 0 ⇒ 逐条列出**。
7. **不得做的事**：
   - 禁把他人结论写成事实句。
   - 禁把同一原文的转载当独立来源。
   - 禁把预测当已发生。
   - 禁把"评级变动"当成"事实变了"（那是观点变了）。
   - 禁自造篮子名（必须逐字取自 `system/rules/baskets.yaml` 本类 `baskets`）。
   - 禁为填格而找信息。
   - 禁不给回执就下"没有"的结论。
   - 禁跨类套问句（§0）。
   - 禁在本类做传导推演（传导属催化剂侧）。

---

**本件最后一句，务必记住**：**先看是哪一类，再打开对应分册，全读（无骨架）→ 抽数据与假设、弃其评级 → 每条问句都要有答案或具名缺口 → 回执只进 `.csv`，答案才进报告（给人看）。**

## 六、断点（本类专用编号）


这一节列**七种「写不下去」的情形**及各自处置——它们不是失败，是要如实写缺口。

| 断点 | 断在哪 | 怎么处理 |
|---|---|---|
| 断一 | 通篇只有评级与目标价，没有任何假设取值 | 只登记"有这份观点"，不入模型格 |
| 断二 | 有假设但缺期间或口径（"增长 20%" 不知是同比还是环比） | 缺口径 ⇒ 只登记，禁填格 |
| 断三 | 把评级/目标价写进事实层 | 退回，移到背景栏 |
| 断四 | 用均值代替离散度 | 补分布；拿不到就写"离散度无源" |
| 断五 | 把他引用的公司数当他的测算 | 标"转述，未核原文" |
| 断六 | 一条信息改不动任何模型格 | 登记即可，不展开 |
| 断七 | 同一件里两套口径混用（分部 vs 合并、GAAP vs non-GAAP） | 分开写，禁合并成一个数 |

**最容易自欺的三处**：断三（评级当事实）、断四（均值当共识）、断七（口径混用）。

## 七、加载索引


这一节解决一个具体问题：**手上只有一份材料，该翻哪一本、翻到哪一节**。

用法自上而下——先看「拿到什么」，再看「必读」，最后才按需打开分册。**不要从第一本读起**：五本读完还没开始干活，是本类最常见的浪费。

第三列写「按需」，意思是**只有前两列指向它时才打开**；表里没列的材料形态，按最接近的那一类走，并在报告里写明「按 X 类读」。

| 拿到什么 | 必读 | 按需打开 |
|---|---|---|
| 投行研报（有评级/目标价/测算表） | §二 2.1 认型 + §三 读法 | `03-型/投行研报.md` |
| 独立研究（无评级、有自建模型或长文论证） | 同上 | `03-型/独立研究.md` |
| 媒体分析、新闻转述 | 同上 | `03-型/媒体分析.md` |
