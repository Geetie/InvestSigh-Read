## 2. 模式 A：只读、不写真源

模式 A 明文：**只读全仓；可写仅 `runs/<批>/` 白名单 7 件；不写真源（`facts/` / `derived/`），永不执行编译（`research_ingest`）**。

### 2.1 三铁律（真源 = 本节；各册出现的副本一律改一行指针回本节）

① **正文 = 人话解读 + 数字四出门 + 出处**；「原文一字不动 + 中文译文逐句」**降级为报告末尾附录「原文与译文」节**（标注"要核对原文才看这段"）——不核对原文的人只读正文就懂，要核对原文的人才翻附录；② **不给读者看的不写**（段号、回执计数等机器账只落 `覆盖回执.csv`）；③ **禁裸代号**——写实际含义（"广告变现率""算力的折旧"），编号最多放括号里。

### 2.3 报告骨架展开：情景卡与材料页（照构思 v2 一.1 / 一.6 逐字）

骨架六段，顺序固定：**情景卡（定位）→ 认知增量 → 缺格 / 缺篮 / 缺行 → 缺口 → 红灯 → 变更提案指针**。

**情景卡五要素**（报告开头必有）：

1. 这是什么材料——**人话标题 +（原始文件名）双写**；
2. 谁发的 / 谁写的；
3. 什么时间；
4. 讲什么事；
5. 为什么值得看。

此后每个结论段首句锚定"本段谈这份材料的哪一部分"。

坏例 / 好例（真实材料对照，Q13）：

- **坏例**：照抄 `exhibit991`（裸文件名，没读过原文的人不知道这是什么）；
- **好例**：「2025Q3 业绩公告附件（官方表格）」（人话说清这是什么；原始文件名在括注里备查）。

**材料页三段式**：

- **封面页**：这份是什么 + 谁何时 + 为什么进这批；
- **图表页**：这图 / 表讲什么 + 关键读数 + 所以什么；
- **无实体页**：为什么没有 + 留下什么线索。

> **这三段是写作结构，不是正文小标题。** 正文里要么写成**连贯段落**，要么用**人话小标题**——
> 「这份材料是什么 / 它的图表讲了什么 / 它缺了什么」。
> **禁止「第 N 件·封面页」「第 2 件·无实体页」这类压缩写法**：那是写作者自己的结构标签，
> 读者看到「件·页」不知道它指什么（实测已发生）。同理，`材料页` 这个词也不要出现在正文标题里。

每档模板句（照填，禁空着、禁"待补 / 占位"字样）：

- 封面页：「这份是〔谁〕在〔何时〕发的〔什么材料〕（原文件名：〔x〕）；进本批是因为〔分流判据〕。」例：「这份是公司在 2025 年 11 月发的 2025Q3 业绩公告附件（官方表格）（原文件名：exhibit991）；进本批因为它是法定披露附件，按 01 类分流。」
- 图表页：「这页〔图 / 表〕讲〔主题〕；关键读数是〔量名 · 数值 · 期间 · 口径〕；所以〔人话结论〕。」
- 无实体页：「本件没有〔应有的实体〕，因为〔原因〕；留下的线索是〔线索〕，已登记缺口上报。」

### 2.4 写给没读过原文的人——六条纪律（真源 = 本节；构思 v2 一.1~一.6 逐字）

1. **每段自带情景**：报告开头必有**情景卡**五要素（模板见 §2.3）。此后每个结论段首句锚定"本段谈这份材料的哪一部分"。
2. **认知增量先行**：先说"这份材料让人**新**知道什么"，再摆证据。只复述常识背景 = 空（B 面失败）。
3. **术语首现即人话解释**：术语 / 黑话 / 简称第一次出现时用一句通俗话解释（通俗但不啰嗦）；同报告后文可直用术语。
4. **禁裸编号**：给人看的正文不得出现 M-x、Q-ID、段号、内部编码。**豁免正名单**（逐条给理由，照 `02-业绩与沟通.md:144` 范式）：法定 Item / Part / 附注名——豁免，因为它是法定名字不是内部代号（`01-监管一手披露.md:92` 同口径）；材料自身的日期与数字——豁免，因为必带量纲与出处（纪律 5）；「本次批次」——豁免，因为块内已定义。禁设"报告内部引用"豁免（那是开口袋）。
5. **数字必带四出门 + 所以什么**：量名、数值、期间、口径（`撰写规范 §1.8`）；每个数字后跟人话结论——数字本身不是答案。
6. **材料页情景化**：封面页 / 图表页 / 无实体页三段式，每档照 §2.3 模板句写；坏例 = 照抄 `exhibit991`，好例 =「2025Q3 业绩公告附件（官方表格）」。

**Q14 跨批条款**：情景卡"变化"维度只写本批内可见信息；跨批比较一律写「**需跨批（交主控）**」，禁自编跨期对照（`02-业绩与沟通.md:85` 同口径）。

### 2.4.1 单条答案的粒度与可读性（条目级；§2.4 管整份报告，本节管一格答案）

> **为什么单列一节**：§2.4 是报告级纪律，管不到阅读器里一格一格的答案。
> 实测后果——同一批材料里，「未来三个月是否寻求投行费：未见。」（**两个字交差**）与
> 「实益持股 ≥1%：未见（仅有印度子公司持债务证券 1% 的通用声明，主体与标的均不符）」（**能核**）并排出现。
> 两者都「没错」，但前者读者拿不到任何信息。**本节就是判这种差别的。**

#### 一、粒度：一条答案必须回答到的三层

按题目性质选**最深的那层**，能到第三层就不要停在第一层：

| 层 | 内容 | 够不够 |
|---|---|---|
| ① 结论 | 「有 / 无 / 未见 / 无法核验」 | **只有这层 = 不合格**（除非题目本身就是是非题且无需展开） |
| ② 内容 | **谁 · 何时 · 什么**（机构名 / 期间 / 证券类别 / 服务类型 / 金额比例）+ 原文怎么说的 | 这是**及格线** |
| ③ 判断 | 为什么是「有」而不是「部分有」；为什么「未见」不等于「无」；这条对估值/判断意味着什么 | **拿高分靠这层** |

**「未见」的专条规矩**：必须三段齐全 —— ① 未见；② **查了哪里**（哪一页/哪一节找不到）；
③ **为何某条相近声明不能算本项**。只写「未见。」两个字 = 与「没查」无法区分 = 不合格。

坏 → 好（实测对照，同一题）：

> ❌ `4. 未来三个月是否寻求投行费：未见。`
>
> ✅ `未来 3 个月是否寻求投行费：未见。附录 A-1 只写「近 12 个月已收取」，全文没有 next 3 months / intends to seek 段，未来三个月的意图未披露。`

> ❌ `7. 实益持股 ≥1%：未见。`
>
> ✅ `实益持有该类普通股 ≥1%：未见。唯一相近的是一句通用声明：Citigroup Global Markets India Private Limited 及/或关联方「可能不时持有标的债务证券 1% 或以上」。主体是印度子公司、标的是债务证券，与本项要确认的「母公司持 Meta 普通股 ≥1%」主体与标的均不符，故判未见。`

#### 二、可读性：讲人话，但不废话

1. **一格只讲一件事。** 题目问什么就答什么；顺带发现的事实写进相邻的题或「红灯」，不塞进这一格。
2. **一句一个意思，句号密度 ≥ 逗号密度的 1/4。** 实测有一格 11 个逗号只有 1 个句号 —— 那不是"信息量大"，
   是**没断句**。长句拆开；每句先给主语与结论，再给限定。
3. **数字后面必须跟"所以什么"。** 「资本开支 1,421 亿」不是答案；「资本开支 1,421 亿、同比 +104%，
   说明 2027 的折旧压力会先于收入兑现」才是。§2.4 纪律 5 的条目级版本。
4. **不写"我已经查过了"这类自述。** 「经仔细核对全文」「已逐项检查」——删掉，直接给结论与依据。
   查证的努力体现在**引用**里，不体现在形容词里。
5. **不用黑话缩写，首次出现给一句人话。** TCO → 「总拥有成本（含电、机房、运维）」；DAP → 「日活用户」。
6. **不改原文语气。** 引原文就用引号原样引（含 `\$`、`~` 这类符号），自己的话与原文的话必须一眼分得开。
7. **没有的内容不编。** 材料没写的，写「材料未给出此项」；**不许**用行业常识补全，**不许**说"一般来说"。
8. **`未见` 与 `无` 必须分开。** 「未见」= 我没找到（可能是载体问题）；「无」= 明确否认。
   把「未见」写成「无」是给材料栽赃。

#### 三、三条红线（犯了这一格作废）

| 红线 | 为什么 |
|---|---|
| 只写结论不写具体内容（「有」「在」「未见。」） | 读者拿不到任何可核信息，等于没答 |
| 「未见」不写查了哪里 | 与「没查」无法区分；下游会把缺口当成"材料声明无冲突" |
| 一格塞进多个题目的内容 | 阅读器是按题分格的，串题会让矩阵错位 |

### 2.4.2 有图必读图（硬纪律，不读图的答案视为未完成）

> 为什么必须单列：**研报的核心信息大量只存在于图表里**——估计表、市场份额图、
> 供需缺口图、目标价走势图、评级分布表。只读文字会漏掉最有价值的部分，
> 而且会写出**假缺口**（「材料未给出资本开支估计」——其实图里就有）。

#### 一、图在哪、怎么读

每份材料的图与它的文本**在同一个目录**：

```
corpus/materials/<材料 id>/
    content.md                 ← 全文，**图片已按阅读顺序内联**（`![001_p012_00.jpg](figures/…)`）
    figures/001_p012_00.jpg    ← 文件名 = 阅读序_页_页内序
    pages.json                 ← 每页的 text + 该页的 figures（带 order）
```

- **`content.md` 是首选**：图片就嵌在它对应的段落位置，按顺序读一遍即可，不会漏图。
- `pages.json` 的 `pages[].figures[]` 给出该页的图及其 `order`，用于精确引用。
- 文件名 `001_p012_00.jpg` = 全书第 1 张 / 第 12 页 / 页内第 0 张 ⇒ **按文件名排序就是阅读顺序**。

#### 二、什么时候必须看图

| 情形 | 必须做什么 |
|---|---|
| 题目问**数值假设**（收入增速、毛利率、资本开支、税率、股数） | 估计表多半是图。**先看图**，再看正文 |
| 题目问**情景 / 目标价 / 倍数** | 估值表、Risk-Reward 图里才有三档数字 |
| 题目问**评级分布 / 占比 / 观测时点** | 那是饼图或表格，正文常只写一句 |
| 题目问**走势图 / 评级历史** | 图本身就是答案 |
| 正文写「见下图」「如下表」「详见 Exhibit N」 | 那句话是**指针**，必须去读被指的东西 |
| 你想写「材料未给出此项」 | **先确认图里没有**。没看图就写「未给出」= 假缺口 |

#### 三、图的依据怎么登记

图**不能单独当文字依据**——依据区要求逐字原文。两种合法写法：

1. **图里有可抄的文字**（表格、标题、坐标标签）→ 抄该文字，标该页 `p.N`。
   例：`- p.3｜BULL Assumptions: 2027E Revenue Growth ~22%`
2. **图是纯图像**（走势图、照片）→ 答案正文里写「见 p.N 的图（第 k 张）」，
   依据区登该页的**图题/图注原文**；若连图注都没有，**答案里明确写「判断依据为该页图表，无文字可引」**，
   并在依据区留空 —— 这是**允许的唯一例外**，因为图确实没有文字。

**禁止**：把图里的数字"读出来"当逐字原文抄（OCR 会错，见 `MinerU用法调研 §5`）。
数字要引，必须是从**文本层**能逐字核到的。

#### 四、一句话判据

> **一份材料有几张图，你就要都能说出它们各自是什么、在第几页。**
> 说不出来 = 没读完这份材料。

### 2.5 停点 vs 内容级断点（一句）

**停点 = 命令 / 守卫非零退出；内容级断点**（如 06 的「非催化剂」/ 断链降级登记）**按分册写缺口，不算失败，不得被误读成停**（`测试流程与Instruction_构思v2.md:30`）。
