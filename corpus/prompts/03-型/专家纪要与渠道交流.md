# `03` · **专家纪要与渠道交流** —— 这一类怎么读

> 本件是 `system/env/meta/prompts/03-卖方与共识.md` 的**分册**：主件说**这是哪一类**，本件说**怎么读、必须过哪些项、问什么、有哪些坑、见到什么要上报**。
> **边界**（本册可能被单独交付，故自带）：**可读＝仓库根以下全部（只读）**；**可写＝仅 `output/<标的>/<材料 id>/`**；其余禁写（`README §3.1.1`）。
> **本册自包含**：跨类**只写一句"口径差异提醒"**，不引用别的册。
> **落点 = `system/env/meta/valuation-model.md` 上的格**；篮子只是存放答案的地方；档位口径见 `system/reports/撰写规范.md §7.5`。
> 输出表达六条纪律见 `RUN-PARALLEL §2.4`；本册特有：专家不在法定披露链上，引述写"据某专家（经第三方整理）"。
> **本册第一纪律**：**它是"访谈的转述"，不是公司口径** —— 专家**不在法定披露链上**，与公司披露冲突时**以公司披露（法定 / 公司原话）为准**。

---

> **输入**：专家访谈、渠道调研、电话会纪要（含无署名的第三方整理稿）。
> **前置**：只需知道——① 这类材料离业务最近、也最不可核；② 经过「受访人→整理者→你」三重转手；③ 与公司披露冲突时以公司披露为准。不需要懂行业黑话，需要时会就地解释。
> **输出**：按「谁在什么时点说了什么」记录；能与其他来源交叉的才进模型，其余作旁证或红灯上报。
> **输出格式 = 本册模板** `corpus/templates/03-专家纪要与渠道交流.md`：抄一份到 `output/<标的>/<材料 id>/material.md` 再填；**采不到的栏目整节删掉，不呈现空项**（模板由 `system/scripts/env/gen_templates.py` 从本册生成，勿手改模板）。

## 读前 30 秒（这段是观点，不是清单）

专家纪要与渠道交流，是**离业务最近、也最不可核**的一类材料。
值钱在于颗粒度：单用户成本、每卡每小时的租价、某个项目在内部排第几——这些公开披露里永远不会有。
风险也在这里：这些恰恰可能是**未公开信息**，而且经过"受访人 → 整理者 → 你读到的文字"三重转手，每转一手都可能失真。
所以本册的规矩是：**只记"谁在什么时点说了什么"，不替它背书**；与公司披露冲突时，一律以公司披露为准。
**最容易犯的错是拿它当"内部真相"**：它给的是视角，不是事实；能进模型的只有"可与其他来源交叉"的那部分。

## 0. 它是什么

**本册在系统里的位置**：从散落的问答里，**只捞改得动估值模型某一格的说法**（算力、成本、产品、竞争、组织），供修正提案比较。催化剂清单是派生的附带品；错误定价＝市场价与模型的差额，对比由催化剂系统做，不是本类。

**认它的痕迹**：专家电话会 / 渠道访谈 **纪要**（前员工 · 现员工 · 渠道商 · 客户 · 供应链）；问答体；常标"专家"、"交流"、"调研"。

**别认错成谁**：
- **公司电话会**：主语是公司自己、有管理层署名 ⇒ 那属 `02`，不是本册。
- **媒体访谈稿**：署名是媒体、以叙事体发表 ⇒ 归媒体分析；本册是**第三方整理的问答体**。
- **研报里的专家观点**：那只是研报的一节，整体仍归投行研报册。

**本环境实有形态（4 份）**：均为第三方整理的**访谈问答体**（"主持人：…受访人：…"），主题集中在模型布局与算力供需。每份都要做"三重转述"标记，并逐条排查"未公开经营事实"的措辞。

**这些别问它**：

| 别问 | 为什么问了也没用 |
|---|---|
| 把专家的话当**公司口径** | 专家**不是公司**；那是**个人说法** |
| 套"卖方研报"的法定披露要素（评级分布 / 冲突披露） | 它**没有法定要素** ⇒ 问了必然"未见"（**假缺口**） |
| 把**单点访谈**当行业共识 | 一家之言 ⇒ 至多是"**一个观察**" |

**"三重转述"要记牢**：**专家本人的看法** → **整理者记录的纪要** → **你读到的文字**。
所以**三者都可能失真**；引用时**只能写"据〔机构〕整理的专家交流纪要"**，**不得**写"公司表示"。

## 1. 怎么读

**读法的依据（不是自己定的规矩）**：

- **每一段都要有交代**。读了、有理由的略读、或者对本文不适用，都写明。（依据：`撰写规范 §1.9`；守卫 `system/scripts/checks/material_spans_guard.py`）
- **抄下来的必须有数字**。量名、数值、时点。**在这类件里，"什么时候说的"本身就是口径**。实在没有数，就按"装不进篮子"写理由。（依据：`撰写规范 §1.8`）
- **数字分级 ＋ 两条数据纪律**。Ⅰ 可逐行复核，Ⅱ 二手带链接，Ⅲ 未核。这类件一律从 Ⅱ 算起（转述）。同一个数字要有两个以上独立来源，偏差超过 2% 就要报警。自定义口径必须建定义卡。（依据：`撰写规范 §7.5`）
- **什么值得报 ＝ 定量 ＋ 定性**。涉及"未公开的经营事实"的措辞，本身就是定性重大项。（依据：SEC `SAB 99`）

所以：落库的单位是**段**——每段有决定，段的并集等于全文。

**怎么读：带着问题去找信息（信息散，禁顺读）**：
- **先拿问题清单**：从估值模型拿本批要核的问题（本环境常考：算力供需与价格、自建 vs 租用、产品节奏、竞争位次、组织与人才）。清单没列的，不主动收集。
- **版面是时间戳分节**（"00:28–04:04｜开场…"）：把时间戳当目录，**按问题词扫节**。命中问题的节逐句读；没命中的节**略读并写理由**。
- **文首先核四件事**：谁在说、何时说的、他什么身份（前员工 / 现员工 / 渠道）、谁整理的——这是"三重转述"的第一环。
- **每个问题都要有交代**：找到了，就引原话并标三重转述；没找到，就写"本纪要未谈及"。**不得**拿别的问题的内容凑。
- **可以停的条件**：问题清单**每一条都有交代**；"未公开经营事实"级别的说法逐条列出并上报。

**可以略读的**：与本公司无关的泛泛行业背景（仍要写理由）。

## 3. 必须过的项（穷举）

### 3.1 身份与来源（先证"能不能引用"）

| # | 要件 | 拿到什么算过 | 常见坑 |
|---|---|---|---|
| 1 | **访谈对象**（身份 / 层级 / 所属） | 明确：**前员工 / 现员工 / 渠道商 / 客户 / 匿名** | 不写身份 ⇒ **不可追** |
| 2 | **与公司的关系** | **是否现任员工**（这一项决定风险等级） | 忽略"现任"这一条 |
| 3 | **访谈日期** | 日期（与财报 / 事件的先后） | 拿旧访谈当现状 |
| 4 | **谁整理 / 谁发布** | 机构名（可追）＋ 是否注明"据" | 只写"专家交流"（**不可追**） |
| 5 | **原话还是转述** | 标"**逐字问答**"或"**整理者概述**" | 把整理者的概括当专家原话 |

### 3.2 未公开信息（MNPI）嫌疑 —— **本册独有的必过项**

| 项 | 判据 |
|---|---|
| **是否触及未公开的重大经营信息** | 逐条标：**涉及 / 可能涉及 / 不涉及**（例：未公布的产能 · 未公布的合同 · 未公布的组织调整 · 尚未披露的数字） |
| **是否与已披露内容冲突** | 冲突 ⇒ 记"**与法定披露不一致**"，**以披露为准**，并上报 |
| **是否涉及选择性披露** | 若信息来自**公司内部人员**且**未公开** ⇒ **上报**（这是合规风险，不是普通缺口） |

**处置口径**：**不得把它当"事实"写进报告**；写"**据〔机构〕整理的专家交流纪要（〔日期〕），专家称……**"，并标注**未公开嫌疑**。

### 3.3 可计量的说法（本册值钱的一面）

| 项 | 拿到什么算过 | 常见坑 |
|---|---|---|
| **单位经济 / 成本 / 产能等数字** | 值 ＋ 单位 ＋ 时点 ＋ **是"专家估计"还是"公司内部数据"** | 把"专家估计"写成本公司事实 |
| **量化说法与公开披露的关系** | 一致 / 不一致 / **无法对照** | 不与公开披露对照 |

## 5. 特有的坑（只写这类件才有的）


这一节列**只有这类材料才会踩的坑**——踩了不会报错，但结论会错。

1. **把专家的话当公司口径** ⇒ 写"**据〔机构〕整理的专家交流纪要**"，**不得**写"公司表示"。
2. **未公开信息当普通事实**：这类信息价值最高、风险也最高。**必须标嫌疑并上报**，不得入事实层。
3. **把整理者的概括当专家原话** ⇒ 体例要判（逐字 / 概述）。
4. **单点访谈当行业共识** ⇒ 一家之言至多为"一个观察"。
5. **匿名 ＋ 无日期**：不可追，只能当"**无法核**"处理。
6. **访谈早于最近披露**：内容可能已过期，必须标时点对比。
7. **现任员工 ＋ 未公开数字** ⇒ **合规风险**，不是"信息优势"。

## 6. 红灯：见到必须上报


这一节列**见到就必须停下来喊人**的信号——不要自己裁，写清在哪、多少、和什么比。

| 红灯 | 判据 |
|---|---|
| **未公开信息嫌疑** | 涉及未公布数字 / 合同 / 产能 / 组织 ⇒ 上报 |
| **现任员工提供内部信息** | 身份是现员工 ＋ 内容未公开 ⇒ 上报 |
| **与法定披露冲突** | 说法与已披露不一致 ⇒ 上报（**以披露为准**） |
| **不可追** | 匿名 / 无日期 / 无整理方 ⇒ 上报并标"无法核" |
| **体例不明** | 无法区分逐字与概述 ⇒ 降级处理 |
| **疑似转述二手** | 纪要说"据某研报" ⇒ 回溯到那份来源，标二手 |
| **时点过期** | 访谈早于最近一次披露而内容被当现状 ⇒ 上报 |

红灯**不是结论**，是**上报信号**：写清"**谁说的 / 哪天 / 说了什么 / 与什么冲突**"。

## 7. 跨类照应（只写"口径差异提醒"，**不引用别的册**）


这一节只写**与其他类的口径差异提醒**：一句带过，不展开别类的判读。

| 提醒 | 内容 |
|---|---|
| **优先级铁律** | **法定披露 / 公司原话 > 专家说法**：冲突时**以前者为准**，专家说法降为"**旁证**" |
| **档位** | 这类件**一律 Ⅱ 起**；只有其内容**明确指向一手来源**时，该条才可为 **Ⅰ** |
| **与"独立研究"的差别在证据形态** | 独立研究给**测算**，这类件给**访谈** ⇒ **不能互相替代**（一个是算出来的，一个是说出来的） |
| **时效** | 访谈是**一次性快照** ⇒ 引用必须带日期；跨期比较**需跨批（交主控）** |
| **它不产出我方结论** | 只产"**谁在什么时点说了什么、可不可核、有没有冲突**" |
