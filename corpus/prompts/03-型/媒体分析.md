# `03` · **媒体分析**（记者调查与报道）—— 这一类怎么读

> 本件是 `system/env/meta/prompts/03-卖方与共识.md` 的**分册**：主件说**这是哪一类**，本件说**怎么读、必须过哪些项、问什么、有哪些坑、见到什么要上报**。
> **边界**（本册可能被单独交付，故自带）：**可读＝仓库根以下全部（只读）**；**可写＝仅 `output/<标的>/<材料 id>/`**；其余禁写（`README §3.1.1`）。
> **本册自包含**：跨类**只写一句"口径差异提醒"**，不引用别的册。
> **落点 = `system/env/meta/valuation-model.md` 上的格**；篮子只是存放答案的地方；档位口径见 `system/reports/撰写规范.md §7.5`。
> **本册第一纪律（真源逐字，`README.md §3.1.2`）**：
> **媒体件不构成独立信源 ⇒ 一律归本册这一类（二手）；一律标 `secondary_tertiary` ＋ 须回溯一手；不得当"已发生"用。**
> 还有一条：**媒体题材若是"规则 / 监管" ⇒ 不算 `06`** —— **生效依据只认官方原文**，本类**只登记它转述了什么**。

---

> **输入**：媒体、自媒体、财经快讯对某家公司或某个事件的转述。
> **前置**：只需知道——① 媒体件是二手，它说「有人说了什么」，不说「这事是真的」；② 它的价值是时效与线索；③ 形容词（重磅/颠覆/千亿级）一律不抄。
> **输出**：待核线索清单（谁、何时、说了什么、去哪里核），不进可入格的数。
> **输出格式 = 本册模板** `corpus/templates/03-媒体分析.md`：抄一份到 `output/<标的>/<材料 id>/material.md` 再填；**采不到的栏目整节删掉，不呈现空项**（模板由 `system/scripts/env/gen_templates.py` 从本册生成，勿手改模板）。

## 读前 30 秒（这段是观点，不是清单）

媒体件是**二手转述**：它告诉你"有人说了什么"，不告诉你"这事是真的"。
它唯一的价值是**时效与线索**——某家公司要做什么、某个人在什么场合讲了什么，往往先出现在媒体上。
所以读它只做三件事：**记下谁在什么时间说了什么、标清这是转述、把它当成"去找一手源"的线索**。
**最容易犯的错是把媒体的形容词当事实**："重磅""颠覆""千亿级"这类词一律不抄；数字要追到原始出处（公司公告、监管文件、当事方原话）。
本册产出的是**待核线索**，不是可入格的数。

## 0. 它是什么

**本册在系统里的位置**：媒体报道只登记**它转述了什么**，并**回溯一手**；能改得动估值模型某一格的才展开。催化剂清单是派生的附带品；错误定价＝市场价与模型的差额，对比由催化剂系统做，不是本类。

**认它的痕迹**：媒体名 / 记者署名 / 新闻或调查报道体（含**转载**、含通讯社稿、含专栏）。

**别认错成谁**：
- **独立研究**：署名是**研究者或研究机构**（SemiAnalysis、Stratechery 这类），归独立研究；署名是**媒体或记者**，归本册。
- **专家纪要**：问答体、第三方整理 ⇒ 归专家纪要册；本册是叙事体报道。
- **共识件**：报道里引用"一致预期"，不等于本件是聚合件；聚合数必须回聚合件本身取。

**本环境实有形态（16 份）**：
- **The Information 系（约 12 份，最大宗）**：独家报道 / 全文翻译 / 中英双语对照——同一原文的多语版本**共用一个来源**。
- **引述链**（THE DECODER 引 The New York Times）：追到**它引的那一家**为止，再往上标"未核"。
- **中文科技媒体**（钛媒体）与通讯社（Reuters）：照常归本册。
- **无署名域件**：无出版者的报道体仍归本册，但档位降档、回溯义务不变；**分析文体**（"××解读"）则归独立研究。

**这些别问它**：

| 别问 | 为什么问了也没用 |
|---|---|
| 把它的结论当**已发生的事实** | 它是**二手**；未回溯 ⇒ 不得当已发生 |
| 套"卖方研报"的法定披露要素 | 它**没有法定要素** ⇒ 问了必然"未见"（**假缺口**） |
| 用它当**规则的生效依据** | **生效依据只认官方原文**（本类只登记"它转述了什么"） |
| 把**转载**当独立来源 | 同一原文的转载**共用一个来源** ⇒ **不得计为两个源** |

**分流（真源已裁定）**：媒体件**一律归本类** —— 不按"它转述了谁"拆（那样边界全靠人判），但**一律标二手并回溯一手**。

## 1. 怎么读

**读法的依据（不是自己定的规矩）**：

- **每一段都要有交代**。读了、有理由的略读、或者对本文不适用，都写明。（依据：`撰写规范 §1.9`；守卫 `system/scripts/checks/material_spans_guard.py`）
- **抄下来的必须有数字**。量名、数值、来源。**在这类件里，"这个数是谁说的"本身就是口径**。实在没有数，就按"装不进篮子"写理由。（依据：`撰写规范 §1.8`）
- **数字分级 ＋ 两条数据纪律**。这类件一律算二手。同一个数字要有两个以上独立来源，偏差超过 2% 就要报警。这类件最容易撞上：多家转载同一篇原始报道。自定义口径必须建定义卡。（依据：`撰写规范 §7.5`）
- **什么值得报 ＝ 定量 ＋ 定性**。核心指控即使没有数字，也可能是定性重大。（依据：SEC `SAB 99`）

所以：落库的单位是**段**——每段有决定，段的并集等于全文。

**读的顺序**：`文首（谁写的、哪家媒体、日期）` → **它引用的原始件是什么** → **匿名信源在哪** → **公司有没有回应** → **结论与指控**（只作待核项）。
**可以停的条件**：**每一条可引用的事实都标了"已回溯到一手 / 未回溯"**；**未回溯的一律不得写成已发生**。

**版面变体 × 读法（16 份实读归纳；先认变体，再加一条纪律）**：

| 变体 | 长相 | 加一条 |
|---|---|---|
| **The Information 独家报道体** | 导语即核心事实，正文展开引述链 | 导语先抄"核心指控"；逐个引述标"谁说的"；匿名信源处标"无法回溯" |
| **全文翻译件** | 前置批注"以下是《X》全文翻译" | 当原文读，但**署名层级跟原文走**（信息源还是原媒体，不是译者） |
| **中英双语对照件** | 段对段排列 | **两语是一份文档**：只回执一次，共用一个来源 |
| **摘要级抽取件**（frontmatter 自述"摘要级，非原文逐字"） | 只有要点与关键表 | **"段并集＝全文"降为"并集＝抽取所及"**：如实记"抽取为摘要级"；关键数字回原文 URL 核验后才能用 |
| **转载件**（如腾讯新闻载钛媒体） | 载体平台 ≠ 原媒体 | 出处写**原媒体**，平台只记为载体；与同原文的其他转载共用一个源 |

**可以略读的**：背景叙述与转述行业常识（仍要写理由）。

## 2. 它结构上必然带着什么



| 必然带着 | 别处拿不到的是什么 |
|---|---|
| ① **它引用的原始件**（公司文件 · 法庭文书 · 匿名消息 · 其他报道） | **回溯路径**——决定这条能不能用 |
| ② **记者自采内容**（调查 · 走访 · 数据挖掘） | 一手之外的新线索（仍须核） |
| ③ **公司的回应 / 否认** | 被报道方怎么说（**这一项常被忽略**） |
| ④ **时点**（发布日 / 事件日） | 时效 |
| ⑤ **转载关系** | 哪些是同一原文（防止虚增来源数） |

## 5. 特有的坑（只写这类件才有的）


这一节列**只有这类材料才会踩的坑**——踩了不会报错，但结论会错。

1. **把报道当"已发生"** ⇒ 它是二手：**未回溯到一手的，一律不得写成事实句**。
2. **多家转载当多个独立来源**（防止"三家转载 ＝ 三个源"）⇒ 同一原文**共用一个来源**。
3. **用媒体转述当规则的生效依据** ⇒ **生效依据只认官方原文**；本类只登记"它转述了什么"。
4. **把记者的推断读成事实** ⇒ 逐条区分"引用的事实"与"记者的推断"。
5. **只看指控、不看公司回应** ⇒ 回应或否认要一并写。
6. **记者的算术当公司口径** ⇒ 数字要问"**谁提供的**"。
7. **把沉默当默认**（"未回复即默认"）⇒ **不得**这样解读。

## 6. 红灯：见到必须上报


这一节列**见到就必须停下来喊人**的信号——不要自己裁，写清在哪、多少、和什么比。

| 红灯 | 判据 |
|---|---|
| **核心指控只由匿名信源支撑** | 未回溯 ⇒ 上报（不得当事实） |
| **公司明确否认** | 回应段 ⇒ 上报（指控与否认都要写） |
| **与法定披露冲突** | 报道说法 vs 已披露 ⇒ 以披露为准 ＋ 上报 |
| **回溯不到一手** | 无法定位原始件 ⇒ 上报 |
| **转载冒充原创 / 转载关系不明** | 上报（防止虚增来源数） |
| **疑似把推断当结论** | 记者推断被写成事实 ⇒ 上报 |
| **涉规则的题材** | 媒体转述 vs 官方原文不一致 ⇒ 上报口径冲突 |

红灯**不是结论**，是**上报信号**：写清"**哪家媒体 / 哪天 / 指控什么 / 一手是什么 / 公司怎么说**"。

## 7. 跨类照应（只写"口径差异提醒"，**不引用别的册**）


这一节只做一件事：**说清「这份材料里的某句话看起来像别类，但为什么仍归本类」**。

媒体件最容易越界——它常引用监管原文、常转述财报数字、常替卖方复述观点，但**转述不等于原件、不等于测算**。所以正文只写一句「口径差异提醒」，把读者引到正确的类，**不在这里展开别类的判读**——展开了就是把两类的活混成一件，两边都做不深。

| 提醒 | 内容 |
|---|---|
| **它一律二手** | 措辞写"**据〔媒体〕〔日期〕报道，……**"；**不得**写"已发生" |
| **优先级** | **官方原文 / 法定披露 > 公司原话 > 媒体** ⇒ 冲突时以前者为准 |
| **题材涉规则时** | 它**不算约束类**：**生效边界与日期必须回官方原文**（本类只留转述线索） |
| **转载与同源** | 同一原文的多家转载**共用一个来源**；与"同一原文的四种加工件"同属"**同源归一**"家族 |
| **与"市场在定价什么"的分界** | 主语是**市场预期与仓位**，不归本类；主语是**公司基本面事实**，归本类 |
| **它不产出我方结论** | 只产"**它称什么 ＋ 一手在哪 ＋ 能不能回溯 ＋ 公司怎么说**" |
