> 本件是 `system/env/meta/prompts/03-卖方与共识.md` 的**分册**：主件说**这是哪一类**，本件说**怎么读、必须过哪些项、问什么、有哪些坑、见到什么要上报**。

> **本册自包含**：跨类**只写一句"口径差异提醒"**，不引用别的册。
> **落点 = `system/env/meta/valuation-model.md` 上的格**；篮子只是存放答案的地方；档位口径见 `system/reports/撰写规范.md §7.5`。
> 报告**给人看**：认知增量先行、说人话、**不出现段号与回执计数**。输出表达六条纪律见 `RUN-PARALLEL §2.4`；本册特有：评级与目标价只作背景，报告只拆数据与假设。
> **本册第一纪律**：**抽其数据与假设、弃其评级** —— 评级、目标价、买入理由**只作背景，不进事实层**。

> **输入**：具名投行研究部出的研报（含中资券商海外部、券商模型件 `xlsx`），有评级或目标价。

## 读前 30 秒（这段是观点，不是清单）

一份投行研报，本质上是一套**别人已经跑通的估值模型**，外加一句"因此我给买入"的结论。
**值钱的不是结论，是模型里的假设**：他把明年的收入增速设成多少、毛利率给到几成、算力开支按什么斜率走。
你要做的是把这些假设一条条抠出来，和自己的数并排放，看差在哪一年、差多少——差距就是你要去一手源核的地方。
**最容易犯的错是反过来**：抄下"目标价 800 美元、维持买入"，然后当成事实写进报告。那是他的观点，不是公司的事实，明天就可能改。
所以本册只干一件事：**把研报翻译成一张"假设 vs 我的数"的对照表**；评级、目标价、"买入理由"一律放背景，不进事实层。

## 0. 它是什么

**本册在系统里的位置**：拆出他的数据与假设，填进估值模型的格，供修正提案比较。催化剂清单是派生的附带品；错误定价＝市场价与模型的差额，对比由催化剂系统做，不是本类。**判一条信息值不值得提，只看它改得动模型哪一格。**

**认它的痕迹**：具名投行研究部（含中资券商海外部）；**评级 / 目标价 / 预测**；"业绩回顾及展望""预览""深度"这类标题；也可能是**券商模型件**（`xlsx`）。

**别认错成谁**：
- **独立研究**：判据一条——**没有具名券商研究部、没有评级目标价**的深度长文（SemiAnalysis、Stratechery、Citrini 这类），是独立研究，不是本册。
- **共识与评级档位**：一份报告再全景，也是**单家结论**；只有"多家聚合"的一致预期 / 分布，才归共识册。
- **媒体分析**：券商观点被**媒体转述**时，署名是媒体 ⇒ 归媒体分析。

**本环境实有形态（163 份的出品方与产品画像，判别时直接对号）**：
- **出品方主力**：Morgan Stanley 约 50 份（产品标记 "M | Idea / Global Insight / Thematics"，中译本署名"大摩"）· Bernstein 约 20 份（邮箱域名 bernsteinsg.com；Stacy Rasgon、Alex Wang 是它的半导体分析师）· Goldman 约 15 份（"GS Forecast"、"US Equity Views"）· Citi 约 11 份（"1st Impression" 是它的产品）· JPMorgan 约 8 份（文件名前缀 JPM_；Doug Anmuth、Harlan Sur 是它的人）· BofA 约 7 份（"Preview / Earnings Tracker"）；其余有 BNP（"ANCHOR REPORT / Global Markets Research"）、HSBC、Jefferies（Edison Lee）、Barclays，以及中资券商的中文报告（中信、广发）。
- **产品形态**：个股评级与目标价（"Reiterate Rating: BUY, PO…"）· 评级变动（"Rating Overweight→Equal-weight"）· 财报首评（1st Impression）· 季前预览（Preview）· 业绩追踪（Earnings Tracker）· 资本开支追踪（Cloud Capex Tracker）· 主题研究（Thematics / Idea / Moats）· 客户调研（CIO Survey）· 零售数据（Retail Radar）· **模型件 `xlsx`**（假设表）。
- **判别技巧（按可信度排序）**：① 分析师**实名**对照上列名单；② **邮箱域名**（@bernsteinsg.com 这类）；③ 文件名前缀（JPM_ / BERN_）；④ 页面产品标记（"M | Idea / Global Insight"）。

**版面通式（163 份实读归纳；先认版面，再决定怎么读）**：
- **免责与冲突披露在开头**（"does and seeks to do business…conflict of interest"）：样板，可**有理由的略读**；但扫一眼**承销 / 做市关系**——那是"他的观点带立场"的红旗素材。
- **产品头**：产品名 ＋ 日期 ＋ 分析师实名。先在产品头认出**这是哪种产品**，再套下表的读法。

| 产品 | 版面长相 | 怎么读 | 产出（填哪格） |
|---|---|---|---|
| 评级 / 首评 / 维持（"Reiterate Rating…PO…"） | 摘要句 → 论点 → 当季数字 → 估值与风险 → 附录认证页 | 摘要句抄下评级与目标价（标"他认为"）；只拆**论点背后的假设与数字**；附录略读，留一句"披露页已见" | 假设取值逐项对照模型；目标价与评级只作背景 |
| 追踪表（Earnings Tracker / Cloud Capex Tracker） | 一张多公司大表，每公司一行 | **逐行找 Meta 与直接相关行**，不整表抄；口径看表头脚注 | 表内数＋口径 → 对照模型同口径项 |
| 季前预览（Preview）＋ 业绩首评（1st Impression） | 先"我们看什么 / 上季回顾"，再逐项预测 | 提**预测的驱动假设**（量、价、费用）；首评重点抓"他改了什么" | 预测差 → 预期差 |
| 主题研究 / 调查件（Thematics、Moats、CIO Survey） | 叙事长文，或问卷统计 | 抓"我们的判断"句与量化锚；调查件先问**样本 N、问卷期、口径** | 长期假设（渗透率、周期、需求）→ 模型的慢变量 |

**这些别问它**：

| 别问 | 为什么问了也没用 |
|---|---|
| 把**评级 / 目标价**当事实或价格预期 | 那是**他人结论**；评级变动 ＝ **观点变了**，不是事实变了 |
| 用"媒体件的问句"问它 | 媒体件没有测算（那是另一类材料） |
| 问"评级档位分布"当**本份报告**的数据 | 分布是**机构级披露**（见 §3.5），不是这一份的结论 |

**一个可用的推论**：**发布日与"发行窗口"的关系，能解释"为什么某段时间某家没出报告"** —— 承销商在 IPO 后**至少 10 天**、二次发行后**至少 3 天**有**静默期**（含例外，见 §3.5）。

## 1. 怎么读

**读法的依据（不是自己定的规矩）**：

- **每一段都要有交代**。读了、有理由的略读、或者对本文不适用，都写明。不许只记"必过项"。（依据：`撰写规范 §1.9`；守卫 `system/scripts/checks/material_spans_guard.py`）
- **抄下来的必须有数字**。量名、数值、期间、口径。实在没有数，就按"装不进篮子"写理由。（依据：`撰写规范 §1.8`）
- **数字分级 ＋ 两条数据纪律**。Ⅰ 可逐行复核，Ⅱ 二手带链接，Ⅲ 未核。同一个数字要有两个以上独立来源，偏差超过 2% 就要报警。他的自定义口径（non-GAAP、调整后指标）必须建定义卡。（依据：`撰写规范 §7.5`）
- **什么值得报 ＝ 定量 ＋ 定性**。定量只是起点。掩盖趋势、掩盖未达预期、涉及重要分部——这些定性因素可以让金额小也照样重大。（依据：SEC `SAB 99`）

所以：报告章节只是**去哪儿找**（定位）。落库的单位是**段**——每段有决定，段的并集等于全文。

**读的顺序与什么时候可以停**（先看修正、再看假设、最后看情景 —— 因为**假设表才是值钱的部分**）：

`首页（只作背景）` → **预测修正** → **论点要点**（能不能映射到模型某一行）→ **假设表逐行** → **估值与情景** → **风险章** → **图表**。
**可以停的条件**：**每一处与我不一样**的假设都已经点出来（要么给出差异，要么写明他没给）。

**载体变体**：若为 `xlsx` **模型件**，**必须回原生表读**（**不得**用截图 / 转述替代）；只读**假设页与科目表**，不逐格抄公式。

**可以略读的只有一处**：**免责声明与方法论样板**（略读也要写理由；但**冲突披露**与**评级定义**不许略 —— 它们是 §3.5 的必过项）。

## 2. 它结构上必然带着什么

为什么这一节要背？因为**投行研报的价值不在结论，在这六样东西**。

一份研报的结论（买/卖/目标价）本质是**别人已经跑通的估值模型**的输出，**值钱的是模型里的假设**：他把明年收入增速设成多少、毛利率给到几成、算力开支按什么斜率走。
这六样东西里，**①假设取值和②预测修正**是唯一能直接搬进你自己模型的（别人的答案 + 改动方向），**③情景和④估值方法**告诉你他在什么条件下会改口，**⑤法定披露要素**决定这份结论可信度（有没有冲突披露、评级分布是不是一边倒），**⑥风险章**是他自己认下的脆弱点。

读的顺序反过来最容易出错：**先看评级与目标价、后补假设**——那样你抄到的是一个结论，而不是一套可以对照的账。




| 必然带着 | 别处拿不到的是什么 |
|---|---|
| ① **关键假设取值**（收入增速 / 毛利 / 折旧 / 算力开支 / 税率 / 每股收益） | **别人的答案** ⇒ 做**逐行对照** |
| ② **预测修正**（改了哪一项、从多少改到多少） | 分歧在**收敛还是发散** |
| ③ **情景**（乐观 / 中性 / 悲观）与各自驱动假设 | 他的**条件依赖** |
| ④ **估值方法与倍数** | 他用什么尺子量这家公司 |
| ⑤ **法定披露要素**（评级定义 · 评级分布 · 目标价依据 · 冲突披露） | **判断"这份研报的结论有多可信 / 是不是被迫说好话"** |
| ⑥ **风险章** | 他自认的脆弱点 |

## 3. 必须过的项（穷举）

### 3.1 假设与预测（它值钱的地方）

| 项 | 拿到什么算过 | 常见坑 |
|---|---|---|
| 关键假设逐行 | 量名 ＋ 数值 ＋ **期间** ＋ **口径** | 只抄"目标价"，不抄假设表 |
| **与我不一样的地方** | 差异最大的 **3–5 行** ＋ 差多少 ＋ 差在哪一年 | 不做对照 ⇒ 白读 |
| **财年是谁的财年** | 写清（**公司财年还是日历年**），否则**不可比** | 拿日历年口径混公司财年 |
| **预测修正** | 改的是**假设**还是**结论** | 只改评级 ＝ **不重要**；改假设 ＝ **重要** |
| **情景** | 三种情景 ＋ 各自假设 | 只给一个目标价 ⇒ 记为"**无情景**" |
| **估值方法** | 方法 ＋ 倍数，且**多种方法能不能互相印证** | 只看倍数不看依据 |

### 3.2 风险章（可核判据）

**判据**：风险句能不能写成 **"若〔变量〕变 X ⇒〔哪一年〕每股收益变 Y%"**。
- 能写成"若 X 变则 Y 变"＝有信息；只写成"竞争加剧可能影响业绩"＝记"**样板风险**"（**不是缺口**）。

### 3.3 结论的可核性（只作背景，但要标状态）

| 项 | 拿到什么算过 | 常见坑 |
|---|---|---|
| 评级 / 目标价 | 记下**日期**与**档位**（仅背景） | 当依据用 |
| **无数据支撑的结论** | 标"**无法核**"并上报 | 当事实用 |

### 3.4 载体变体：**券商模型件（`xlsx`）**

| 项 | 拿到什么算过 | 常见坑 |
|---|---|---|
| 假设页 | 逐行取值 ＋ 期间 ＋ 口径 | 只看输出页（结论）不看假设页 |
| 科目表 | 与公司披露口径的**映射关系** | 把模型的科目名当公司口径 |

### 3.5 法定披露要素（美国卖方研报；这些是**能核的形式要件**）

| # | 要素 | 判据（缺了就是形式不合规，写"**未见**"） |
|---|---|---|
| 1 | **评级定义** | 每一评级须有**清晰定义**，含**时间跨度**与**基准**，并与字面含义一致 |
| 2 | **评级分布三件** | ① 全部被评级证券中买入 / 持有 / 卖出的**占比**；② 各类别中**过去 12 个月提供过投行服务**的公司占比；③ 观测时点 ＝ **最近日历季度末**（发布日距季末 <15 天时可截至上上个季末） |
| 3 | **目标价依据** | 须有**合理依据** ＋ **估值方法的清晰解释** ＋ **风险的公平列示** |
| 4 | **评级 / 目标价历史走势图** | 若对该证券已给评级或目标价**≥1 年** ⇒ 须含收盘价折线图（覆盖该期间或**三年**，取较短者），并**标注每次赋/改的日期** |
| 5 | **冲突披露（九项）** | 分析师及其家庭的持仓 · 分析师报酬是否与投行业务收入挂钩 · 过去 12 个月是否主/副承销或收取投行报酬 · 未来 3 个月是否寻求 · 过去 12 个月是否收取非投行报酬 · 是否客户及服务类型 · 是否实益持有该类普通股 **≥1%** · 是否做市 · 分析师过去 12 个月是否从标的收酬 · 其他重大冲突（须置于**首页**或首页指明页码） |
| 5.1 | **九项逐项判据（上面第 5 条的展开，Q10 照这张表逐项写）** | 见下方「九项到底怎么核」 |

#### 九项到底怎么核（Q10 的粒度标准）

**每一条都必须写成三段**：① 结论（有 / 未见 / 无法核验）；② **具体内容**——是谁、什么时间、什么证券、多少比例、
什么服务；③ **判「未见」时说明查过哪里**（附录第几页 / 哪一节找不到），并说明为何某条通用声明不能算本项。

| 项 | 在原文里找什么（典型措辞） | 算「有」必须抄下什么 | 什么情况判「未见」 |
|---|---|---|---|
| ① 分析师及家庭持仓 | `analyst or a member of research analyst's household`；`owns securities`；逐个分析师名的持股句 | **具体人**（如 Gregory Gao）+ **证券类别**（common/preferred）+ 该人身份（分析师本人 / 家庭成员） | 通篇只有「未实地考察」这类运营声明，**没有**任何持股句 ⇒ 未见（并引那句最接近的声明，说明为何不算） |
| ② 报酬是否挂钩投行收入 | `compensation is determined by`；`not directly related to`；`investment banking` | 原文对**挂钩关系的完整表述**：挂钩什么（公司整体收入 / 含投行收入）、不挂钩什么（特定推荐 / 特定交易） | 只有「分析师认证」标题而无报酬句 ⇒ 未见 |
| ③ 近 12 个月主/副承销或收取投行报酬 | `managed or co-managed a public offering`；`received compensation for investment banking services` | **机构全名**（如 Citigroup Global Markets Inc.）+ **期间**（within the last 12 months）+ **标的是否含本股**（Meta Platforms Inc 在不在名单里） | 名单只列了别的公司、不含 Meta ⇒ 写「名单不含本标的」（这是**有信息量的未见**，必须写出来） |
| ④ 未来 3 个月是否寻求投行费 | `In the next 3 months`；`expects to receive`；`intends to seek` | 原文对未来三个月意图的**原句**；含本标的就写「含」，不含就写「不含本标的」 | 全文无 next 3 months 段 ⇒ 未见 |
| ⑤ 近 12 个月非投行服务报酬 | `non-investment banking`；`securities-related services` | 服务**类型**（证券相关 / 非证券）+ 是否含本标的 | 只有投行服务句、无「非投行」句 ⇒ 未见 |
| ⑥ 是否客户及服务类型 | `is or has been a client`；`client relationship` | 客户**身份类型**（投行客户 / 非投行证券类 / 非证券类），三类分开写 | 无客户关系句 ⇒ 未见 |
| ⑦ 实益持股 ≥1% | `beneficially owned 1% or more`；`as of` 日期 | **截止日期**（如 as of March 31, 2026）+ **证券类别**（common equity / debt）+ 本标的在不在名单 | 只有「某子公司可能持债务证券 1%」这类通用声明 ⇒ 未见，且**必须说明**：对象是子公司 / 标的是债务，不是本项要求确认的普通股 |
| ⑧ 是否做市 | `makes a market in the securities of`；`market maker`；`liquidity provider` | 做市**主体**（Morgan Stanley & Co. LLC 等）+ **是否含本标的** | 只有「非做市商推荐工具由 Firm 提供流动性」这类限定句 ⇒ 写「部分披露」并抄原句，不要直接判「有」 |
| ⑨ 分析师过去 12 个月是否从标的收酬 | `received compensation from`；`compensation from the subject company` | 收酬**主体**与**来源**（是否来自本标的）+ 期间 | 只有公司层面报酬句、无「from the subject company」⇒ 未见 |
| ⑩ 其他重大冲突 | `significant financial interest`；`beneficial ownership`；`director`；`advisory board` | 冲突**类型**与**对象**（如 Citigroup 对 Meta 有重大财务利益） | 无其他冲突句 ⇒ 未见 |

**三条硬规矩**

1. **「未见」不是两个字。** 必须写清查了哪里、为什么不成立。只写「未见。」= 不合格（与「没查」无法区分）。
2. **通用声明 ≠ 本项确认。** 例：印度子公司「可能持债务证券 1%」不能当成「Morgan Stanley 持 Meta 普通股 ≥1%」。
   这类要写「有相近声明但对象/标的均不符」。
3. **「有」必须落到可核的四要素**：谁（机构/人名）· 何时（期间或截止日）· 什么（证券类别 / 服务类型 / 金额比例）· 原文怎么说。
   缺任何一项都只能算「无法核验」。

| 6 | **静默期** | 作为承销商：IPO 后**≥10 天**、二次发行后**≥3 天**不得发布 / 公开露面（例外：新兴成长公司 · 覆盖基金 · 重大新闻且经法务事先授权 · 活跃交易证券） |
| 7 | **终止覆盖** | 若拟终止覆盖 ⇒ 须通知客户 ＋ 附**最终报告或说明原因** |

**反向判据（认清它的边界）**：下列**不算研究报告**，**不要拿本册的问句去问它**：
广泛指数讨论 · 经济 / 政治 / 市场评论 · 纯技术分析 · 多公司统计摘要 · **评级或目标价变动通知** · **分发给少于 15 人的通信** · 法定招股说明书 · 私募备忘录。
**研究报告的实质定义**：**书面（含电子）通讯 ＋ 含对证券或发行人的分析 ＋ 提供足以据以作出投资决定的信息**（三者同时成立）。

## 4.5 形式要件四查（先确认它是不是一份「研究报告」）

美国卖方研报按惯例必须同时具备四项。**缺两项以上，它就不是研报**——按二手转述处理，或退回补件。

| 查什么 | 在哪找 | 缺了意味着 |
|---|---|---|
| **署名**（研究部 ＋ 分析师实名） | 封面页 / 末页 | 无署名 ⇒ 无法追责，也判断不了立场 |
| **日期**（发布日） | 封面 / 页脚 | 无日期 ⇒ 分不清是当前观点还是半年前的旧观点 |
| **评级与目标价**（或明确的「无评级」声明） | 摘要句 | 两者皆无 ⇒ 它只是摘要，不是完整研报 |
| **冲突披露**（持股 / 承销 / 做市关系） | 末页 Disclosure | 缺披露 ⇒ 观点可能带立场，引用要打折 |

**实测**：本批有一件（`2026-07-08_美银上调三大云厂商资本开支预测.pdf`，513 字）四项全缺，只有三组数字。
它被分类成「投行研报」，但按上面四条，**更像二手转述**。处置：

- 数字可以登记，但档位一律 **Ⅲ（未核）**，不进事实层；
- 报告里写明「形式要件缺 X 项，按转述处理」；
- 建议主控改判为「媒体分析」或退回，补 BofA 原报告。

## 4.6 无共识分母时怎么办（三条替代判法）

本类最常见的死结：两件材料给了同一指标的两个值，但**都没有「共识」可作分母**，
于是「偏离共识 >5%」这条红灯打不出来，最后只能写「判不了」。

三条替代判法，按可信度排序：

1. **跨机构对照**：A 机构 vs B 机构，各自带**版本日期**。
   差 >5% 且能找到假设差异（桥）⇒ 正常分歧；差 >5% 且**无桥** ⇒ 红灯。
2. **对指引对照**：机构的数 vs 公司自己给的指引或上一期实际。
   偏离一个档位以上（如资本开支差 10%+）⇒ 红灯。
3. **对历史误差带对照**：把当前预测放进该公司过去 8 个季度「预测 vs 实际」的误差带，
   超出带宽 ⇒ 红灯。

**三条都打不出来时**，写「无可比分母，本项判不了」，并**把两个数与各自版本日期并列**——
**不要只留一个数**，那会让下游误以为只有一个值。

## 5. 特有的坑（只写这类件才有的）


这一节列**只有这类材料才会踩的坑**——踩了不会报错，但结论会错。

1. **只抄目标价、不抄假设表** ⇒ 本册的价值全部丢失（"弃其评级"就是为此）。
2. **评级变动 ≠ 事实变了**：那是**观点**变了 ⇒ 措辞必须写"**某机构于〔日期〕将其评级由 X 改为 Y**"。
3. **他的 non-GAAP / 调整后口径**往往自成一套 ⇒ **必须建定义卡**，**不得**与公司口径混用。
4. **财年口径不写清 ⇒ 整张表不可比**（公司财年与日历年差一个季度）。
5. **`xlsx` 只读输出页** ⇒ 拿到的是结论，不是假设（本册要的正是假设）。
6. **"未见披露"就说"未见"**，**不许自己数条数聚合**（评级分布是机构级披露，不是我们能数出来的）。
7. **静默期**能解释"这段时间为什么没有报告" ⇒ 别把它当"覆盖中断"。

## 6. 红灯：见到必须上报


这一节列**见到就必须停下来喊人**的信号——不要自己裁，写清在哪、多少、和什么比。

| 红灯 | 判据 |
|---|---|
| **只有结论、没有数据与假设** | 标"**无法核**" ＋ 上报 |
| **偏离共识 > 5% 而无书面辩护** | 他的假设 vs 共识 ⇒ 有 ⇒ 上报 |
| **同一事实、与别类材料说法相反** | 与别的材料并排 ⇒ 出"**对立来源对照**" |
| **同一机构预测被两处转述而数字不一致** | 口径冲突 ⇒ 上报 |
| **形式要件缺失** | 评级定义 / 评级分布 / 目标价依据 / 冲突披露 **未见** ⇒ 上报（可信度降级） |
| **风险章全为样板** | 无一条能写成"若 X 则 Y" |
| **模型件与报告口径冲突** | `xlsx` 与文字版假设不一致 ⇒ 上报 |

红灯**不是结论**，是**上报信号**：写清"**哪一段 / 哪张表 / 多少 / 与什么比**"。

## 7. 跨类照应（只写"口径差异提醒"，**不引用别的册**）


这一节只写**与其他类的口径差异提醒**：一句带过，不展开别类的判读。

| 提醒 | 内容 |
|---|---|
| **它给的是"别人的答案"** | 与**公司口径**混用，会把"预测"写成"已发生" |
| **期间口径** | 研报用**日历年 / 公司财年**两种口径的都有 ⇒ 引用**必须标口径** |
| **载体差异** | 同一份研报的**文字版与模型件**常常数字不完全一致 ⇒ 以**模型件**为准并注明 |
| **评级口径** | 各机构对买入 / 持有 / 卖出的**定义与时间跨度不同** ⇒ **跨机构可比性有限** |
| **它不产出我方结论** | 只产"**他的假设**"与"**差异**"；判断留给主控 |
