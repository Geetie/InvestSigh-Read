# `03` · **共识与评级档位**（聚合件）—— 这一类怎么读

> **开工必读**：写法规范两章逐章读（通用落纸纪律与全局查法不进读法列——读法列是精简指令，只留本型特有判据）。
> 本件是 `corpus/prompts/03-卖方与共识.md` 的**分册**：主件说**这是哪一类**，本件说**怎么读、必须过哪些项、问什么、有哪些坑、见到什么要上报**。
> **边界**（本册可能被单独交付，故自带）：**可读＝仓库根以下全部（只读）**；**可写＝仅 `output/<标的>/<材料 id>/`**；其余禁写（`README §3.1.1`）。
> **本册自包含**：跨类**只写一句"口径差异提醒"**，不引用别的册。
> **落点 = 估值模型上的格**；篮子只是存放答案的地方；档位口径见主件 §0.5 术语表。
> 输出表达六条纪律见 `RUN-PARALLEL §2.4`；本册特有：聚合数必带口径四件（样本、期间、口径、来源），缺一件不可比。
> **校准状态（如实）**：一致预期、评级分布这类聚合件，在本批材料里**没有独立成件**（它们多藏在研报的"评级与预测"页里），所以本册是按**官方披露要素**和**聚合口径的常规要件**写的，**没有用独立真件校准过**，用的时候按 §1 自行校准。

---

> **输入**：一致预期汇总、评级分布、目标价区间这类聚合件。
> **前置**：只需知道——① 聚合件回答「市场整体怎么想」，不回答「某一家怎么想」；② 值钱的是分布（离散度），不是均值；③ 聚合件通常看不到单家假设。
> **输出**：分歧定位（哪一格最不确定、多少家在上调/下调），不产出「谁对」的判断。
> **输出格式 = 本册模板** `corpus/templates/03-共识与评级档位.md`：抄一份到 `output/<标的>/<材料 id>/material.md` 再填；**采不到的栏目整节删掉，不呈现空项**（模板是本体文件，守卫在 `server/check.mjs`）。

## 读前 30 秒（这段是观点，不是清单）

一致预期与评级分布，回答的是**"市场整体怎么想"**，而不是"某一家怎么想"。
它值钱的地方是**分布，不是均值**：均值告诉你市场的中枢，离散度告诉你**哪一格最不确定、最该去核**。
所以读它的第一动作不是抄那个平均数，而是看**最高值、最低值、覆盖家数、最近有多少家在上调或下调**。
**最容易犯的错是把均值当共识**：十家机构里九家给 100、一家给 10，均值 91 看起来"一致"，实际分歧巨大。
本册还有一个硬边界：聚合件往往**看不到单家的假设**，所以它只能定"分歧在哪"，不能定"谁对"。

## 0. 它是什么

**本册在系统里的位置**：聚合数（一致预期 / 离散度）用来定位**分歧在哪一格、有多宽**，供修正提案比较。催化剂清单是派生的附带品；错误定价＝市场价与模型的差额，对比由催化剂系统做，不是本类。

**认它的痕迹**：**一致预期 / 评级分布 / 离散度**这类**聚合**数（覆盖多家机构）；常出现在研报的"评级与预测"页、数据终端导出的表、券商汇总页。

**别认错成谁**：
- **单家投行研报**：再全景也只是单家结论，归投行研报册；只有**多家聚合**才进本册。
- **媒体引述**："分析师认为……"出现在报道里，署名是媒体 ⇒ 归媒体分析；聚合数必须来自**聚合件本身**，不得从报道里抄。

**本环境实有份数：0**（247 份里没有聚合件）。本册为"将来的一般材料"而写——真拿到一致预期 / 评级分布件时，按本册走，并把"聚合数来自哪家终端或哪一页"写进出处。

**这些别问它**：

| 别问 | 为什么问了也没用 |
|---|---|
| 只问**单家**的论点与目标价 | 它是**多家聚合**，单家观点属**投行研报 / 独立研究** |
| 拿**均值**当"市场认为" | 它值钱的地方在 **离散度**，不在均值 |
| **自己数条数、口算**占比 | 它的数**必须有来源**，自己数就是自造数据 |

**它和"市场在定价什么"怎么分（看主语）**：主语是**投资者的预期与仓位**，归 `07`；主语是**分析师对公司基本面的预测**，就是本册这一类。

## 1. 怎么读

**读法的依据（不是自己定的规矩）**：

- **每一段都要有交代**。读了、有理由的略读、或者对本文不适用，都写明。每段的交代合起来，要覆盖全文。（守卫：`server/check.mjs`）
- **抄下来的必须有数字**。量名、数值、期间、口径、观测时点。**在这类件里，观测时点本身就是口径的一部分**。实在没有数，就按"装不进篮子"写理由。
- **数字分级 ＋ 两条数据纪律**。Ⅰ 可逐行复核，Ⅱ 二手带链接，Ⅲ 未核。同一个数字要有两个以上独立来源，偏差超过 2% 就要报警。这类件最容易撞上：不同终端的口径不一样。自定义口径必须建定义卡。
- **什么值得报 ＝ 定量 ＋ 定性**。分歧集中的那一格，本身就是"最值得去一手源核"的信号。（依据：`SAB 99` 的定性维度）

所以：落库的单位是**段**——每段有决定，段的并集等于全文。

**这类件读法的特点**：表比文重要。先读表头和脚注（口径四件，见 §3.1），再读数。表头读错，后面全错。

**什么时候可以停**：口径四件齐了（有值，或写明"未标"）；离散度和两端已经给出。两者都拿不到，就如实写"无源"。

## 2. 它结构上必然带着什么



| 必然带着 | 别处拿不到的是什么 |
|---|---|
| ① **覆盖范围**（多少家机构 / 哪些机构） | 这个分布**代表谁** |
| ② **观测时点** | 共识**有多新**（陈旧共识会误导） |
| ③ **统计口径**（均值 / 中位数 / 加权） | 同一个数**是怎么算出来的** |
| ④ **评级分布**（三档占比 ＋ 投行关系占比） | 卖方口径的**一致程度** |
| ⑤ **离散度与两端**（最高 / 最低 / 谁在两端） | **哪一格最不确定** ⇒ 下一步该去核哪里 |

## 3. 必须过的项（穷举）

### 3.1 口径四件（在表头与脚注里；缺一件，这个数就不可比）

| # | 要件 | 拿到什么算过 | 常见坑 |
|---|---|---|---|
| 1 | **覆盖家数** | 数字（家数太少就标"**样本薄**"） | 把 3 家当"市场" |
| 2 | **观测时点** | 日期（与本次事件、财报的先后关系要写清） | 拿财报前的共识当财报后 |
| 3 | **统计口径** | 均值 / 中位数 / 加权（**写清**） | 不同终端的"共识"口径不同 |
| 4 | **指标与期间** | 指标名 ＋ 财年口径（**公司财年还是日历年**） | 混口径 ⇒ 数不可比 |

### 3.2 评级分布三件（官方披露要素）

| # | 要件 | 判据 |
|---|---|---|
| 1 | 全部被评级证券中 **买入 / 持有 / 卖出 的占比** | 有 / **未见** |
| 2 | 各类别中**过去 12 个月提供过投行服务**的公司占比 | 有 / **未见** |
| 3 | **观测时点** ＝ **最近日历季度末**（发布日距季末 <15 天时，可截至上上个季末） | 有 / **未见** |

**三件都要**；**给不出来就写"未见"**，**不许自己数条数聚合、不许口算**。

### 3.3 离散度（这类件唯一值钱的地方）

| 项 | 拿到什么算过 | 常见坑 |
|---|---|---|
| **分布形态** | 最高 / 最低 / 中位 / 众数（能给就给） | 只看均值 |
| **两端是谁** | 最高与最低分别来自哪家（能追就写） | 忽略 |
| **收敛还是发散** | **需跨批（交主控）**；本批只有一期，就只记当期形态 | 自造跨期对照 |

- **主材料**：一致预期/评级分布/目标价区间聚合件本体（每数带口径四件：样本、期间、口径、来源）。

- **外部件**：共识聚合服务（Bloomberg/FactSet/Visible Alpha）**暂无可靠源**——本册标待数据侧；过渡期只许引用研报内自载共识数并写明出自哪页，不得从免费页抄均值凑数（口径四件不齐，只可作Ⅱ档旁证）。
## 5. 特有的坑（只写这类件才有的）

踩了不会报错，但结论会错。

1. **拿均值当"市场认为"** ⇒ 它值钱的地方在**离散度**：分歧大 ＝ 那一格最不确定，**最该去一手源核**。
2. **口径四件缺一 ⇒ 数不可比**（尤其**观测时点**：财报前后的共识不是一回事）。
3. **不同终端口径不同**（均值 / 中位数 / 加权、含不含某类机构）⇒ **同一个数字要有 ≥2 个源，偏差 >2% 报警**。
4. **评级分布只能引用、不许自己数**（那是机构级披露）。
5. **"3 家机构"不是市场** ⇒ 样本薄必须写明。
6. **公司财年与日历年混用** ⇒ 整张表不可比。

## 6. 红灯：见到必须上报

**见到就必须停下来喊人。不要自己裁：写清在哪、多少、和什么比。**

| 红灯 | 判据 |
|---|---|
| **离散度极端 / 两端差距大** | 分布形态 ⇒ 上报（该格最不确定） |
| **共识被极少数机构驱动** | 覆盖家数少而分布集中 ⇒ 上报"**样本薄**" |
| **数据陈旧** | 观测时点距事件过久 ⇒ 上报 |
| **口径不明** | 口径四件缺项 ⇒ 该数不得入结论 |
| **两个源数字不一致** | 偏差 >2% ⇒ 上报口径冲突 |
| **评级分布与手上研报对不上** | 分布说买入占比高、但手上研报多为中性 ⇒ 上报 |
| **只给均值、不给分布** | ⇒ 记为关键缺口 ＋ 上报 |

红灯**不是结论**，是**上报信号**：写清"**哪个数 / 哪个时点 / 差多少 / 缺什么**"。

## 7. 跨类照应（只写"口径差异提醒"，**不引用别的册**）

| 提醒 | 内容 |
|---|---|
| **它是"多家平均"，不是"某家观点"** | 引用时必须写清**覆盖家数与时点**，否则读者会误当"市场共识" |
| **评级定义各家不同** | 各机构对买入 / 持有 / 卖出的**定义与时间跨度不同** ⇒ **跨机构聚合的可比性有限** |
| **与单家研报的先后** | 单家更新常常**滞后于**共识 ⇒ 两者出现差异时**都要写**，别只留一个 |
| **与股价无关** | 它只给**预期分布**，**不含**仓位与资金 ⇒ **不得**当"市场在定价什么" |
| **它不产出我方结论** | 只产"**共识取值 ＋ 离散度 ＋ 时点**" |
