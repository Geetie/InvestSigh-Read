# `07-情绪与预期` —— 总流程册（服务催化剂系统）

这一份是**怎么走**：两个不同的东西、六种测量方法、产出物、红线。每次都要读。

## §0 一页速查（先读这 25 行，再读下面）

**这一类先把两个词分开，分不开就别往下做**：

| | **预期 expectations** | **情绪 sentiment** |
|---|---|---|
| 是什么 | 对未来某个变量取值的**信念分布** | 对**风险的态度**（愿意承担多少不确定性） |
| 问的是 | "市场认为下季 EPS 多少" | "市场现在敢不敢买" |
| 怎么测 | 共识值、隐含概率、调查中位数、点阵图 | 看多比例、资金流、仓位、隐含波动溢价、搜索热度 |
| 错了的表现 | 预期差（surprise） | 拥挤方向被迫平仓 |

**六个测量族**（按测量方法分，不按题材分）：共识与预期差 / 期权与波动率 / 利率与通胀 / 仓位与资金流 / 情绪调查与行为 / 预测市场与事件概率。

**六个核心概念**：

1. **共识**：必须能追到编制方 + 样本量 + 时点；"市场普遍认为"不是共识。
2. **分歧（dispersion）**：最高最低差或标准差。只报水平不报分歧，等于没测。
3. **预期差（SUE 式）**：实际 − 共识，按历史标准差标准化；未标准化要写明。
4. **风险中性**：IV 与期权隐含概率含方差风险溢价，**不是真实概率**。
5. **仓位 = 动作，问卷 = 态度**：两者背离本身是最有价值的信息，不许二选一。
6. **反身性**：极端 + 持续才叫拥挤；要写"反转时谁被迫动"。

**三对最容易混的**：预期 ≠ 情绪；价格 ≠ 情绪（涨跌是结果）；问卷 ≠ 仓位（13F 也不是"当前"）。

**只记三件事**：① 先分预期还是情绪；② 没有基准不许说"极端"；③ 预期卡与情绪卡分开出。

**编号约定**：本书的「断一…断八」「卡 1…11」只在本类有效。分册只认 `07-型/` 下被 `classification.jsonl` 引用的那六本（旧的三本已删除）。

## 零、为什么这一类必须先分清两个词

中文里"情绪"和"预期"常被混用，金融界是**严格分开的**，混了就做不出可用的东西：

| | **预期（expectations）** | **情绪（sentiment）** |
|---|---|---|
| 是什么 | 对**未来某个变量取值**的信念分布 | 对**风险的态度**（愿意承担多少不确定性） |
| 回答的问题 | "市场认为下季 EPS 是多少" | "市场现在敢不敢买" |
| 可观测形式 | 共识值、隐含概率、调查中位数、点阵图 | 看多比例、资金流、仓位、隐含波动率溢价、搜索热度 |
| 关键属性 | 水平、分歧（dispersion）、修正方向、确定性 | 极端度、持续性、反身性 |
| 错了怎么表现 | 预期差（surprise）：实际 ≠ 共识 | 情绪反转：拥挤方向被迫平仓 |
| 典型失效 | 共识样本太少、口径不一致 | 把"价格涨"当"情绪高"（价格是结果不是情绪） |

**两者的关系**：情绪会污染预期（情绪高时共识偏乐观），但**统计上必须分开测**。混在一起的后果是：把"看多比例高"当成"预期 EPS 会上调"，两件事完全不同。

**本类的第一条纪律**：**每条读数先落到"这是预期还是情绪"，落不了就不进卡。**

## 一、六个测量族（本类的骨架，按测量方法分，不按题材分）
为什么按「测量方法」分而不是按「题材」分？因为**同一件事可以有三种完全不同的读数**：AI 资本开支，分析师有共识值（预期）、期权有隐含分布、Polymarket 有「明年是否翻倍」的概率。

三者不可互换，混在一句里就等于没测。所以六族各自成套：**族内可比，跨族要显式对照**。


| 族 | 测的是 | 典型来源 | 打开哪本 |
|---|---|---|---|
| 共识与预期差 | 预期（水平与修正） | 共识数据商、券商汇总、财报实际值 | `07-型/共识预期与预期差.md` |
| 期权与波动率 | 预期（风险中性分布） | 期权交易所、波动率指数 | `07-型/期权与波动率预期.md` |
| 利率与通胀 | 预期（政策路径与物价） | 期货、OIS、央行预测、调查 | `07-型/利率与通胀预期.md` |
| 仓位与资金流 | 情绪（风险承担的实际动作） | 持仓报告、13F 聚合、基金流、券商 PB | `07-型/仓位与资金流.md` |
| 情绪调查与行为 | 情绪（问卷与交易行为） | 协会调查、put/call、宽度、搜索、社媒 | `07-型/情绪调查与行为.md` |
| 预测市场与事件概率 | 预期（事件概率） | Polymarket、Kalshi 等 | `07-型/预测市场与事件概率.md` |

**为什么按测量方法分而不是按题材分**：同一题材（如"AI 资本开支"）可以同时有共识预期（券商 EPS）、期权隐含（事件波动）、预测市场（"某公司今年是否宣布 X"）三种读数，它们的口径、滞后、失效方式都不同。按题材分册会让 agent 在同一册里混用三种口径。

**一本检索表册**：`07-型/情绪指标地图.md`——每个指标谁发布、多久一次、口径、极值怎么读、领先还是同步、什么情况下失效。

## 二、只收什么

**准入口径**（三条全满足）：

1. 主语是**市场 / 投资者 / 资金**，不是某家公司经营；
2. 能落到**可核读数或可核概率**（含发布方与口径）；
3. 能说清"这是预期还是情绪"。

**不收**（转出并写归类纠正）：

- 公司自己说的（指引、电话会）⇒ `01`/`02`（那是被预期的对象，不是预期本身）。
- 他人对公司的评级与目标价 ⇒ `03`（那是他人结论，不是市场共识）。
- 申报级持仓结构（13F 明细行、Form 4）⇒ `04`。
- 规则与宏观变量 ⇒ `06`；链上的物理量 ⇒ `05`。

**边界口诀**：**"谁相信什么"归本类；"谁做了什么"归 `04`；"什么被规定了"归 `06`；"什么被造出来了"归 `05`。**

## 三、预期侧四步
预期侧只做一件事：**把「市场认为会怎样」变成一个可以相减的数**。

四步顺序不能乱：先定对象（哪个变量、哪个期间），再取读数（含样本量与口径），然后量分歧与修正（离散度比均值有用），最后才算预期差。

**最容易跳过的是第二步**——不记样本量，后面所有标准化都是假的。


| 步 | 做什么 | 判据 | 断了怎么办 |
|---|---|---|---|
| 1 | **定对象**：预期的是哪个变量（EPS / 收入 / 政策利率 / 事件是否发生），什么期间 | 变量 + 期间 + 口径三件齐 | 定不了 ⇒ 只登记来源 |
| 2 | **取读数**：共识值 / 隐含概率 / 调查中位数 + 样本量 + 编制方 | 必须有样本量与编制方；单一预测不算共识 | 无样本 ⇒ 标"单方预测"，降 C 级 |
| 3 | **量分歧与修正**：离散度（最高最低差、标准差）、近 30/90 天修正方向与家数 | 分歧与方向分开记；只有水平不算完成 | 只给水平的 ⇒ 写"静态预期" |
| 4 | **算预期差**：实际（或新读数）− 共识，按历史标准差标准化；给"多大算大" | 用 SUE 式标准化或明确写"未标准化" | 算不出 ⇒ 写"预期差待核" |

**预期侧的三条硬约束**：

1. **共识必须能追到编制方**（谁汇总的、几家、什么时候）。"市场普遍认为"不是共识。
2. **期间必须对齐**（1Q / FY / NTM 不可混；名义 vs 实际不可混）。
3. **修正方向比水平有信息量**：连续两期同向修正 > 单期水平高。

## 四、情绪侧四步
情绪侧测的是**「敢不敢承担风险」**，不是「觉得会涨会跌」。所以四步从「定通道」开始：问卷（态度）、资金流（动作）、波动率（保险价格）、仓位（拥挤度）——通道不同，结论不能互推。

第三步「判极端与持续」是本类核心：**没有历史分位就没有「极端」**，单周读数更不构成趋势。


| 步 | 做什么 | 判据 | 断了怎么办 |
|---|---|---|---|
| 1 | **定通道**：这一族指标测的是哪一类风险承担（方向性买入、杠杆、对冲需求、被动配置） | 四类之一；说不清 ⇒ 只登记 | 通道不明 ⇒ 断三 |
| 2 | **取读数 + 定基准**：数值、口径、历史分位或标准差 | 至少一个参照系；无基准不算极端 | 无基准 ⇒ 只说"读数"，不说"极端" |
| 3 | **判极端与持续性**：分位 >90/<10 或 ±2σ；持续几周 | 极端 + 持续才叫拥挤；单日不算 | 单点 ⇒ 标"瞬时读数" |
| 4 | **反身性与失效**：若反转，谁被迫动（平仓、降杠杆、赎回、再平衡）；什么时候失效 | 主体 + 动作 + 时效 | 无被迫动作 ⇒ 只记情绪波动 |

**情绪侧的三条硬约束**：

1. **价格不是情绪**：涨跌是结果；情绪要用"仓位、资金流、问卷、隐含波动溢价"这类**动作或态度**度量。
2. **中间分位没有信息**：分位 30–70 区间写"无边际信息"，不许编方向。
3. **情绪不能直接改估值假设**：只能改"幅度与节奏"，不能改"基本面水平"。

## 五、产出物：两张卡（不要混成一张）
两张卡必须分开出：**预期卡**记「市场认为什么」（水平、分歧、修正），**情绪卡**记「敢不敢买」（极端度、持续性）。混成一张，就会出现「看多比例高 ⇒ 预期 EPS 上调」这种错——这两件事在数据上不相关。


### 5.1 预期读数卡

| # | 栏 | 写什么 |
|---|---|---|
| 1 | 一句话 | 市场对这个变量的预期是多少、往哪改 |
| 2 | 对象 | 变量 + 期间 + 口径（名义/实际，GAAP/非 GAAP） |
| 3 | 读数 | 共识值/隐含概率/中位数 + 样本量 + 编制方 + 时点 |
| 4 | 分歧 | 区间、标准差或分位；样本是否偏斜（几家大机构主导） |
| 5 | 修正 | 近 30/90 天方向、家数、幅度 |
| 6 | 预期差 | 实际 − 共识，标准化口径（SUE 式或自定，须写明） |
| 7 | 与价格隐含的差 | 市场定价隐含的预期 vs 共识（能算就算，算不出写"未反解"） |
| 8 | 对催化剂卡的作用 | 给哪张卡提供基线/幅度 |
| 9 | 失效条件 | 什么情况说明预期测错了（样本变更、口径改、事件取消） |
| 10 | 复核时点 | 下一次共识刷新/财报/会议 |
| 11 | 可信度与缺口 | A 可交叉 / B 单源可核 / C 黑箱 + 具名缺口 |

### 5.2 情绪读数卡

| # | 栏 | 写什么 |
|---|---|---|
| 1 | 一句话 | 市场现在敢不敢承担风险，敢到什么程度 |
| 2 | 族与指标 | 六族中的哪一族、哪个指标、发布方 |
| 3 | 读数与口径 | 数值、单位、期间、口径（含杠杆与否、含 ETF 与否） |
| 4 | 基准与分位 | 历史分位或 σ 倍数；样本区间 |
| 5 | 极端与持续 | 是否 >90/<10 分位；持续几周 |
| 6 | 通道 | 方向性买入 / 杠杆 / 对冲需求 / 被动配置 |
| 7 | 拥挤与反身性 | 谁站满一边、反转谁被迫动、多快 |
| 8 | 与预期的一致性 | 情绪读数与预期读数同向还是背离（背离要写） |
| 9 | 失效条件 | 什么情况说明这个情绪读数不成立 |
| 10 | 复核时点 | 下一次发布日 |
| 11 | 可信度与缺口 | A/B/C + 具名缺口 |

**三类填卡规矩**：

1. 没有基准，不许说"极端"。
2. 没有被迫动作，仓位类那栏要削弱。
3. **预期卡与情绪卡分开出**；一张卡里既写共识又写看多比例，等于没测。

## 六、断点（编号本类专用，勿与 04/05/06 同号混用）
这八条断点分两类：**前四条是「预期侧」的失败**（没有共识就算预期差、用均值代替分布、把陈旧预期当当前、把一家之言当共识），**后四条是「情绪侧」的失败**（拿涨跌当情绪、没有基准就说极端、单周读数当趋势、把拥挤方向当反向信号）。

两侧的错法完全不同，所以**别用预期侧的问句去检验情绪侧的结论**——这是本类最常见的返工。


| 断点 | 断在哪 | 怎么处理 |
|---|---|---|
| 断一 | 读数没有发布方、样本量或口径 | 停，写"读数不可用"并上报 |
| 断二 | 没有基准/历史分位 | 只登记读数，不判极端 |
| 断三 | 落到"感觉市场很乐观" | 降为"读数登记"，不许写预期差 |
| 断四 | 预期与情绪混在一句里 | 拆成两张卡 |
| 断五 | 仓位只有聚合 bps | 当拥挤度线索，不当"谁在买"的证据 |
| 断六 | 群内/社区讨论被当共识 | 降级为单方观点，另找共识源 |
| 断七 | 写不出失效条件 | 卡不完整 |
| 断八 | 用价格涨跌当情绪 | 退回，换"动作或态度"类指标 |

最容易自欺的三处：断三（感觉当读数）、断四（两个词混用）、断八（价格当情绪）。

## 七、加载索引
这一节把「拿到一种读数该翻哪本」压成一张表。

六族的分界不是题材，是**测量方法**：问卷测态度、资金流测动作、期权测分布、预测市场测事件概率。**同一个话题（比如 AI 资本开支）可能同时落在三族里**，这时不是选一个，而是三个都记、然后看它们彼此是否背离。


| 拿到什么 | 必读 | 按需打开 |
|---|---|---|
| 任何材料 | 这一份总流程册 | 无 |
| 共识 EPS/收入、评级分布、修正方向、财报 actual vs consensus | §三 四步 | 《共识预期与预期差》 |
| 隐含波动率、skew、事件隐含波动、0DTE | §三 四步 | 《期权与波动率预期》 |
| 政策利率路径、点阵图、breakeven、通胀预期调查 | §三 四步 | 《利率与通胀预期》 |
| COT、13F 聚合、基金流、PB、FMS、空头、margin | §四 四步 | 《仓位与资金流》 |
| AAII、II、put/call、VIX、宽度、搜索、社媒、媒体语气 | §四 四步 | 《情绪调查与行为》 |
| Polymarket / Kalshi / 赔率 / 事件是否发生 | §三 四步 | 《预测市场与事件概率》 |
| 不知道用哪个指标 | 无 | 表册《情绪指标地图》 |

本类没有材料，就报"该类无源"，不许拿别的类顶替。

## 八、回执、处理、红线

**回执**：只落 `覆盖回执.csv`；一段 = 一个自然段，表格以「表」为单元。

**四条底线**：

- 读数必须有发布方与口径；转述标"转述，未核原文"。
- 不许截断、不许抽样；略读必须写理由。
- "未发布"和"我没找到"分开写。
- 不许把"价格"当"情绪"、"单一预测"当"共识"。

**五种处理**：

- 能填：进报告，标 A/B/C。
- 噪声：删掉不影响任何一栏判断，且不是可观察可计数的量。
- 缺族：有读数但落不进六族（出缺族报告并上报）。
- 口径冲突：两个来源同指标不同口径，并列不取舍，差 20% 以上上报。
- 预期与情绪背离：**如实并列**，不许二选一（背离本身是最有价值的信息）。

**见到就要上报**：

1. 共识样本 <3 家或明显偏斜。
2. 预期与情绪背离（读数极端但没人改预期）。
3. 仓位只有聚合、却被当"谁在买"。
4. 群内/社区单方观点被当共识。
5. 判断依赖已停更或改口径的指标。
6. 预测市场与期权隐含概率差距过大（>15 个百分点）。
7. 疑似已定价（写"疑似已定价（依据：…）"）。
8. 链条断了（没基准、没通道、写不出失效条件）。

**不许做的事**：

1. 不许拿涨跌当情绪，不许拿一家之言当共识。
2. 不许用聚合仓位当申报级证据。
3. 不许在没有基准时说"极端"。
4. 不许把"缺数据"写成"无情绪"。
5. 不许给买卖建议（本类只出读数与预期差）。
6. 不许跨类套问句。
7. 不许不给回执就下"没有"的结论。
8. 不许跳过断点，尤其断三、断四、断八。

---

最后记一句：**先分"预期"还是"情绪"，再按六族找读数。预期看水平、分歧、修正、预期差；情绪看通道、基准、极端、持续性、反身性。两张卡分开出，回执只进 `.csv`。**
