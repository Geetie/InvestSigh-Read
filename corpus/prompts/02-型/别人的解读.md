## 0. 认它的痕迹 / 别认错

**认它的痕迹**：有**别人的假设取值**（收入增速、折旧、算力开支、税率、回购、股数）或方法论；署名是他方（券商研究部、独立机构、第三方模型）。

**别认错成谁**：
- 有评级与目标价、且是券商研究部出的 ⇒ `03-型/投行研报.md`（03 的活是逐行拆假设；本册只做与"业绩与沟通"相关的解读与差异）。
- 主语是公司、且有问答逐字 ⇒ 本类 `02-型/公司自己的话.md`（公司自己的话问句不得套到本型上）。
- 只是同业读数 ⇒ `02-型/旁证与读穿.md`。

## 1. 怎么读（本型路线）

首页（评级 / 目标价 —— **只作背景**）→ **预测修正** → 论点要点（能否映射到模型的某一行）→ **假设表逐行**（`xlsx` **必须回原生表读**）→ 估值与情景 → 风险章（有无挂数字）→ 图表。

★ **停止条件**：**每一处与我方不同**的假设都已点出（差异或该栏删掉）。

## 2. 本型结构上必然带着什么

① **别人的假设取值**；② 与共识的差；③ 它认为最关键的单一变量；④ 情景区间。
**别处拿不到的**：别人的答案——用来做逐行对照（"他 2027 年增速 / 折旧是多少，和我差在哪一项、哪一年"）。

**载体陷阱**：`xlsx` 抽取正文 98.1% 是公式串（实测：124 万字符里 Meta 只出现 1 次）⇒ **回原生表读**，不得照抄抽取正文。

## 3. 必过项（穷举）

| # | 项 | 拿到什么算过 | 常见坑 |
|---|---|---|---|
| 1 | **驱动假设** | 用驱动树写出"收入 = 哪个量 × 哪个价"，并给页码 | 只抄结论 |
| 2 | **假设逐行** | 5 年收入增速 / 利润率路径 / 算力开支 / 回购与股数：取值＋期间＋口径 | 缺项不记，读者以为他没写 |
| 3 | **差异 3–5 行** | 与我方差最多的 3–5 行，差多少、差在哪一年 | 不做对照，等于白读 |
| 4 | **跳跃与拐点** | 最后一个年度的跳变位置 / 幅度 ＋ 有无一句依据 | 把跳变当趋势 |
| 5 | **情景三档** | bull / base / bear ＋各自驱动假设 | 只给一个目标价 |
| 6 | **估值方法与交叉验证** | 方法＋倍数并列＋能否互相印证 | 只看倍数不看依据 |
| 7 | **修正方向与幅度** | 最近 3–6 个月改了什么；基本面变化 / 一次性项目 / 口径调整三者分清 | 把口径调整当基本面改善 |
| 8 | **风险章是否挂数字** | 能否写成"若〔变量〕变 X ⇒〔某年〕每股收益变 Y%" | 套话当风险 |
| 9 | **形态与结论强度** | 首次覆盖 / 公司更新 / 闪评 / 行业：深度是否配得上结论 | 闪评里的大结论不降档 |
| 10 | **可复算性** | 假设表可复算 ⇒ Ⅰ；点评只有结论 ⇒ Ⅱ | 把点评当模型 |

## 4. 问句表


| # | 问什么 | 读法 | 拿到什么算过 | 答不上来怎么写 | 频次 | 落哪个篮子 |
|---|---|---|---|---|---|---|
| 1 | 他的**关键驱动假设**是什么（量 × 价 / 用户 × 单价）？ | 只有能从单位数×单价（或用户数×人均支出）一路乘出该年收入的，才算给了驱动分解；只给增速或只给总额的记「未给驱动分解」，不要替它反推，反推出来的数一律标为材料未提供。 | | | 季 | 他人假设与预期差 |
| 2 | 5 年收入增速 · **利润率路径** · **算力开支** · **回购与股数**各假设多少？ | 四项各抄一个数并挂上财年与币种：收入增速、营业利润率、资本开支、回购。凡与公司公开指引一字不差的标「沿用指引」而非独立假设；缺的写「材料未提供」，不拿同业值补。 | | | 季 | 他人假设与预期差 |
| 3 | ★★ **他哪几行和我不一样？差多少？** | 只对两边定义相同的那几项比数；先判是定义差（口径含不含某块业务、财年错位）还是取值差，定义差的写「不可比」不算差额，否则会把口径差读成观点差。 | | | 季 | 他人假设与预期差 |
| 4 | ★ 有没有"**终点年跳跃**"或**突然的利润率拐点**？依据是什么？ | 末年那一段的增量若落在前三年增量区间之外，记「终点年跳升」并抄幅度；再看有没有对应的成本或投入支撑，只给「规模效应」一类说法而无对应项的，按未解释处理。 | | | 季 | 他人假设与预期差 |
| 5 | 给了 **bull / base / bear 情景**吗？各自驱动假设是什么？ | 三档要各自带一套可复算的假设才算三情景；只给三个目标价而没有对应假设的，记「只有档位没有情景」。没给的写「单情景」，不要借别人的悲观档补一档。 | | | 季 | 他人假设与预期差 |
| 6 | 用了哪几种**估值方法**？**彼此能互相印证吗**？ | 记方法与其作用的利润口径（净利、息税前、销售额、分部）及各自权重；只在正文提一句作交叉验证的不算主方法。给了方法却没写权重与主次的，记「主方法不明」。 | | | 季 | 他人假设与预期差 |
| 7 | **预测修正**的方向与幅度（最近 **3–6 个月**）？**上季实际 vs 他当时预期**差多少？ | 修正只在同一指标同一财年上比：记上版发布日与改前改后两个数。只写「上调」不给数的记「有方向无幅度」；两版财年定义不同就当没有对照。 | | | 季 | 他人假设与预期差 |
| 8 | 他的**风险章**是套话还是挂了数字？有**上行风险**吗？ | 风险条目能写成「某变量变动多少、对应利润或目标价变动多少」的才算挂了数字，只有方向词的是样板风险；再判它换个名字是否就能套在任何一家身上，通用的不计入看空理由。 | | | 季 | 他人假设与预期差 |
| 9 | 这份材料**属于哪一类**（首次覆盖 / 公司更新 / 闪评 / 行业）？**深度配得上结论吗**？ | 判据是内容不是篇幅：有三年以上完整预测与假设链、并声明开始覆盖的算首覆；只给结论与目标价变动、假设沿用上版的算闪评。闪评只能当情绪旁证，不能用来改假设。 | | | 季 | 他人假设与预期差 |
| 10 | ★★ 它是"**只有结论**"还是有**可复算的内部一致性**？ | 拿它给的倍数乘它给的利润，看能不能落回它写的目标价（差额在舍入范围内算通过）。乘不回去、或关键输入没给的，记「结论不可复算」，只当背景。 | | | 季 | 他人假设与预期差 |
