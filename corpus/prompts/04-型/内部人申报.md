## 0. 它是什么

**认它的痕迹**：EDGAR **Form 3**（上任初始持股）/ **Form 4**（交易后 2 个工作日内申报）/ **Form 5**（年报补报）；以及把 Form 4 抄成表格的**聚合站页**（二手）。

| 别认错成谁 | 为什么 |
|---|---|
| 13F / 13D / 13G | 那是**机构存量快照**（归《机构持仓申报》册）；本册是**事件流** |
| 财报里的回购 / 股本行 | 那是法定披露件（归 `01`）；本册只管内部人申报族 |
| "资金面转暖"类研报 | 那是形容不是申报（归 `03`） |

**本环境实有 3 份（2026-10-14 采集后）**：EDGAR 原始 XML ×12（73 个拆分行，含 code）· 申报全清单（554 份，2024-06→2026-10，**SC 13D/G＝0**）· SecForm4 聚合页 ×1（二手）。

## 1. 怎么读（版面变体 × 读法，全部实读归纳）

| 变体 | 长相（实读所见） | 加一条纪律 |
|---|---|---|
| **EDGAR 原始 XML**（一手） | `ownershipDocument` 结构；**同一人同日拆成多行**（多账户：直接/间接各一行） | 先合并到人，再谈"这一笔" |
| **解析逐笔表**（10 列） | filed · reporter · role · txDate · **code** · shares · price · **postShares** · nature · 10b5-1 | code 列优先读；postShares 用来算占比 |
| **聚合页**（二手） | 一、23 笔 SALE 表（**含申报时间，全在 18 点档**）→ 合计 → "主要观察" → 二、期权节选 → 入库提示 | "主要观察"是别人的结论，不入事实层；**它的"23 笔"是它自己的合并口径** |
| **申报全清单** | filingDate · form · accession 三列 554 行 | 只当**申报日历底座**；申报人明细在 XML 里 |

**XML 字段地图**：`rptOwnerName`（申报人）· `officerTitle`（职务）· `transactionDate`（交易日）· **`transactionCode`** · `transactionShares` · `transactionPricePerShare` · **`sharesOwnedFollowingTransaction`**（交易后余额）· `ownershipNature`（直接/间接）· **footnote 定义在文件级、交易行用 `<footnoteId>` 引用**。官方还有两处盘上常被漏看的结构：**Item 4 修正件字段（Form 4/A 要写原申报日）** 与 **2A/3A"视为执行日"（Deemed Execution Date，计划交易用）**。

**code 人话表（官方 Instruction 8 原文，19 个码，全表见 `materials/04-资金与持仓/text/2026-10-14_SEC-Form4-官方表格与指示-全文.md`）**：
- 高频：**P** 公开市场买入 · **S** 公开市场卖出 · **A** 授予/奖励（16b-3）· **F** 代扣税（**不是减持信号**）· **M** 行权/转换（16b-3 豁免）· **C** 衍生转换 · **G** 赠与。
- 容易踩错的：**I** ＝ 酌情交易（16b-3(f)，**不是**"计划外"）· **Z** ＝ **投票信托存取**（不是"其他"）· **K** ＝ **股权互换**（不是"转换"）· **O** ＝ **价外**衍生行权 · **X** ＝ 价内/平价行权 · **D** ＝ 处置回发行人 · **E/H** ＝ 空头/多头衍生仓位到期 · **J** ＝ 其他（须 footnote 说明）· **K** 之外的 **U** ＝ 控制权变更要约出售 · **L** ＝ 小额取得（16a-6）· **W** ＝ 遗嘱/继承 · **V** ＝ 自愿提前申报标记。
- 表头还有官方 **10b5-1(c) 勾选框**（Instruction 10）——盘上 XML 里对应勾选与 footnote 双证。

**实读撞出来的四个形态（判据都从这来）**：

1. **账户拆分**：聚合页"Olivan 1,575 股"在 XML 里是 **946＋82＋57＋82＋408 五行**（合计恰 1,575、同价）——不回原始件就把账户结构误读成多笔交易。
2. **申报时间 ≠ 交易时点**：聚合页申报时间全在 **18 点档**（EDGAR 盘后批处理）⇒ 别拿申报时间排"谁先卖"。
3. **同日全员代扣日**：聚合页期权节选里 **8-15 几乎全员同日归属＋代扣 @589.85** ⇒ 整日按**被动（薪酬结构）**处理，这就是"同日全员代扣"判据的现成实例。
4. **对冲形态**：Zuckerberg 7-31 **Gift 591,690 ＋ Conversion 591,690 @0 同日成对** ⇒ 经济变动为零，不是增减持信号。

**读的顺序**：`code`（性质）→ 股数/价/金额 → **合并到人** → **占比（用交易后余额算，落 `derived/`，禁口算）** → 是否同日全员代扣 → 10b5-1 标记。
**可以停的条件**：每一行都有"主动/被动"标注与依据；相反方向的多笔**逐笔列出**（净额掩盖方向）。

## 1.5 信号强弱：哪些内部人交易值得当信号（专业口径）

**这一节解决一个真问题**：Form 4 一年几十万笔，绝大多数是噪声。学术界与实务界收敛的结论是——
**只有一小类交易有可重复的预测力**，判据如下（按重要度排）。

| # | 判据 | 为什么 | 怎么在本册落地 |
|---|---|---|---|
| 1 | **买入 >> 卖出** | 内部人卖出有无数理由（分散、交税、买房、行权），买入只有一个理由 | 只有 **P** 才进"正向信号"；**S 一律按噪声处理**（除非是集群卖出+Rally，另论） |
| 2 | **机会性 ≠ 例行** | 例行的定义是"可预测的季节性/固定计划"（如每年 3 月为交税卖、按 10b5-1 固定节奏买），这些不含私有信息 | 看 **10b5-1(c) 勾选框**：勾了 = 计划性，降为弱信号；再看该人近 3 年是否有**同月同方向**的固定节奏 |
| 3 | **集群（cluster）** | 多位内部人**各自独立**同期买入，是最强形态（互相不知道对方在买） | 同一发行人 30 日内 ≥3 位不同申报人出现 **P** ⇒ 标「集群」；若其中有 10b5-1 的，把他剔除后再数 |
| 4 | **高管 > 董事** | 高管（officerTitle 有 CEO/CFO/COO 等）掌握经营细节；董事多为外部、信息滞后 | 用 `officerTitle` 分档：C-level / 其他高管 / 董事 / 10% 以上股东 |
| 5 | **金额要标准化** | 买 10 万美元对年薪 50 万的人 vs 年薪 5000 万的人，含义不同 | `金额 ÷ 该人交易后持股市值` 与 `金额 ÷ 年薪`（年薪无源就写"无源"），落 `derived/` |
| 6 | **情境放大** | 股价刚跌、无重大负面、市值小、覆盖少 ⇒ 信息不对称最大，信号最强 | 三个情境各写"是/否/无源"：近 90 日跌幅、市值档、分析师覆盖数 |

**判定顺序（短路，别逐条打分）**：

1. code 是 **P** 吗？不是 ⇒ 只作行为记录，不进信号。
2. 有 **10b5-1 勾选** 或能证明是例行节奏？是 ⇒ 弱信号，标注原因。
3. 30 日内是否**集群**？是 ⇒ 强信号，必须写"同期还有谁买"。
4. 申报人是**高管**吗？是 ⇒ 加一档；董事 ⇒ 中性档。
5. 金额占比与情境三条是否支持？支持 ⇒ 最强档；不支持 ⇒ 保持原档。

**四条明确不许做的事**：

1. 不许把"内部人买入"直接写成"看好公司"——它是**本人用自有资金承担风险**这一事实，动机可以有一百种。
2. 不许把 **F（代扣税）** 与 **M（行权）** 当增减持——前者是薪酬结构，后者是期权到期动作。
3. 不许把**赠与/信托转换**（G/C/Z）当方向信号——经济实质未变。
4. 不许用**净额**（买入−卖出）总结内部人动向——净额会被一笔巨额卖出抹掉十笔买入。

**一个必须写进报告的边界**：以上判据来自公开学术结论（买入优于卖出、机会性优于例行、集群更强、高管更强），
但**它们在不同市值/不同市场上的强度不同**，本批若只有单件材料，只能写"符合/不符合该判据"，**不得写成"因此会涨"**。

## 5. 特有的坑

这一节列**只有这类材料才会踩的坑**——踩了不会报错，但结论会错。按下面的顺序看：**前一半是「读错」**（把 A 当成 B、把旧数当新数），**后一半是「算错」**（口径混用、净额化、时间错配）。读错比算错更难发现，因为它不影响数字的算术正确性。

1. **拆分行当多笔**：先合并到人，再数笔数。
2. **代扣当减持**：F 码是税务代扣，不是信号。
3. **申报时间当交易时点**：18 点档是批处理，无先后信息。
4. **对冲形态当增减持**：G＋C 同日成对＝零变动；**Table II 的 C 码（Class B→A）是类别转换，权益不变**。
5. **加权均价当成交价**：单价是多笔的加权均价（footnote 自报区间），**不得**拿它当某笔精确成交价去比模型。
6. **footnote 漏读**：10b5-1 与间接持有路径都在**文件级 footnote 区**、由交易行引用；只扫交易行会把"计划内"读成"主动减持"——实测 12 份里**每一份都有计划**。
7. **只标"计划内"不记采纳日期**：日期才能核**冷静期（90 天/两个财季）与 12 个月有效期**；超期计划仍在跑是红灯。
8. **把"计划内"一律当无信号**：计划内卖出**信息量低**是对的，但**"全体高管全是计划内、零 discretionary"本身是结构读数**（本环境实测如此）——照实登记。
9. **间接行当第三人**：经由信托/控股实体的行，主体仍是申报人。
10. **聚合页"主要观察"当事实**：那是别人的结论；它的"23 笔"是它自己的合并口径。
11. **净额化**：方向相反的多笔必须逐笔列。
12. **占比不算**：10% 持股人的小额卖出与 1% 持股人的同额卖出含义完全不同。

## 6. 红灯：见到必须上报

这一节列**见到就必须停下来喊人**的信号。判断标准不是「数字大不大」，而是**「我能不能独立复算」**：复算不了的、两处对不上的、只有结论没有依据的，都要上报。上报时写清三件事——**在哪一段、多少、和什么比**；判断留给主控，你只负责把它摆出来。

| 红灯 | 判据（本环境样例） |
|---|---|
| **非计划（discretionary）的公开市场卖出** | 全员都是计划内的窗口里出现一笔计划外卖出 ⇒ 重信号，上报 |
| **计划疑似超期**：footnote 采纳日期距今超 **12 个月**（官方有效期上限，Release 33-11116）仍有大额卖出 | 上报 |
| 单笔金额异常大、原因不明 | **Cox 40,000 股 ≈$2,851 万**（单笔最大）就是这类 |
| 同期多笔方向相反 | 逐笔列，不得净额化 |
| 同日全员代扣被写成"内部人抛售" | 纠正并上报（8-15 日是现成反例） |
| 10b5-1 计划内被写成主动信号 | 纠正并上报 |
| **footnote 与交易行冲突**（行说 direct、footnote 说经由实体） | 上报 |
| 聚合页与 EDGAR 对不上 | 勾稽失败 ⇒ 上报 |
