北美专家纪要：谷歌、Meta 等前沿进展
Demis 卸任 CEO 改做 Chair 的原因？Sergey 和 Koray 的任命对 Gemini 整体路线和 Gemini Enterprise 推进的影响？
如果只说 Demis 的话，其实对 Gemini 没有太大影响。Gemini 从第二代开始基本上是 Korey 负责，虽然 Korey 向 Demis 汇报，但日常决策并不需要经过Demis。因此，这次变动对 Gemini 本身没有实质影响。Demis 以前主要负责 FORSCIENCE 相关工作，尤其是 AlphaFold 的 INFORMATICS，可能对那边会有一些影响。
Sergey 是否更多是一个过渡掌门？他和 Koray 的工作模式和内容对比过去Demis 是否发生显著区别？
目前 Gemini 4 整体由 Sergey 直接管理，他负责日常事务，Korey 现在不再负责 Gemini 4，但 Gemini Flash 等其他项目仍由 Korey 负责日常管理。
OpenAI 希望通过 Astra for Law 做辅助工具还是取代做核心职能的公司？
我了解到 OpenAI 确实在专门做一些垂类的 agent，法律是他们目前重点推进的领域。现在 coding 领域的差距越来越小，市场竞争也愈发激烈。coding 和企业服务不同，企业服务需要一些 FDE，而 coding 更换模型其实并不难。企业服务还需要做 RAG、知识库等工作，所以 coding 领域竞争非常激烈。各家公司都在寻找下一个具有一定门槛的领域，法律就是其中之一。法律领域有一定门槛，落地速度比 forscience 快很多，市场也足够大，虽然不如 C 领域那么大。因此，OpenAI 已经正式设立了专门部门来做法律相关业务，而据了解其他公司还没有专门部门做法律。
现在 Gemini 4 Pro 还是目标 SoTA 水平？ GDM 未来一年是否仍然追求最前沿的模型能力？
现在还是要追求最前沿的模型能力。Gemini4Pro 现在有一些 checkpoint 正在测试，有些榜单比如 AA 榜目前不是排名第一，可能排第二、第三。还是要在个别榜单有更有说服力的表现后才能发布。现在追求的是 SoTA，4Pro 现在有几个不错的 checkpoint，体感上是 SoTA 模型，GDM 自己测试后通过 ab test、elo test，但在某些榜单上不是第一。如果现在发布，可能排到第二名。Sergey 希望能排第一，所以还要再刷一刷，主要是 forscience 的一些问题。
Jeff Dean 去做的 Discovery Loop 的目标是 RSI？是否看好这个 startup 的路线和前景？
他们的目标是用 RSI 去做现在 RSI 还无法实现的事情。RSI 是一个比较主观的概念，通常指的是用大模型辅助方法让训练更快、更高效，但本质上还是训练Transformer。JeffDean 的目标是用 RSI 解决模型架构的问题，希望找到更好的架构。现在硅谷有很多 RSI 公司，有些是用 RSI 做产品，比如生命科学领域，有些是构建 RSI 的 framework，但不发明新的药物或蛋白质，也不像 Jeff 那样发明比传统更好的东西。Jeff 的模式是只卖 RSI 的 framework 和方法，类似于一组 agentframework，帮助发现新东西。他实际上做的是第三种模式，想解决Transformer 的一些问题，找到效率更高的方法。

近期是否看到客户对开源用量在显著提升？未来半年的趋势是什么样？
这要看企业类型。比较喜欢用开源的企业主要是一些特殊垂类，比如 healthcare、金融、政府类客户，他们有自己的原因更倾向于开源。最近像 Anthropic 有一个新部门，提供模型训练服务，适合非常大的企业。如果企业不想用 Anthropic 的模型，担心数据外泄，想用开源模型但自己搞不定，可以让 Anthropic 提供服务，企业提供数据，Anthropic 帮忙训练模型，训练好后收服务费和维护费，但模型所有权归企业，数据 Anthropic 不能用。这也是开源模型的一种竞争方式。OpenAI和 Gemini 也准备做类似服务，这属于比较高级的模型训练服务。类似 FireworksAI 也在做这类服务，但没有那么多科学家手把手帮忙训练。
从 Vertex AI 平台客户来看，哪些客户在一直追求最 SoTA 的模型？
还是要分行业，比如简单的客服审核并不追求 SoTA 模型。现在有些法律相关的应用，最近排行榜上法律类模型很受关注，还有反荡词相关的榜单。用高端模型的主要是法律和金融投资领域，像 GeminiPro 这样的模型，还有一些科学场合也在用。因此成立专门做法律 agent 的部门是有原因的，法律领域确实需要SoTA 模型。
像 SSI 这种因无法满足其 TPU 需求而流失的客户多吗？对三四季度 GCP 收入影响是否显著？
收入影响不大，因为算力已经用到上限。SSI 以外像 Meta 也想用更多算力，但现在没法满足。Meta 自建的数据中心还没有那么快 ready，所以想租些算力，它有很多项目。最大影响还是 SSI。
Meta 在租算力方面有什么情况？他应该会租 GB300 吧？会从哪家租？
目前只知道 Meta 正在建设很多新的数据中心。Meta 比较有意思的是，自己的一些老卡会租出去赚钱，但也缺高端的 GB200 以上算力。
Google 现在拿到多少 TPU V8？是不是都是 V8I？全年会有多少 V8I 和 V8T？
现在都是 V8I，数量还很少。目前有一些 delay，到 Q3 结束时才会开始放量。  
今年预计不会特别多，大概小几十万。现在基本还是以 V7 为主。
Delay 的原因是什么？

主要是供应链原因，与 V8 本身设计没有太多关系，所以现在也开始对外租算力。对外租算力主要是跑模型，主要还是供应链问题。应该是今年（2026 年）第三季度结束后会开始有较大的量。
今年（2026 年）V6 和 V7 的产量是否也有下调？
现在主要算力还是依赖 V7，V6 已经没有新的了，目前都是 V7。今年（2026 年）不会做 training 的 V8T，只会做 V8i。V8i 主要是为 Anthropic 定制的，因为Anthropic 的模型基本都跑在 V7 上，没有定 V8T，基本都是 V8i。
GPT-6 Astra 和 Muse Spark 1.3 在 Coding 等能力的实质提升？
Astra 在 coding 方面，目前大家感受不到特别大的差距，但在一些中长尾的coding 问题，比如 debug test case 失败、网卡配置错误等，Astra 表现突出。这类中长尾问题在 terminal bench 4 里有体现，Astra 在 Fable 5 以上的表现较好，GPT 5.6 Sol 表现不佳。对于中长尾 coding，Astra 比 5.6 Sol 有很大进步。Astra 和 Fable 5.1 都是 3D Bench CAD 上的 SoTA 模型，Astra 比 Fable 5 高一个代际，比其他模型高好几个代际。在 3D 能力上，Astra 和 Fable5.1 并列领先。在 computer use 方面，Astra 对所有模型都有代际领先，主要是操作电脑，尤其是浏览器。
现在都是去刷 BENCH CAD 吗？为什么看到什么应用场景比较有潜力？
3D 能力大家都非常重视，现在 3D 模型已用于 worldmodel、游戏、机器人环境辅助、3D 打印等，应用非常实用，覆盖很多场景。3D 榜单也比较科学，容易刷，主要看半指 cd。其实大家并没有特别刷榜，半指 cd 是相对简单的问题，现在模型能做更难的任务。未来所有 SoTA 模型发布时，3D 能力都是重点关注的。
Muse Spark 1.3 的 coding 能力是否看到显著提升？
Muse Spark 1.3 Max 从参数规模来看是一线模型。在 coding 方面，尤其是中长尾问题，它远不如 Astra、5.1 和 Fable 5 这些模型，这些模型在长尾 coding 表现很好。Muse Spark 1.3 的 coding 能力和 Opus 5 差不多，Opus 5 在长尾coding 也不太好。3D 能力和 Fable 5 差距很大，可能因为训练时大家还没重视3D。computer use 也差很多，现在 meta 做得不错的主要是 browser use。Meta的 Muse 主要用于订票、抢票、定价等，属于 OS word 里中低端的 testcase。
是否看好 Muse 个人 AI 助手的变现前景？
Muse 之后可能要收费，价格也挺高。Muse 的 usecase 和 Manus、小龙虾差不多，但它有自己的虚拟机，比小龙虾更安全。买了 plan 后可以直接通过Prompt 使用，相对更安全，和北美流行的 instinct 类似。它比小龙虾更好用、更安全，但变现挺难。比如现在 MuseSpark 给免费用户每人一个 8G 虚拟机，硬件越来越贵，租 8GDRAM 一个月要 100 美金，还得长期租，所以能持续多久不好说。3D 能力目前已成为模型评估的重要指标，相关应用场景不断扩展，未来 SoTA 模型发布时 3D 能力将成为核心关注点。Meta 很快推出了收费计划，而且这个计划相对来说比较透明，至少在这方面比 OpenAI 更透明。它在计划中明确指出用户是否贡献数据。

Meta 的这种双轨制定价对客户是否明显更有吸引力？其他实验室会不会也采用类似定价策略？
Meta 的做法比较坦诚，明确说明数据可以被使用。相比之下，Google 不允许使用用户数据，而 OpenAI 最近与一些数学家之间有很多法律争议。OpenAI 实际上最新的发言人已经变相承认会用用户数据，只是做了脱敏处理。现在很多实验室，包括 OpenAI 和 xAI，都是这样操作的：C 端数据、Codex、Claude Code 等，都是脱敏后再用，而且是用大模型做脱敏，因为人工脱敏不现实。这涉及很多隐私问题。大模型脱敏其实很难做到真正透明，有些用户认为所有的 Prompt 和数据都是隐私，为什么可以被使用？所以行业整体并没有做到完全透明，但目前行业现状就是如此。
近期是否看到企业对开源模型的后训练和精调开始显著带动 BigQuery 的需求？
这个需要分开来看。开源模型的增长很快，尤其是一些企业自己购买硬件再做开源部署，这类企业增速非常快。可能和 Fireworks AI、Together AI 直接下场做 FDE有关。如果只做平台，很多传统企业 CTO 可能还不清楚什么是 posttrain，产品必须做得好才行。虽然增速快，但目前占比还是很小，能否达到闭源的一半甚至更多，现在还不好说。
最近 Gemini 发布了 3.5FlashCyber，这个主要用什么数据做后训练？目标客户和需求是什么？
主要用 CVE 数据，也就是各种漏洞及其分析。CVE 数据质量很高，基本都是经过验证的真实 bug。3.5FlashCyber 主要解决白盒分析问题，不是专注于黑盒，虽然也有一定能力，但最强的是在代码库里主动找 bug，或者在开源代码中帮助用户发现 bug。能在业务流中找潜在 bug，因为训练数据质量高且安全。
3.5 Flash Cyber 有没有和网安 SaaS 公司合作？
谷歌这边主要和 PaloAlto 合作。
最近 Crux AI 要部署 500 兆瓦 TPU，终端客户和上线时点？
主要是未来可能提供模型训练服务，或者自己部署。Gemini 现在允许私有部署，但只针对特别大的企业，可以断网部署 Gemini，但只提供权重，不是源代码。目前主要需求还是生物医药企业，未来主要为生物医药行业服务。

Gemini 最近是不是大幅缩减了 free 用户的 token quota？包括 contentwindow 也是吗？
现在大家都在做这件事，比如 OpenAI 不允许 200 美元用户注册，导致国内外200 美元用户账号价格被炒得很高。很多人在 OpenAI 宣布前注册了很多账号，200 美元用户。Answer 这边也多次缩减 quota，上周减了 20，又减了 25。Gemini一直在缩减，因为大家都在亏损，free 用户亏损较多，但 200 美元用户亏损更多。下半年几家准备把 200 美元提到 300 美元。另外大家都在检测谁是薅羊毛的，比如每次刚好用光 quota，最近的举措是如果检测到薅羊毛行为，下次 reset只给正常用户量的 50%。现在通过这种方式控制成本。
这是完全出于成本考虑吗？需求端有没有加速增加？
主要是为了减少免费用户的成本，200 美元用户主要是为了减少亏损。OpenAI 现在 200 美元用户按 token 卖的话，差不多要消耗 4000 多美元 token。
