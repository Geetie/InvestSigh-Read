## Q6 · 他用了哪几种**估值方法**？**能互相印证吗**？

只给一种方法：**概率加权的剩余收益（RI）模型**，没有第二种方法参与定价，因此**不能互相印证**。

方法与输入：

- 权益价值 = 期初权益 + 各年剩余收益现值 + 永续项；每股 = 权益价值 / 股数；
- 三档共用 **CoE 10%** 与**永续增长 3.5%**，明写"remain the same across all the three scenarios"，成本构成（RFR、beta、风险溢价）与上期不变；
- 差异输入是收入、利润率、ROE 路径，2026-36 逐年 ROE 与剩余收益在 RI 表逐行给出；
- 可复算核对：Eoptolink base 权益价值 695,808 / 994 百万股 = 700.0 元，与表内 Per share value 700.0 一致；三档加权 0.3×900 + 0.5×700 + 0.2×450 = 710，与最终 PT 一致。

P/E 只作现状参照、不进定价：12 个月 forward P/E 由 8x 升至 22x，Eoptolink 与 TFC 现价已高于历史区间 +1SD；TFC base case 隐含 P/E 64.5x、P/B 26.4x，Accelink 69.6x / 11.1x 也只是 RI 结果的反算，不是独立方法。

结论：单一方法 + 单点折现率（10%），无 WACC 区间、无倍数法交叉，估值结论对 CoE 与永续增长高度敏感而材料未给敏感度 ⇒ 无法互证。

## Q11 · 他的**风险章**挂了数字吗？

没挂数字，是**样板风险**（不是缺口）。每只股票的风险章分两栏：

- RISKS TO UPSIDE：更强 800G/1.6T 放量、渗透新 datacom 客户、CPO 推迟突破、国内网络投资加速（4 条）；
- RISKS TO DOWNSIDE：datacom 增速不及预期、800G/1.6T 需求弱于预期、CPO 或其他新技术提前突破、国内竞争致毛利承压、元件短缺（5 条）。

九条全是方向句，无一条附百分点、金额，也没有"若 X 变则 EPS/PT 变 Y%"的敏感度。本件唯一带数字的是情景假设（CoE 10%、永续增长 3.5%、三档长期净利 CAGR 与三档 PT），但那是情景结果、不是敏感度表——没有 CoE ±1%、g ±0.5%、目标倍数 ±1x 对应的 PT 变动。

因此按判据写不出"若〔变量〕变 X ⇒〔哪一年〕EPS 或 PT 变 Y%"，只能定性。这也意味着无法验证 PT 对折现率的脆弱性，而这恰是本件最大的软肋（单一方法、单一 CoE）。
