## Q1 · 他给的公司**未披露口径**的外部估算是什么？

一律标「外部估算」（FUNDA 自建渠道检查与自估模型，均非 AppLovin 披露）：

1. **电商广告环比路径**：1Q26 −11% QoQ、2Q26 +23% QoQ 且超过 4Q25 电商绝对额——本件最核心的预估，用来支撑「电商已重新加速」这一结论。
2. **代理商 A 的 AppLovin 预算同比**：1Q25–4Q25 为 56% / 30.4% / 97% / 68.6%，1Q26–2Q26 为 132.8% / 65.5%；该代理商 2025 年底自估 2026 全年 +44%，实际远超。样本 = 一家代理商自报，n=1。
3. **Apple Link-out 的增量**：自 12 月起给整个 iOS 游戏广告市场带来约 5.5% 增量，增量资金绝大部分流向 GOOG 与 APP；Link-out 为游戏公司省下的成本约为日本 2%、美国 9%，但广告主不会把节省的 100% 投回买量。
4. **竞价溢价压缩（代理变量 = 赢一次曝光所需溢价）**：过去 APP 需比 Unity 高 50%、比其他竞价方高 30% 才能赢，今年只需 5–7%——用溢价收窄代理买量成本下降。
5. **Audience Network 份额**：代理商 C 口径 1Q26 占其预算 2.1%（与 4Q25 持平），年底 2.3%–3%，但受访者自己说「还没有正式预测」。
6. **Unity 侧对照**：D28 留存 APP 44.7% vs Unity 40.6%；Unity 深度行为数据样本同比 +140%；Unity Vector 同比 100% / 173% / 159%、全年 68%。

样本与口径：七位专家（2 家游戏公司 + 4 家代理商 + 1 家电商平台），预算全是口述自报、无台账。第 1、5 项是 FUNDA 自己的判断，第 2–4、6 项是受访者估算经转述，两类都不能当公司口径；第 5 项的 2.1%→3% 是单家代理商占其自身预算的比例，不能当 Meta 或 APP 的市场份额。

## Q4 · 他的**假设与算式**能不能复算？

能复算的两条，加一条不能复算的和一条表体作废的：

- **Self Service 的贡献拆分（本件最关键）**：4Q→1Q 环比 +19%，其中 Self Service 贡献 10pp，剩下约 9% 来自 fully managed；若 managed 维持 9% 环比到全年，1.09^4 = 1.412，即 +41%，正落在文中「40–50% 全年增长」的下沿。复算通过——但要注意配套含义：区间上限 50% 还得靠 Self Service 再补约 8pp，材料没给这条路径，所以 40–50% 是靠 managed 的 9% 单独撑住的。
- **电商路径**：以 4Q25 = 100，1Q26 −11% → 89，2Q26 再 +23% → 109.5，比 4Q25 高 9.5%，与文中「2Q26 超过 4Q25 电商广告收入」自洽。复算通过。
- **不能复算**：Link-out 带来的「约 5.5% iOS 游戏广告市场增量」没有市场基数，也没有 5.5% 的推导步骤；Audience Network 的 2.1%→3% 没有分母（是哪家代理商的哪类预算）。
- **模型页表体作废**：收入预测表在版式解析后串列，电商行同时出现 110 / 174 与 −11% / 23%，而 110 与 −11% 互不对应（−11% 要求基数 123.6），所以该表不能作为复算输入，只能用正文口径。

结论：本件可用于模型的是「managed 9% 环比 ⇒ 全年 41%」这条复算链，其余是口径不明的口头区间。

## Q6 · 他的**自建口径 / 评级**定义是什么？与公司口径差多少？

无评级、无目标价、无打分体系。本件有三个「准口径」，只有一个可用：

1. **相对指引上限的超预期幅度**（自建尺子）：公司给的是 Ads Guidance 的 low / high 区间，FUNDA 把「实际收入 − 指引上限」定义为 beat，并用自身历史序列判断本季「超预期幅度会高于历史平均」。与公司口径的差在基准：公司口径是区间中点，FUNDA 用上限，同一季数字在这把尺子下天然更难 beat，方向上偏保守。这把尺子只能纵向比自己，不能横向比别家公司。
2. **Self Service 贡献 pp 的拆分**：把 19% 环比拆成 Self Service 10pp + managed 9%，定义清楚、可复算，是本件最干净的自建口径，可直接入格。
3. **收入预测表（含 TAC 45%、1P 游戏广告拆分）**：口径本意是「总预算 × 45% 分成 = 收入」，但该页表体解析串列（电商行同时出现 110 / 174 与 −11% / 23%，互不对应），定义无法复原，故这个口径不得用。

与公司口径的差异方向：本件所有「占比」类数字（预算占比、电商占 APP 支出比）都是受访者自报的分母，不是 AppLovin 披露的收入结构，因此不能与公司财报的 Software Revenue 构成相比。

## Q8 · 他的**行业级判断**（产能 · 份额）有数据支撑吗？

份额类断言全部来自 n=1 到 n=4 的访谈，只能当方向，不是读数：

- 「对多数有游戏敞口的广告主，AppLovin 已成为第三大广告平台」——口径是单一代理商服务的客户群，不是市场份额统计。
- 一家游戏公司的预算拆分：GOOG 40% / META 30% / 其它 30%，其它里 AppLovin 约 40%（即其自身预算约 12%），且随游戏进入成熟期上升——单一大客户自报。
- Audience Network：1Q26 占该代理商预算 2.1%、与 4Q25 持平，年底 2.3%–3%；而另一家说「还没真正开始」。同一件事两三个受访者给出不同数，本身就说明这不是读数。
- Link-out 渗透：美国约 10% iOS 流水、东南亚 25–30%、另一家游戏公司估 15–20%；广告预算侧 1Q26 已有 10–15% 走 Link-out。四个数不同口径（流水 vs 预算、地区不同），不能合成一个渗透率。
- 作者自己的行业判断：「未观察到 Meta Audience Network 对 AppLovin 有任何影响，也没看到 Meta 准备做非 IDFA 竞价」，同时又承认 Meta 已大幅加人对标、后续 DSP 功能会更多——这是观点，不是份额读数。

判断：全篇没有一个可回溯的行业份额数字（无统计口径、无地理范围、无基数年份），份额与产能结论一律记「观点」。
