## Q1 · 他给的公司**未披露口径**的外部估算是什么？

本件主体是 AI Agent 行业而非某公司，所有数字都是拾象社群对市场的估算，没有一家公司的披露口径可比。逐项（均为外部估算）：① 单价与消费——C 端订阅习惯是 \$20/月或 \$200/月，已有团队人均 Token 消费达 \$500/月，市场在酝酿 \$1000–2000/月的高价值 Agent 定价，代理变量是"人均 token 开销"，样本是社群内的若干团队，不是行业抽样；② 用量增速——2026 年 Token 消耗量至少 10 倍于 2025 年，甚至更快，口径未定义（含不含缓存、embedding、训练）；③ 渗透差距——全球 20 亿人用过 Chatbot，真正用过 Agent 的可能只有几千万，中间是 50–100 倍差距；④ 单位经济——推测 Claude Code 作为高溢价 Coding Agent"单体 ROI 很可能已经转正"，无成本拆分、无客户数；⑤ 定制硬件量——Manus 云端统一分配 8000 台虚拟机。判断：③④⑤是"量级判断"，①口径可读但样本极小，②没有可换算的基数，全部只能当量级，不能入格。

### 依据
- p.7｜过去用户在 C 端习惯的订阅价格通常是 \$20/月，或者是稍贵一点的 \$200/月。但事实上，已经有团队目前人均 Token 消费已经达到了 \$500/月的水平，市场已经开始出现并酝酿定价在 \$1000 - \$2000/月的高价值 Agent 服务。
- p.7｜有观点推测，Claude Code 作为一个高溢价的 Coding Agent 产品，单体 ROI 很可能已经转正。
- p.8｜因此，一个激进但又合理的预测是：相比 2025 年，2026 年的 Token 消耗量预计将有 10 倍甚至更多的增长？甚至还会是一个更夸张的速度。
- p.17｜目前全球有 20 亿人使用过 Chatbot（如 ChatGPT、豆包等），但真正使用过Agent（如 Claude Code、Manus）的人数可能只有几千万的量级。

## Q2 · 他的**物理量**从哪来、能不能核？

只有三个准物理量，全部无法回溯。① 8000 台虚拟机：指 Manus 在云端统一分配的自有算力池规模，无时点、无机型（几核几 G）、无地区、无出处，只作为"中心化路线"的举例出现，记为来源不可回溯，数值降为旁证；② 16GB 内存的 Mac Mini：说的是运行 OpenClaw 的本地硬件门槛，这是产品说明书式的配置参数，可核（苹果规格），但它只说明单机门槛，不能推出任何群体规模；③ 10 万级并发：指 CPU 侧沙盒"支撑 10 万级并发非常容易"，同样无测算、无厂商报价支撑。真正的物理量——GPU 张数、机架、电力、晶圆——全篇一个都没有，只有一句"GPU 将再次进入买不到的紧缺状态"的定性判断。因此本件不能用来做任何算力供需的量化，只能读它的逻辑。

## Q4 · 他的**假设与算式**能不能复算？

关键结论是"Agent 要从几千万用户走到几十亿，中间差 50–100 倍"，这条能复算：分母取"几千万"（按 3000 万），分子取"20 亿"，算式为 20 亿 ÷ 3000 万 ≈ 66.7 倍，落在 50–100 倍区间内，复算通过；若分母取 2000 万则为 100 倍、取 4000 万则为 50 倍，说明这个区间本质是分母的敏感度，而非独立测算，只能当量级。另一处算式对不上：他讲 Polymarket 事故时给"单次下注额度 500 美金""重复下注 40 次""总投入 1.8 万美金"，若每注都是 500 美金应为 2 万美元，与 1.8 万差 10%，说明部分下单未成交或金额不等，材料没有交代，属缺一步不能复算。至于"Token 消耗 10 倍""高价值 Agent 定价 1000–2000 美金"，全是只给结果，没有任何基数与乘数，无法复算。

### 依据
- p.17｜而 Agent 代表了一种全新的交互范式，要把这个新范式的用户规模从几千万带到几十亿，中间存在 50 到 100 倍的巨大差距。
- p.14｜原本设定的单次下注额度是 500 美金。
- p.14｜这导致 Agent 误以为任务失败，于是不断重试，最终重复下注了 40 次，总投入金额高达 1.8 万美金，第二天事件反转后，该博主直接亏损了 1.4 万美金。

## Q6 · 他的**自建口径 / 评级**定义是什么？与公司口径差多少？

他自建了三把尺子。① "AI-native 程度"＝Token 消耗占比：定义原文是"使用 Token 的比例越大，说明越 AI Native"，并明确否掉 UV／日活这套旧指标；与公司口径的差异在于方向相反——公司按收入和 DAU 报，他按成本侧（token）报，且没给"比例"的分母（占总成本？占总请求？），所以只能定性比较两家谁更"重 token"，不能算倍数。② "高价值 Agent"＝能替代或大幅增强专业人力、从而切企业工资预算（而非 IT 预算）的 Agent，这是定价跃升到月费上千美元的依据；与 SaaS 口径（按席位／按功能）差在计价基础，差多少未量化。③ "Token 与 Token 不等价"：小参数模型与专用芯片（Cerebras）产出的 token 与大模型 token 不同质，因此"10 倍 token 增长"这个口径不能跨模型加总——这一条必须带着走，否则 10 倍会失真。

## Q8 · 他的**行业级判断**（产能 · 份额）有数据支撑吗？

他的行业级判断有三条，全部是观点不是读数。① 供给："去年部分 GPU 可能还卖不出去，今年在 Agent 爆发驱动下，预计未来一年内 GPU 将再次进入买不到的紧缺状态"——没有任何出货量、晶圆产能、机架数或交期数据，纯推断；② 需求：2026 年 Token 消耗 10 倍增长，靠 Long-horizon task、Proactive Agent、多模态三条主线驱动，无口径、无基数；③ 结构：开源模型"下限达标"后会蚕食中低端市场、倒逼闭源冲上限，并称这是"2026 年开源模型 Token 消耗的大爆炸"——同样无份额百分比、无统计范围（全球／中国）、无年份对齐。唯一带数字的是"20 亿 Chatbot 用户对几千万 Agent 用户"，但两者都不是同一统计口径下的活跃用户定义，只能当量级。结论：本件的价值在把 Infra 缺口（Agent 专用浏览器、支付、安全审计）和"切工资预算"的商业逻辑讲清楚，不在任何产能或份额读数。

### 依据
- p.11｜总的来说，市场对 2026 年全球 Token 消耗量持极度乐观态度，唯一的制约瓶颈可能在于硬件供应。去年的状态是部分 GPU 可能还存在卖不出去的情况，但在今年 Agent 爆发的驱动下，预计未来一年内 GPU 将再次进入“买不到”的紧缺状态。
