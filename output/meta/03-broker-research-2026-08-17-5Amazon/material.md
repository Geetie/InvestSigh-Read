## Q6 · 他用了哪几种**估值方法**？**能互相印证吗**？

两种方法，而且**互相矛盾**，这是本件最值钱的一处发现。

**方法一（正式目标价）**：P/E 相对估值。约 25x 乘 '27/'28 平均 EPS 14 美元（滚动到年中），得 $335；等价于约 28x '27 EPS、约 22x '28 EPS。

**方法二（长周期路径）**：EV/EBIT 资本化 + 折现。把约 5,000 亿美元的长期 AMZN EBIT 乘 21x EV/EBIT（对同业均值约 23x 打约 10% 折），得长期 EV；按 10% WACC 折回 2028 年；减 2027 年末净负债 934 亿美元；除 2027 年末 111 亿股；得 2027 年末每股 $466–$537。

**能不能印证：不能，且方向相反。** 方法二在同一时点（2027 年末）给出的价格比方法一的正式目标价高 39%–60%，而方法一的时限恰好也是 12–18 个月（即 2027 年末前后）。同一篇里两个方法指向不同的 2027 年末价格，而他既没有说明为何正式目标价不采用长期模型的结果，也没有说明两者如何衔接——只在前言写"bull case increasingly in play"。所以这不是"两法互证"，是"两法并存且未调和"。

另一处可核的反向自洽：方法二自己也给了一个"现价隐含多少"的镜像算法——现价约等于 11x 折回后的 5,000 亿 EBIT（约 2,650 亿），对同业约 50% 折价。这条与"现价 $263"能对上，说明方法二的内部算术是通的；问题不在算错，而在于它与正式目标价的选择不一致。

## Q11 · 他的**风险章**挂了数字吗？

**挂了，而且挂了两套**——这在 MS 件里不常见。

- **第一套：变现率的股价敏感度**。每增量瓦特变现 $11 / $12 / $13 / $14 / $15 对应 2027 年末每股 $466 / $488 / $505 / $521 / $537，上行 77% / 85% / 91% / 97% / 103%。这是能直接写成"若〔每增量瓦特变现〕变 +$1 ⇒ 每股价格变 +$16~19"的真敏感度。
- **第二套：收入路径敏感度**。同样五档变现率决定 AWS 何时到 1 万亿收入（2036 / 2035 / 2035 / 2034 / 2034），以及每年 960 亿美元的稳态增长额。
- **缺的一套：WACC 与倍数的敏感度**。10% WACC 与 21x EV/EBIT 都只给单点，没有 ±1% / ±1x 的敏感性；P/E 法那边 25x 也只给单点。所以"折现率或倍数变一点，$335 会变多少"这一问在本件无答案。
- **公司风险条目本身无数字**：下行三条、上行三条全是方向句，不附百分点或金额。

判：**不是样板风险**——它有真敏感度（变现率→股价），缺的是折现率与倍数维度的敏感度，以及风险条目到 EPS 的传导。
