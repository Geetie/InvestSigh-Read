# 4A 验证 · 机器人产业链差异清单（组合 A：绿的谐波＋埃斯顿＋博实）

> 流程：通用网标准版 → 机器人产业链网（差异清单 1）→ 三家公司各自差异清单（差异清单 2）。
> 数据：调研十一（位置差异）＋调研十四（三公司披露面核实）。性质：纸面实例化验证。

## 一、机器人产业链网 · 差异清单 1（vs 通用网标准版）

| 操作 | 对象 | 理由（带调研证据） |
|---|---|---|
| **加** 起点节点 Y21 订单与合同 | 在手订单/book-to-bill/定点公告/审厂进度 | 装备制造业核心需求先行指标：backlog 领先收入 3-9 个月（调研十二）；博实官方公告 56.66 亿、绿的定点排至 2027（调研十四） |
| **加** D1 内传导链 | 审厂→定点→小批量 PO→量产订单→海外产能 | 人形机器人链固定传导路径（调研十一），上游订单领先整机出货 2-4 季 |
| **改** D3 价格族 | 强化"位置不对称"标注 | 整机降价 72% 上游毛利率稳 40-55%——降本由中游承担、上游吃量不吃价（调研十一） |
| **改** F2 周期位置参数 | 装备制造业改"下游客户 capex 周期"传导 | 设备需求由下游行业资本开支周期决定（调研十一/十二） |
| **激活** 链上传导边 | D1/D2/D3 的跨公司输入 | BOM 拆解传导、供应链审厂周期（调研十一第六节） |
| 复用不变 | 通用核全部（T1/E1-3/F1-6/D1-8）与 19/20 起点节点 | 节点重合度 38→39（净加 1）——**通用核跨产业链成立** |

## 二、三家公司 · 差异清单 2（各 vs 机器人产业链网）

### 绿的谐波（上游减速器）

| 操作 | 对象 | 理由 |
|---|---|---|
| 改 F1 披露等级 | A→**B 级**（量官方、价推导） | 官方披露销量 42.52 万台＋分产品收入，单价精确可推导、官方不报（调研十四） |
| 标 Y11 强源 | 产能利用率官方序列（43%→68%） | 上游第一驱动，官方披露完整 |
| 改 Y21 代理 | 在手订单仅第三方口径（8 亿/排至 2027） | 官方不披露订单金额（B 模式：代理＋置信分级） |
| 改采集面 | 年报/定增文件为主 | 信息渠道分化（调研十四：绿的走年报/定增） |
| 权重 | D2 供给族最高、D7 技术族高 | 位置敏感度表（调研十一） |

### 埃斯顿（中游本体）

| 操作 | 对象 | 理由 |
|---|---|---|
| 停用 F1 量节点 | 量价 **C 级**：官方零量披露 | 通行量数据（3.34 万台、市占 10%）全部来自第三方 MIR（调研十四）——代理（B 模式） |
| 标 Y12 强源 | 竞争信号：MIR 份额登顶 | 第三方背书是公司行业地位的主证据 |
| 权重 D4 最高 | 规模效应拐点：毛利率年升 1-1.5pct 目标 | 中游是降本主承担者（调研十一），公司在业绩交流会明示目标 |
| 改采集面 | 业绩交流会为主 | 埃斯顿走交流会披露指引（扣非 2 亿等） |
| 权重 D5 高 | 价格战主承担方 | 中游净利率仅 5-8%（调研十一） |

### 博实股份（下游集成）

| 操作 | 对象 | 理由 |
|---|---|---|
| 停用 F1 量节点 | 量概念不存在（项目制） | C 级：无量纲披露（调研十四） |
| 改 D1 为"订单-交付"节点 | 需求=项目订单与交付验收 | 下游需求形态（调研十一：项目订单/交付周期/回款） |
| 标 Y21 官方强源 | 在手合同 56.66 亿官方公告（智造装备 44.01 亿） | **下游反而提供最强的官方需求先行指标**（调研十四互补发现） |
| 改 F5 营运资本重点 | 应收+合同资产+合同负债三件套 | 下游营运资本结构（调研十一） |
| 改采集面 | 逐笔重大合同公告 | 博实走合同公告节奏 |

## 三、验证结论

1. **位置层起作用**：三张差异清单的关键差异（Y1/Y11 量价强弱、Y21 订单源强弱、D2/D4 权重）严格按上/中/下游分布，与调研十一位置差异表一致——**差异落在位置层，没有雷同**；
2. **跨产业链鲁棒**：38 节点机器人网净加 1 个（Y21），通用核全部复用——与 Meta 网的节点重合度 >95%；
3. **公司层（披露差异）由差异清单 2 承接**：量价等级三档（B/C/C）、采集面三种（年报/交流会/合同公告）——披露差异不侵入网络结构；
4. **意外发现登记**：下游公司反而是官方需求先行指标最强的位置（博实官方在手合同 vs 绿的只有第三方口径）——"上游看产能、下游看订单"的位置直觉在披露维度是**反向**的，位置敏感度表按此修正。
