# 通用探测器网络 · 建模 v1（阶段 2 产出）

> 依据：调研八（通用核最小集）＋调研九（目标面×材料分布矩阵）＋调研十（边界四模式）＋调研十一（位置差异）＋调研十二（链内传导）＋调研十三（公共网接口）。
> 架构根基：网络瞄准公司；公司间差异由产业链×产业链位置决定；四层差异（通用核/产业链层/位置层/公司层）由差异清单机制处理。

## 一、通用骨架（从 L0 逆推）

```
T1 价值判断（终点：价值格更新提案 → 卡面篮子格＋变更提案五列）
 ├─ E1 盈利预测（盈利腿 EF：收入增速 × 利润率路径）
 ├─ E2 风险感知/倍数（折现率腿：尾部风险·竞争·治理·情绪·利率）
 └─ E3 资本配置（现金腿：FCF 路径·回购融资·配置原则）
      ↑
L2 通用盈利恒等式（调研八通用核，全部公司共享）
 ├─ F1 收入因子：收入＝量×价×组合（带披露等级 A/B/C 探测）
 ├─ F2 利润率因子：毛利−费用−一次性（带周期位置强制参数）
 ├─ F3 再投资因子：capex＋研发＋营运资本占用（g＝再投资率×ROIC）
 ├─ F4 现金桥：FCF＝OCF−Capex（预置三替换桥：内容/租赁/监管资本）
 ├─ F5 营运资本：CCC 双符号＋预收修正（先收后付行业反号）
 └─ F6 分部因子：分部贡献与亏损（多元化集团强制 SOTP）
      ↑
L3 通用驱动族（八大族，带位置敏感度标注）
 需求 D1｜供给 D2｜价格 D3｜成本 D4｜竞争 D5｜政策监管 D6｜技术 D7｜资本 D8
      ↑
起点节点（探测目标面，只收集——面定义与觅食面见登记表）
```

## 二、双向核查补线记录（本轮发现并补上的线）

对每个节点声明全部上游需求、每个下游声明全部供给，双向对照后补上：

1. **管理层可信度节点**（v5 有、初稿漏）：聚合 Y5 回避＋Y6 措辞＋兑现记录（假设账）→ 调节 **E1 对 Y2 指引的采信权重**与 E2。它是调节节点：不直接产出判断，改变上游对信息的处理方式；
2. **D 层横向交互边**（初稿全部缺失）：D2 供给过剩→D3 价格战；D1 需求萎缩→D5 竞争加剧；D7 技术→D5 竞争重构（技术替代是调研十二的失效模式，同时是竞争族的输入）；
3. **F5 营运资本**（初稿漏）：先收后付行业（SaaS/订阅）CCC 反号——不补则这类公司 OCF 优于净利被误读；
4. **F6 分部**：多元化集团单树失效（调研十边界 5）→ SOTP 强制化；
5. **公共网挂接**：Y9 共识/Y14 情绪/Y20 宏观属公共节点（单实例维护）——公司网引用时走 kit 摘要件，缺席走状态 4（调研十三）；
6. **链上传导输入边**（跨公司边）：D1/D2/D3 接收"链上传导输入"（下游客户动量→本公司需求；上游成本→本公司成本）——标注调研十二 8 字段（方向/权重/时滞/放大系数/转嫁条件/失效模式/双探针/不对称）；
7. **F1 披露等级探测**：量价披露 A 级（官方量价）/B 级（量官方价推导）/C 级（仅收入）——Netflix 停报类事件使等级降档（调研八＋调研十）；
8. **F2 周期位置强制参数**：周期行业 boom 年利润率不得直接外推（高估 87% 算例，调研十）；
9. **E2←D8 资本族**：利率/流动性→折现率（公共网挂接主通道）；
10. **D8→D2 融资→产能**：绿的 14.13 亿定增直接决定 100 万台新增产能（调研十四）——装备业扩产常识边（红队 Z6）；
11. **D6→D1/D2 管制→可售范围**：出口管制改变可售范围（调研九政策面）——政策不只进尾部风险，直接改需求与供给的边界。

## 三、探测器登记表（38 个 × 7 字段）

字段：①聚合 ②收集 ③觅食面（带调研九矩阵证据）④上交 ⑤论证 ⑥边界情况（四模式：替换 A/代理 B/降级 C/旁路 D；内嵌参数：披露等级 disclosure_status / 代理层级 proxy_tier / 置信上限 confidence_cap / 周期位置 cycle_position）⑦消费方清单（**仅公共节点必填**，其余节点该列省略）。
**全局字段层**（每节点登记时必填三枚举）：disclosure_status（A/B/C）／proxy_tier（官方 1 级→第三方 2 级→推算 3 级）／confidence_cap（置信上限，随 proxy_tier 与覆盖度下调——proxy_tier≥3 且无共识时输出强制"区间＋禁预期差"，调研十 Z9 修法）。
**起点层收敛（红队 Z7）**：5 个纯中继节点（Y12/Y13/Y15/Y16/Y20）并进对应驱动族的②收集列——起点层从 20 收敛到 15；起点节点的角色是"探测目标面索引"，合并后避免同一张卡被两个探测器重复扫（调研九 §五建议采纳）。

## 四·补3 · 边界叠加规则（红队 Z9 修正）

四模式叠加时的仲裁：
1. **A 激活（行业结构失效）时**：D/B/C 的路径库整体切换为 A 模式内路径——银行＋零覆盖：reverse DCF 旁路失效（建立在 FCF/倍数上，银行全不适用）→改用 insider 流＋监管文件节奏＋行业月度数据（调研十现成）；
2. **proxy_tier≥3 且无共识**：输出强制"区间＋禁预期差"（B/C 模式的置信铁律在共识消失时的落点）；
3. **停报＋周期股**：cycle_position 需 7-10 年序列、停报使探针缺输入→A 模式建立在被降级数据上＝降档为"区间＋标明数据断代"；
4. **回边**：低层失效（C 降级）反向触发上层重判——某节点降级后，其全部上游的采信权重重估（可信度调节的推广）。
