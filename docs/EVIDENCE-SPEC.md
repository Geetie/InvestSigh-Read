# 原文证据登记

## 需求

Agent 回答问题、登记数据时，**必须连带登记支撑它的原文**。
只填了答案、没填原文块 → 不合格，回去找。

---

## 1. 摘录是什么

**就是从 MinerU 出的那一页文本里，原样抄下来的一段。**

- 不改字、不加标点、不概括、不省略、不换语序；
- 不用省略号截断：要么抄完整的一句/一段，要么就不登记；
- 抄出来的这段，必须能在该页原文里被搜到 —— 搜不到就是编的。

## 2. 模板长什么样

**答案正文保持干净**：不写页码、不写括号引用。页码只出现在依据区。

```md
## Q1 · 读数属于哪层哪一环

单月营收 2,583 亿元，同比 +34.2%，产能利用率 96%。

### 依据
- p.3｜单月营收 2,583 亿元，同比 +34.2%
- p.3｜产能利用率 96%，环比持平
- p.7｜CoWoS 月产能由 3.5 万片扩至 7 万片，2026 年底达产
```

依据区一行一条：`p.N｜原文片段`。

**这一区是双向的**，两边都读它：

| 谁读 | 读它做什么 |
|---|---|
| 后端 `server/validate.mjs` | R1（有答案必须有块）、R2（块须逐字可搜到）—— `node server/check.mjs` |
| 前端 `src/pages/DetailPage.tsx` | 详情页右栏「原文依据」按 `p.N` 翻页、把登记的片段列出来、在原文里高亮命中句 |
| 后端 `server/parse-md.mjs` | 解析成 `evidence[rowId] = [{page, quote}]`，是上面两方共同的数据来源 |

所以依据区空着不只是「没过校验」——**页面上右栏会显示「这条答案的依据区还没登记原文」，读者看不到任何出处**。
（旧版曾靠答案正文的 `[p.N]` 翻页，那条路已降级为 v1 旧材料的兜底。）

## 3. 规则

| | 规则 | 能不能查 |
|---|---|---|
| **R1** | 有答案的行，依据区至少一条块 | 能查 |
| **R2** | 每条块是第 N 页原文的逐字片段 | 能查 |
| **R3** | **所有**依据都要找到并登记，有几处登几处，不许只登一段交差 | **查不了**，写进模板强制 |

R3 查不了，所以它必须在提示词里说死：**"材料里有几处支撑就登几处"**。
校验器只能保证「登记了的都真」，不能保证「真的都登记了」—— 这一点不许含糊。

## 4. 缺了怎么办

1. 写完答案，回原文找支撑；
2. 依据区逐段抄进去 —— 抄不出来就回 `full.md` 再找一遍；
3. 还是找不到 → **把这句从答案里删掉**，或整句改成「材料未给出此项」；
4. 不许留没有原文支撑的断言。

> **反斜杠要原样保留**。MinerU 抽出来的原文常带转义：`\$725.00`、`\~14%`。
> 抄成 `$725.00`（去掉反斜杠）会判 `unverified`——校验是去空白后的子串匹配，不清理转义。
> 已实测：带反斜杠 → `ok`；去掉 → `unverified`。

## 7. 图的依据怎么算（2026-10-27 增补）

图**不能单独当文字依据**，因为依据区要求逐字可核。三条规则：

1. **图里有可抄的文字**（表格单元格、图题、坐标轴标签）→ 抄该文字，标该页 `p.N`。
2. **图是纯图像**（走势图、照片、示意图）→ 答案正文写「见 p.N 第 k 张图」，
   依据区登该页图题/图注的原文。
3. **连图注都没有** → 答案里写明「判断依据为该页图表，无文字可引」，依据区留空。
   这是**唯一允许的「有答案无依据块」例外**，且必须在答案里说清楚。

**禁止**：把从图里"看"出来的数字当逐字原文抄。OCR 读图会错（`GOOGL`→`G00GL`、`2026`→`2O26`），
数字要引就必须从文本层逐字核到。
