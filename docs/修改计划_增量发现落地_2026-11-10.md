## 阶段一：修 03 类缺口（供件 + 第四态 + 守卫）——最实，先行

### 1.1 写法规范.md：「材料的三种状态」扩为四种

- 新增第四种：**对照面不在场**——这道题需要对照的东西（指引账摘要、上季材料、公司口径摘要）本批材料包里没有。合法落纸一句："〔对照物〕不在本批材料内，留待对照"，**照此登记，禁删节**（登记题尤其如此）。
- 区别写清：状态 2（材料不含）是"确认了它不在"；状态 4 是"要对照的东西没送来"——性质不同，前者是读数、后者是待办。
- agent 逻辑变化：遇对照面缺失不再删节，改写留待对照句 → Q8/15/16 不再集体消失。

### 1.2 RUN-PARALLEL.md 与备批脚本：材料包供给规则（含门禁，不是一句提醒）

- §1 或 §2.2 加一条：03 卖方与共识类批的投喂清单**必须含**指引账摘要件（output/meta/_ledger-guidance.md 的当季相关行）与 02 类公司口径摘要（公司指引与口径变动一句话）；缺件时批任务块注明"对照面不在场"，agent 按 1.1 第四态处理。
- **门禁（机器强制，不是口头规则）**：批次环境.json（备批写入，本就记录投喂清单）备批时校验——03 类批清单缺"指引账摘要件"或"02 口径摘要件" → **备批脚本直接停，不进跑批**；跑批侧 check 遇 03 类卡缺 Q8/15/16 且批次环境声明"对照面不在场" → 走第四态不拦；批次环境无此声明 → 按硬门禁拦。
- agent 逻辑变化：03 类批开工时手上必有对照物（门禁保证），Q8/15/16 可答；实在无件时第四态兜底且有据可查。

### 1.3 新建我方假设账：output/meta/_ledger-assumptions.md（注意：这是登记账，不是基线）

- **概念分清**：我方假设账是**登记账**（与指引账同性质：记"谁在何时说了什么、何时到期、兑现没有"），作用是**对照物**——解决 6 题"要对照的东西不在场"。**基线**是另一层：从账与卡提炼出的"平时的样子"（兑现偏差分布、措辞历史形态）——账是原料，基线是加工品；基线在阶段三建（措辞基线账等）。
- 格式照指引账（追加式、来源可回溯、缺口不编、重算留痕）：每行 = 带时点的承诺/假设（内容 + 谁说的 + 何时到期 + 兑现状态 + 核账处 + 来源材料 id）。
- 首版回填数据源：已有卡（02 电话会卡 Q10 登记过的七条承诺等）+ 03 卡的假设登记——由回填脚本抽取、人工抽检。
- 解决：6 题"账本:我方假设账"的对照面（02 Q10、03 共识 Q7、07 预期差 Q9 等）。

### 1.4 03-型/投行研报.md：Q15 三态 → 四态

- 复述 / 加工 / 冲突之外加第四态**待印证**（"无可印证基础"的正式归位）——冲突态升级为带处置动作（登记双方各自的可视范围差异，触发"调查原因"）。
- agent 逻辑变化：Q15 永远可答（四态之一），不再被"整节删掉"规则误伤。

### 1.5 server/check.mjs：登记题守卫（分两步走）

- 第一步（本阶段）：03-投行研报型的卡，Q15/Q16 缺失 → 软观察报警（不拦交付），跑两批看误报率；
- 第二步（误报率确认低后）：升硬门禁（该型 Q8/15/16 缺失 = 不合格）。
- 风险：存量 163 份 03 卡会大面积报警——软观察期正好量化这个存量缺口，作为"待重填"队列证据；硬门禁只对新产出卡生效（按 templateVersion 与产出日期区分）。

## 阶段二：写法规范一体化重写（判断程序＋口径＋篇幅＋中文语序一次成形）

### 2.1 写法规范.md：**整体重写，一次成形**（不做分批补丁）

> 理由：这些新节共享同一套概念体系（两道工序/增量判断/口径主尺/中文语序），分批往里加节就是你批评过的补丁式落地。一次成形，术语唯一。

一次重写包含**全部**六块（缺一不可）：

1. **两道工序重构**：§先分清两件事（想/写）升级为明确的"构思工序 / 落纸工序"两章——构思章含**§增量的判断**（白话版概念体系：一句话/两道关/六个类型及各自查法/四个刻度/基线对照与降级纪律/来源三要素/知识账）；落纸章含既有表达纪律 + **增量就地叙述的组织规则**（构思挂哪题就写哪题，不搬家）；
2. **§口径分层**：四视角（有机增长/核心经营利润/FCF/披露口径）+ 三条护栏（Item 10(e) 两年复发测试/折旧年限变更必录/capex 拆分标自行估算）+ 重资产阈值标注为自设启发式初值；
3. **§篇幅跟信息量走**：句数上限降为参考中值，唯一硬约束=删句测试（升级版：删掉后读者对结论的信心和再验证能力不变才删）；
4. **§中文语序**：A 层欧化治理（被动句滥用/代词显化/系动词回避/填充短语）+ B 层 AI 痕迹（句尾拔高语三正向操作/软词表带语境豁免）+ C 层术语纪律（术语在线官方库/三段式惯例）；
5. **材料四种状态**：三种 → 四种（对照面不在场），登记题禁删节的豁免条款；
6. **工序的话禁令精确化**：区分"工序动作流水账"（禁）与"论证实质结论"（用读者语言落纸，必须）——这是老板问题 1 在规范层的根因修复。

- agent 逻辑变化（一体化后）：构思工序跑增量判断与口径判断（对照基线账/口径账）；落纸工序按表达纪律呈现——两道工序各司其职，可读性闸口在落纸，判断力在构思。
