# 视觉资源选型表 —— INVESTSIGH 七类信息 Dashboard 原型

> 原则：界面元素 → 具体视觉资源库组件。风格参考 ReactBits 但**不直接照搬**：保留其交互骨架与几何语言，改造配色（赛博朋克霓虹 on 深空玻璃）、密度与形态，使其成为本产品自己的界面。

## 0. 资源库结论

| 项 | 结论 |
|---|---|
| 主源 | **ReactBits** `DavidHDev/react-bits`（MIT）。**无官方 npm 包**，官方形态即"复制粘贴式源码库"。npm 上的 `reactbits-installer` / `@appletosolutions/reactbits` 为第三方仿制品，**弃用**。 |
| 变体 | 官方提供 `src/ts-default/**`（手写 CSS）与 `src/ts-tailwind/**`（Tailwind 版）。本项目 Tailwind 4 ⇒ **取 ts-tailwind 版**。 |
| 获取 | `git clone` 本机网络极慢（>10min 未 checkout）⇒ 改用 GitHub API：`/git/trees/main?recursive=1` + `raw.githubusercontent.com` 逐文件拉取。 |
| 本地落点 | `.vendor/rb/src/ts-ts-tailwind/**`（41 个候选），选中的 16 个 vendored 进 `src/vendor/`。 |
| 需装依赖 | `ogl@1.0.11`（CrystalizedBall WebGL）、`@hugeicons/react@1.1.10` + `@hugeicons/core-free-icons@4.3.5`（PromptBar / CallChip）。 |

┌────┬─────────────────────────────────────────────────────┐
│ 01 │ 顶横栏 PillNav：29 型细分型切换                        │  ← 左竖栏 LineSidebar
│ 02 ├─────────────────────────────────────────────────────┤
│ 03 │                                                     │
│ 04 │              主体（双形态）                            │
│ 05 │   日模式：材料载体卡挂在所属日点之上（SpotlightCard）      │
│ 06 │   时_分模式：材料名=列、问句/数据=行（缺格留空）          │
│ 07 │                                                     │

│ 09 │ 底部时间线：滚轮伸缩 · 日 / 时_分 · 一单位一点            │

      悬浮球 CrystalizedBall（右下角常驻，点击开 AI 输入框）

## 3. 关键交互契约

- **时间线滚轮伸缩**：`wheel` 事件改变时间跨度（tick 粒度），`deltaY` 正负决定进入更细/更粗；粗档 = 日（"9.6"），细档 = "_时_分"（"09:30"）。RubberSegment 亦可直接切档。
- **不遮挡**：AI 输入框与悬浮球都挂在独立层，主体的滚动容器为其留出 `padding-bottom`，任何时候数据区不被覆盖。
- **缺格如实**：`cells` 中不存在的 rowId ⇒ 渲染 `.hatch-missing` 斜线格，不写"无""N/A""未披露"等占位词。
