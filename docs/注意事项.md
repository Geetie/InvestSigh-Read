## 1. 平台差异：照抄 Windows 的做法一定会卡

| 环节                     | Windows（原环境）                                           | Mac 上可能不同                                                        | 应变原则                                        |
| ---------------------- | ------------------------------------------------------ | ---------------------------------------------------------------- | ------------------------------------------- |
| 浏览器位置                  | `C:\Program Files (x86)\Microsoft\Edge\...\msedge.exe` | `/Applications/Microsoft Edge.app/Contents/MacOS/Microsoft Edge` | 代码已内置三平台候选表；实在找不到就设 `PIPELINES_BROWSER` 指过去 |
| 路径分隔符                  | `\`                                                    | `/`                                                              | 代码全用 `pathlib`，不要手拼路径                       |
| 保存对话框导航                | `Alt+D` 聚焦地址栏（**本机实测有效**）                              | 没有地址栏；用 `Cmd+Shift+G`「前往文件夹」（**未在真机验证**）                         | 先试快捷键；不行就**直接存到下载文件夹再搬**——别跟对话框较劲           |
| Node / playwright-core | 已装                                                     | 可能要 `brew install node` + `npm install`                          | `npx playwright install chromium` 也可作为浏览器兜底 |
| 环境变量设法                 | `set` / 系统属性                                           | `export` / `~/.zshrc`                                            | 只影响 key 与浏览器路径，代码不依赖具体设法                    |

**判断"到底哪里不同"的方法**：跑 `python -m pipelines doctor`，它会逐项报当前平台的实际解析结果。报错了按它的 `→` 提示修，别凭记忆改代码。

### 2.2 知识星球：**三段式，型由内容判定**

> **不要按星球预设型。** 同一个星球（Dots）实测产出两份：一份个人研究笔记、一份播客访谈稿——
> 按星球分型会两发两错。

```
① python -m pipelines intake --as-of <今天>     # 拉全部星球 PDF + 抽正文 + 出清单
② Agent 读 _intake.json 的 items[].head          # 判定每份属于哪个型，写 mapping.json
③ python -m pipelines ingest --mapping <path>   # 按判定的型写 corpus/materials
```

**判读依据在 `corpus/prompts/03-型/` 的手册里**（投行研报 / 独立研究 / 专家纪要与渠道交流 / 媒体分析 / 共识与评级档位），先读手册再读材料；格式与 mapping 见 `docs/zsxq取数.md §2`。

**实测**（2026-10-28）：

| 文件 | 判定的型 | 依据 |
|---|---|---|
| `Robinhood_Q3_2026_Outlook_2027.pdf` | `03-independent-research` | 第一人称情景分析 + 两版估值，无券商署名/评级/合规声明 |
| `Indigo_郑迪_对谈全文.pdf` | `03-expert-channel` | 播客对谈文稿，19 章节 + 时间轴 + 嘉宾简介 |

入库形态：`needsExtraction=false`、`pageCaliber=physical_page`、按物理页分块、
`meta.classifyEvidence` 记着判型依据。

**老板唯一要做的事**：扫一次码。

```bash
zsxq-cli auth login     # 浏览器已登录时会自动确认；否则把链接发给老板
```

**拿不到的 3 个**（不要浪费时间）：

|---|---|

### 2.3 腾讯 ima：每天拿到各投研相关知识库**当天更新发布的 PDF**

| 条件            | 含义                     | 现状                       |
| ------------- | ---------------------- | ------------------------ |
| **各班投研相关知识库** | 不是她全部知识库，是**投研相关**的那几个 | 需人指定：看客户端里"订阅知识库"下哪些是研报类 |
| **当天更新发布**    | 只收当天新增/更新的文件           | 客户端列表带日期，按日期筛            |
| **PDF**       | 只要 PDF                 | —                        |

**ima 这条没有"配好就自动"的方案**（知识库只在桌面客户端内，web 无视图、无接口，  
六条路都排除过）。所以每天必须有人在客户端里点"下载"。你能做的是把人的成本压到最低：

1. 建好目录 `pipelines/_landing/ima/<日期>/`
2. 给人**一句话**（含目标目录 + 只需点下载）
3. 收到后校验 `%PDF` 头 + `%%EOF` 尾 + 页数 > 0，报"收到 N 份"

> 如果你发现某个 ima 知识库其实是"订阅"来的公开库，先确认它的文件能不能通过别的公开渠道拿到——  
> 能的话走自动通道，比每次让人点强。

## 3. 入库纪律（这部分是**你的操作要求**，不是代码逻辑）

### 3.1 直接进 `corpus/materials/`

没有"待处理暂存区"。`pipelines/_landing/` 是**原件副本**（留档、可重放、不进 git），  
不是队列——入库走的是内存里的那份，不从 `_landing` 读回。

### 3.2 入库前**你必须打开读**

这是**指令层面的强制**：不要跑完 `run` 就当完事。

> **zsxq 的 PDF 尤其如此**：它们的型不是取数时定的，而是**你读完内容后定的**。
> 走 `intake → 判读 → ingest` 三段式（§2.2），判读就是入库的门槛——
> 没读就给型，`ingest` 会因为缺 `evidence` 拒绝。

每份新材料入库前，你要：

1. **打开 `content.md` 读第一屏**（至少标题 + 开头两段）
2. 判断三件事：
   - 它**是不是**被声明的那个型？（`01-8-k` 里装的应该是 8-K，不是错误页 / 登录页 / 404）
   - 内容**是否完整**？（是不是只有导航栏、是不是空壳）
   - 有没有**明显归错型**？（例如 8-K 里含 `Item 2.02` + 财报，那它其实是业绩发布，属 `02-company-voice`）
3. 发现问题就**报出来**，不要默默接受

**判据**：正文能不能读出"这份文件在讲什么"。读不出来就是垃圾，不许入库。

### 3.3 同一份内容只入一次

同一份文件常被多个型取到（实测：一个 8-K 被 5 个型各取一遍，产生 4 份同内容副本）。  
入库前用 `sourceSha256` 查重，已存在就跳过——不要因为"另一个型也要它"就再存一份。

`python -m pipelines audit` 的 **A4** 就是查这个，跑完应该 0 组重复。

## 5. 不许静默

这个项目最容易犯的错是"看起来跑完了，其实什么都没拿到"。所以：

- **拿不到就说拿不到**，并说清是"查过确实没有（`empty`）"还是"我进不去（`unavailable`）"
- `empty` 不许写成"没有材料"；`unavailable` 不许写成"暂无风险"
- 入库了 0 份但报告说 `ok`，必须核对 `artifacts` 是不是空的
- 判读发现内容不对，**必须报**，不许"先入库再说"

判断自己有没有做到：跑 `python -m pipelines audit`，A1–A5 全过才算干净。

## 6. 每天该跑的

```bash
python -m pipelines doctor                      # 环境还在不在
python -m pipelines health                      # 今天哪些源能用
python -m pipelines run --all --as-of <今天>     # ① 34 型采集
python -m pipelines audit                       # 入库体检

python "pipelines/03-卖方与共识/zsxq_daily.py" --as-of <今天>            # ② 星球（5 个）
python "pipelines/03-卖方与共识/zsxq_browser.py" --all-rejected --as-of <今天>  # ② 星球（1 个）
```

外加两件人工协作：

- 知识星球：**只在会话过期时需要人**（`zsxq-cli auth login`，扫一次码）
- ima：每天都需人点下载（§2.3）

**定时怎么挂**：见 `docs/自动化任务.md`——三个任务（盘前自检 / 盘后采集 / 星球抓取）
的 cron 表达式和 prompt 都已经写好，直接抄。

**本包不含调度器，也不该加**：定时只在宿主 Agent 一处定义，避免"代码里写着每天跑、
实际根本没触发"这种静默失效。
