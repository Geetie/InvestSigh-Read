## 2. 四题各自的「过关标准」与「答不上来怎么写」

**Q1 同期同业／上下游的原话怎么说**
- 只认同一报告期的说法：两家覆盖的财季或数据月要对得上，发布日相差不超过一个披露周期。
- 抄**事实句**（数字、时点、当事方）；对方的**判断句另记**（"我们认为需求强劲"这类不算旁证）。
- 必须交代三件：**哪一期 / 谁说的 / 什么时候发布**。首段先给「本件报告期 = X，发布日 = Y，与 Meta 同期（Z）对不对得上」。

**Q2 本体把某件事归因给「行业逆风」，同业也这么说吗**
- 判「行业共性」要**两家以上互不转载的材料各自出现、且各自数字同向**。只有一家说、或几家引的是同一段话 ⇒ 记「**未获旁证**」，并优先怀疑是自身问题。
- 本件是旁证侧、只有一家 ⇒ 十有八九是「未获旁证」。**但不要只写四个字**：要写清①本体侧那句话不在本件内（本件没有 Meta 的归因段落）；②本件里唯一沾到"行业层面"的判断是哪句、它说的是不是和本体同一件事；③差在哪一步才够格（缺第二家 / 缺同向数字）。

**Q3 上下游的订单／资本开支／库存能不能交叉验证本体的量价说法**
- 对得上要满足三件：**覆盖同一批主体 + 单位能换算 + 期间对得上**。三件齐而方向相反才是矛盾；只有量级能对上记「**仅量级一致**」，不要写成验证通过。
- 本件的量价说法（本体侧）不在本件内 ⇒ 你要做的是：把这个材料里**最接近"订单/资本开支/库存/产能"的那几个数**抄出来，然后逐条过这三件，指出**卡在哪一件**，结论只到「仅量级一致」「方向一致但不可换算」「不构成上下游」这类，**不许**写"验证成立"。

**Q4 这个读数有没有时滞？当"现在"用对不对**
- 每个读数先标它**描述的是哪一期**，再看两份材料的期间差几季：**订单类领先、库存与渠道类滞后**。期间没对齐就并列的，记「**时滞未对齐**」，不出结论。
- 要落到具体天数/季度：本件的披露日 vs Meta 同期的披露日，差多少；本件讲的前瞻区间（如"售罄到 2027"）覆盖到哪一年。

## 3. 答案正文硬要求

1. **正文不写页码**：不写「第 N 页」、不写 `[p.1]`、不写「见 p.1」。页码只进依据区。
2. **三层粒度**：① 结论 → ② 具体内容（谁·何时·什么·多少·什么口径）→ ③ 判断（这意味着什么、为什么这么判）。每行一般 250–600 字。
3. **数字四出门**：量名、数值、期间、口径，后面跟一句「所以什么」。
4. **「未见」三段式**：未见 + 查了哪里（哪一页/哪一节没有）+ 为何相近那句不能算本项。**未见 ≠ 无**。
5. **不编**：不许「一般来说」「业内普遍认为」，不许拿别期/别份材料填空。
6. **不混算**：GAAP 与 non-GAAP 不混；口径变了写「同比不可比」。
7. **讲人话**：一句一个意思；不写「我已仔细核对」这类自述。
8. 一格只讲一件事；同一段引文不要在多题反复粘。

## 4. 依据区（校验器只认这一种格式）

```
### 依据
- p.1｜Orders 4.2 billion, up 27% year-on-year
```

- `- p.N｜原文片段`，`N` = `pages.json` 的 `n`（1 起，逻辑块号）。
- **逐字**：原样复制，不改字、不概括、不加省略号、不换语序、不补标点。
- **实体码与转义原样保留**：`&#160;`、`&#8221;`、`&#x27;`；`\$2 billion` 的反斜杠一起抄。
- 空格不计：原文把 `$` 与数字拆行时，一行内用空格连起来即可。
- **依据行不能以 `<` 开头**（解析器把整行当占位符丢掉，块数会静默减少）。
- **有几处支撑登几处**；每行至少 1 块，建议 3–6 块。
- 「材料未给出」的判断也要登依据：登能证明本件范围的那句（标题行、章节题、目录行）。
