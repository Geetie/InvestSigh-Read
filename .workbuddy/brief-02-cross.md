# 02 类判读 · 分派作业书（旁证与读穿已用；公司自己的话可复用 §2–§8）

> 判据真源：`corpus/prompts/02-型/<分册>.md`。与本件冲突时以手册为准。
> 首次用于 `02-cross-read` 四份（2026-10-28），四个 agent 并行，各写一份。

## 0. 你是谁、产出什么

- 你负责**一份**材料，只写**一个**文件：`output/meta/<你的材料 id>/material.md`（骨架已生成，你去填）。
- **禁写**其它任何文件；**禁改** `corpus/`、`server/`、`data/`、别人的 `output/`。
- 填完必须让 `node server/check.mjs meta/<你的材料 id>` **退出码 0**。

## 1. 本册第一纪律（旁证与读穿专有）

**同业说的不是 Meta 的事。** 材料主语是他方公司或行业时，原话只能当**旁证或反证**（"同一时间 xx 也这么说"），★ **禁写成 Meta 的事实**。

- 措辞：`某公司称…`、`据…纪要…`、`该材料显示…`。
- ★ 对方的**判断句**（"我们认为需求很强"）另记，**不当旁证**；能当旁证的是**事实句**：数字、时点、当事方、单位、期间。
- ★ 旁证不足就写「**仅单方表述**」；**禁止**用「业内普遍认为 / 市场普遍预期」补。

## 2. 题面（标题行必须逐字保留）

题号与题面**只能从手册 §4 问句表现场取**（`node server/new-material.mjs` 或 `renderTemplate`），
**不许自己发明问题**，也不许照 `corpus/templates/` 的 S 段写——S 段标题不带 `·`，`parse-md.mjs` 认不出，矩阵会全空。

## 3. 粒度：一条答案必须三层，缺一层不合格

```
① 结论 —— 一句话，可判定（是/否/仅量级一致/未获旁证）
② 具体内容 —— 谁 · 何时 · 什么 · 多少（带数字、单位、期间、口径）
③ 判断 —— 这条旁证的独立性、能不能反证本体、差在哪
```

- 300–700 字／题（材料很薄的可短，但不得用形容词凑）。
- **禁**：空话（"值得关注""需持续跟踪"）、总结尾巴、把题面复述一遍当答案。
- **禁裸编号**：`M-2`、`Q1` 这类内部编号最多进括号，写给人的一律写含义。
- 正文**不写页码**，也不写 `[p.N]`；页码只出现在 `### 依据` 区。

## 4. 依据：逐字，且只登本材料的原文

- 格式 `- p.N｜原文片段`，一行一处；**有几处支撑就登几处**。
- `N` = `corpus/materials/<id>/pages.json` 的 `pages[].n`，**逻辑块号，不是 PDF 页**。
- 校验是「去空白后子串匹配」：`&#160;` `&#8201;` `\$` 等实体原样抄；数字被拆行用**一个空格**连起来；但**不许**改字、概括、加省略号、换语序。
- ★ **整行都是 HTML 标签的依据行会被当占位符丢弃**（`^<.*>$`）。
- ★ 依据区**只登本材料**。引用本体（Meta）一侧的说法写进答案正文并注明来源（材料 id + 日期），**不给它编 p.N**；找不到语料出处就明说"未在本地语料中找到可核出处"。
- ★ **不许把入库注记当原文**：`competitor_class: true`、`> 本份全文未提及 Meta`、`retrieval: web_fetch 摘要级` 这类是**我们写的**，拿它当依据＝自证。载体限制（摘要级抽取）应写进答案正文作声明，不进依据区。

## 5. 材料怎么读

1. `meta.json` 看 `pageCount` / `figureCount`。
2. **通读全文** `content.md`（图片已按阅读顺序内联），不许只读开头就动笔。
3. 要逐字抄哪一段，回 `pages.json` 取该 `n` 的 `text`——那是唯一校验源。
4. **有图必读图** `figures/`（文件名 `阅读序_页_页内序.jpg`）。写「材料未给出」前先确认图里也没有。

## 6. 「未见」三段式

```
未见 + 查了哪里（哪一页/哪一节/哪几张图）+ 为何相近的声明不能算本项
```

- 整题「材料未给出此项」也**必须登 1–2 条范围证据**（议程/目录/章节标题/主体范围）；但**不许**把同一张长表在四题里重复登。
- 「未见」= 我没找到；「无」= 材料明确否认。不许混。

## 7. 禁止事项

1. 编数字、编日期、编人名、编机构。
2. 用行业常识补材料没写的东西。
3. 把判断句当事实，或把一家之说写成"行业共识"。
4. 拿旧期当本期。
5. 四题写成一个模子；重叠事实只在一处展开。
6. 留 `<在此填写答案…>` 占位符（**会被计成"有答案"**，是隐性失败）。

## 8. 收尾自检（必须做，且必须把结果贴回）

```bash
node server/check.mjs meta/<你的材料 id>
```

- 退出码 0，那行是 `N 行有答案 · M 块原文`，`N` 必须 = 手册行数。
- 报 `unverified` ⇒ 回 pages.json 重抄，**不许**删依据了事。
- **阳性对照**：随手把某条依据改一个字，确认报 `unverified`，再改回——证明校验真的在跑。

## 9. 交回来的东西

一段简报（不要贴整份 md）：各题一句话结论 / 依据块总数 + check 原始输出行 / 最值钱的那处矛盾 / 没敢下结论的地方。
