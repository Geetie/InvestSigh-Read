## 1. 怎么读一份材料

```
corpus/materials/<材料 id>/
    pages.json     ← 唯一页码权威。{"pages":[{"n":1,"text":"…"}]}，n 就是 p.N
    content.md     ← 同一批文本的通读版；有图时按阅读顺序内联
    figures/001_p012_00.jpg  ← 文件名 = 阅读序_页_页内序
    source.pdf
```

1. **先通读 `content.md`**，知道这篇讲什么、谁写的、什么时候。
2. **再按 `pages.json` 定位每一句话在哪一页**——依据区的 `p.N` 只能从这里取。
   注意：`content.md` 没有页边界，凭它猜页码必错。
3. **有图必看图**（`figures/` 非空时用看图工具逐张看）。图里的表格/基准分/柱值往往是全文最硬的数字；
   只看文字会写出假缺口。
4. 本批有三份是**超长单页**（一份 1.2 万 pt 高的整页截图，25,631 字），全篇只有 `p.1`，属正常，不要编出 p.2。
   若页尾出现 `2030FY` 这类成串碎片，那是图表 OCR 残渣，**不得当事实引用**。

## 2. 七问各自要什么（判据 = 手册 §3 / §4）

开头一句铁律：**这类件一律二手**。它说「有人说了什么」，不说「这事是真的」。
正文措辞必须是「据〔媒体〕〔日期〕报道，……」；**未回溯到一手的，一律不得写成已发生**。

| # | 问什么 | 拿到什么算过 | 答不上来怎么写 |
|---|---|---|---|
| Q1 | 一手来源是什么？能不能回溯？ | 逐条点名：哪份文件 / 哪家具名机构 / 哪个可查编号 / **匿名消息（几人、什么身份）**；每条标「已回溯 / 未回溯」 | 只有匿名信源 ⇒ 标「无法回溯」并说明匿名到什么程度（几个人、只给"知情人士"还是给了部门） |
| Q2 | 带来的**新事实**是什么（不是转述的那部分） | 逐条：此前未公开且可核的金额 / 时点 / 当事方 / 进展到哪一步；计划与意向要写明**尚未发生** | 全为转述 ⇒ 写「无新事实」，并说清它转述的是哪件已公开的事 |
| Q3 | 有可计量的数字吗？谁提供的？ | 每个数字：值 + 期间 + **提供者**（公司公告 / 监管文件 / 第三方数据商 / 匿名估算）+ 与已披露是否一致；同篇口径混用的逐个标出，**不许合并成一个数** | 无数字 ⇒ 写明，并给出该篇唯一的时间/规模表述作范围证据 |
| Q4 | 公司回应是什么 | 四态分开记：确认 / 否认 / 不予置评 / 截稿前未回应；**点名是谁说的**（发言人？备忘录？） | 报道没写回应 ⇒ 记「未载明」，并说明**不等于默认否认** |
| Q5 | 原文还是转载？转载原文在哪？ | 三样里至少两样：指名原发媒体与记者 / 正文有"据某家报道" / 有回链与更正。同一稿多家转载**共用一个来源** | 转载关系不明 ⇒ 写明"不明"及其证据（缺署名？缺回链？） |
| Q6 | 涉规则 / 监管时，说的是哪条规则的什么 | 规则名 + 转述内容 + 条款号/主管机关/生效日（三者有一即可核）；**生效依据必须回官方原文**，本篇只登记它转述了什么 | 题材不涉规则 ⇒ 写「本题不适用」并说明本篇题材是什么；**仍要登 1 条范围证据**（如导语或主题句），不许空着 |
| Q7 | 和已披露内容一致还是冲突 | 逐条对：一致 / 冲突 / 无法对照；冲突要写冲突点与报道源级别 | 手头无对照材料 ⇒ 写「无法对照」，**这不是"没有冲突"** |

**它不许被问的四样**：评级、目标价、假设取值、法定披露要素。问了必然"未见"，那是假缺口。

## 3. 输出格式（逐字照抄，改一个字校验就挂）

```md
## Q1 · 这条报道的**一手来源是什么**？能不能回溯？

（答案正文：中文，讲人话，不写页码，不写 [p.N]）

### 依据
- p.1｜原文片段，逐字
- p.3｜另一段原文片段
```

- `## Qn · …` 这一行**一个字都不许改**（题号、加粗、标点全照骨架）。
- `### 依据` 是固定的三级标题；依据区**只放** `- p.N｜片段` 这种行，一行一条。
- 分隔符是全角 `｜`（竖线也可，但全批统一用 `｜`）。
- 一份材料 7 行全填，**不许空行**。材料确实没有的，写「材料未给出此项」+ 为什么 + 范围证据。

## 4. 证据纪律（R1 / R2 / R3）

- **R1**：有答案就必须有依据块，一块都没有 = 不合格。
- **R2**：每一块必须是该页原文的**逐字片段**（校验器去空白后做子串匹配）。
- **R3**：支撑一处登一处，**不许只登一段交差**。一条答案通常 2–4 块；同一段原文**不许在七问里反复用**。

抄的时候最容易挂的五个点，全是实测踩过的：

| 坑 | 表现 | 正解 |
|---|---|---|
| 连字符号 | 原文 `artiﬁcial`（ﬁ 是连字）、`eﬀorts`（ﬀ） | 直接复制粘贴，别手打 |
| 反斜杠转义 | 原文 `\$8`、`\$30` | 反斜杠一起抄 |
| HTML 实体 | `Item&#8201;8.01`、`&#160;` | 实体原样抄 |
| 断行 | 一个句子被切成两行 | **一块必须落在同一行内**（不要跨行拼），挑一段不跨行的 |
| 省略号 | 抄了前半句加 `…` | 禁止截断；要么整句，要么不登 |

自检命令（必须跑到「合格」）：

```bash
node server/check.mjs meta/<材料 id>
node tools/gate-03-media.mjs <材料 id>
```

第一条查 R1/R2（报告 unverified 就是抄错字，回原文重抄）；第二条查厚度与格式（见 §6）。
**只跑到第一条合格不算完**——空答案也能合格，那是校验器的盲区。

## 5. 表达纪律（一条答案写到三层）

| 层 | 内容 | 够不够 |
|---|---|---|
| ① 结论 | 有 / 无 / 未见 / 无法核验 | 只有这层 = 不合格 |
| ② 内容 | **谁 · 何时 · 什么**（机构、期间、金额、原文怎么说） | 及格线 |
| ③ 判断 | 为什么这样定性；这条对估值/判断意味着什么；「未见」为什么不等于「无」 | 高分靠这层 |

具体要求：

1. **一格只讲一件事**，别把相邻题的答案塞进来。
2. **一句一个意思**。长句拆开；每句先给主语与结论，再给限定。
3. **数字必带四出门**（量名、数值、期间、口径）+ 一句「所以什么」。
4. **术语首现给人话**（如"蒸馏（用大模型教小模型）"）。
5. **不写自述**：「我已核对」「经仔细检查」一律删掉，查证体现在引用里。
6. **禁裸编号**：正文不出现 Q1/M-4/S02/段号这类内部代号（法定 Item、日期、金额不受限）。
7. **正文不写页码**，页码只在依据区。
8. **「未见」三段式**：未见 + 查了哪里（哪一页、哪一节）+ 为何相近的声明不能算本项。
   `未见。` 两个字 = 与「没查」无法区分 = 不合格。
9. **「未见」≠「无」**：前者是我没找到，后者是材料明确否认。混起来等于给材料栽赃。
10. **不编**：材料没写的写「材料未给出此项」，不许用行业常识补，不许写"一般来说"。

篇幅参考：短材料（1–2 页）每格 120–250 字；长材料（5 页以上）每格 200–450 字。宁短勿空，但三层必须齐。

## 6. 这一型的六个坑（踩了不报错，但结论会错）

1. 把报道当「已发生」——它是二手，未回溯不得写成事实句。
2. 多家转载当多个独立来源——同一原文共用一个源。
3. 用媒体转述当规则生效依据——生效依据只认官方原文。
4. 把记者的推断读成事实——推断要标「记者推断」。
5. 只看指控不看回应——回应/否认/拒评/未回应四态要一并写。
6. 记者的算术当公司口径——数字要问「谁提供的」。

**红灯（见到必写进答案，不要自己裁）**：核心指控只由匿名信源支撑 / 公司明确否认 /
与法定披露冲突 / 回溯不到一手 / 转载关系不明 / 疑似把推断当结论 / 涉规则题材的口径冲突。
红灯不是结论，是上报信号：写清哪家媒体、哪天、指控什么、一手是什么、公司怎么说。

## 7. frontmatter：填三处，其余不动

```yaml
title: "原文标题"          # 英文原文用英文标题；中文稿用中文标题；双语件用中文标题
issuer: "The Information"  # 媒体名（转载件写原媒体，不写载体平台）

```

