# 作业书 · 03-卖方与共识 / expert-channel（6 份）

一份材料一个 agent。目标：把 `output/meta/<材料 id>/material.md` 的 Q1–Q7 七行填满。

## 0. 唯一真源（按顺序读）

| 读什么 | 为什么 |
|---|---|
| `corpus/prompts/03-型/专家纪要与渠道交流.md` | 判读手册。§3 必过项、§4 问句表、§5 坑、§6 红灯，**全部要照做** |
| `corpus/materials/<id>/pages.json` | 原文。`{"pages":[{"n":1,"text":"…"}]}`，`n` 就是你要写的 `p.N` |
| `corpus/materials/<id>/content.md` | 同一份文本，图片已内联，便于通读找段落 |
| `output/meta/<id>/material.md` | 骨架，`## Q1 · …` 到 `## Q7 · …`，答案与依据都空着 |

**不要读** `docs/`、`_tmp_*`、`_to_delete/`、别的材料。骨架顶部那句 `> 骨架已生成… corpus/materials/mineru/…` 是过期路径说明，删掉。

## 1. 硬格式（违反即返工，check.mjs 只认这几条）

1. **题面一个字都不能动**：`## Q1 · **谁**在说…` 整行照抄，包括 `**` 与标点。只写「答案正文」和「`### 依据` 下面的行」。
2. 依据行严格写成 `- p.N｜原文片段`：半角 `p`、半角点、**全角竖线 `｜`**。`N` 必须等于你抄的那段所在的 `pages.json` 块的 `n`。
3. **引用逐字**。可以跨行断句拼成一行（校验会去掉所有空白），但不得改字、改标点、加省略号、换语序、把两段拼接。原文里的 `&#160;`、`$`、全角括号一并照抄。
4. 每条答案至少 1 条依据；**整份目标 12–20 条**。写「材料未给出此项」的行，也要挂 1–2 条范围证据（比如说明"全篇只有这几节"的那句标题行）。
5. **正文不写页码**：不写「第 3 页」，不写 `p.3`，不写 `[p.3]`，不写「（见 p.3）」。页码只许出现在依据行。
6. `### 依据` 必须是每节的**最后**一块内容，后面不要再写小标题或补充段。
7. 依据区不要用表格、不要用 `>` 引用块、不要给整行加反引号、不要写 `p.3–5` 这种区间。
8. frontmatter 里 `id / cat / sub / template / template_version / date / time / ticker / source_pages` 一律不动；`title` 可以改成一句中文描述，`issuer` 只在材料写明了整理方时填。

## 2. 内容纪律（check.mjs 查不出来，但这是验收线）

- **三层粒度**：① 结论 → ② 具体内容（谁 · 何时 · 什么 · 多少）→ ③ 判断（这意味着什么；为什么不能直接当事实用）。只写结论不合格。
- **「未见」三段式**：未见 + 查了哪里（哪一节/哪几段找不到）+ 为何相近的说法不能算本项。「未见。」两个字不合格。
- **不编**：材料没写的写「材料未给出此项」，再用一两句说明这份材料结构上为什么不可能有，不许拿行业常识补。
- **专家不是公司**：写「据本纪要整理的专家说法」「受访人称」，**不得**写「公司表示」「Meta 宣布」。
- **数字必带四件**：值 + 单位 + 时点 + 口径（专家估计 / 内部数据 / 转述）。区间估计就写区间。
- **讲人话**：一句一个意思；数字后面跟「所以什么」；不写「我已仔细核对」这类自述。
- 材料里同一张长表不要在多行里重复登记，各行的依据要挑最能支撑本行的。

## 3. 七行各自要点（对应手册 §4）

| 行 | 必须交代 |
|---|---|
| Q1 | 五项：受访者身份/职级/所属、**是否现任员工**、访谈日、整理方、有无脱敏或合规审阅痕迹。缺哪项写「未标」，五缺其一即判「不可追」。访谈日与整理日分开记。 |
| Q2 | 逐条标 **涉及 / 可能涉及 / 不涉及 / 无法排除**。判据是这件事能不能在公开渠道找到同一版本。命中即整条隔离，**不引细节**。 |
| Q3 | 逐条 **一致 / 冲突 / 无法对照**。冲突要写差多少、差在哪一期。答不上写「无对照材料在手」——**不是**「没有冲突」。 |
| Q4 | 材料里所有带单位/期间/口径的量，一条一条列（产能、颗数、价格、成本、人数、增速、份额），每条挂说话人职位与他接触这块业务的方式。 |
| Q5 | 这个数若为真会在哪里留痕（海关编码 / 招标公告 / 环评产能 / 招聘岗位 / 专利 / 财报科目）。指得出具体一处才可为 Ⅰ，指不出**一律 Ⅱ**。本类起点就是 Ⅱ。 |
| Q6 | 二选一 + 理由。判体例：主持人与受访人交替、带引号、带时间戳 ⇒ 逐字问答；摘要 / 要点 / 成段叙述 / 只有"他表示" ⇒ 整理者概述。体例不明按转述处理。 |
| Q7 | 是 / 否 + 排时间顺序。访谈日 vs 最近一次披露日，先排先后再判冲突。 |
