## 二、格式：三条硬规矩

### 2.1 答案正文
每题 3 层，缺一层不合格：
1. **结论**（一句话，回答题面问的那件事）；
2. **具体内容**（谁·何时·什么·多少，带人名与机构）；
3. **判断**（这说明什么／该怎么记／哪一处最值得上报）。

正文**不写页码**，不写 `[p.3]`。引用只在依据区。

### 2.2 依据区
```
### 依据
- p.3｜原文片段
```
- `p.N` 的 N 必须是本份 `pages.json` 里真实存在的块号（`source_pages` 已限定范围）。
- 引文**逐字**：不改字、不概括、不加省略号、不换语序、不补标点。原文有 `\$60 billion`、`\$3 billion` 这种反斜杠要一起抄；原文的 `&#160;` 实体照抄。
- 原文常被折行，抄的时候**把折行用单个空格连起来**即可（校验去空白后比对）。
- 一条答案 1–4 块。**别把同一张长表在六题里重复**：同一块最多在两道题里出现。
- **依据区只能引本份**。跨份对照（"上一季他说的是……"）写在**答案正文**里，用文字说明是哪一份，不要写成 `- p.N｜` 块——引别份的原文在这份里查无此文，check 会报 unverified。

### 2.3 「未见」三段式（两个字不合格）
```
未见 + 查了哪里（本份的哪几块/哪一节都没有）+ 为何相近的说法不能算本项
```
即使是「材料未给出此项」，也**必须挂 1–2 条范围证据**（能证明"我查过这一片"的那种：会议性质声明、议题清单、被问到的问句本身）。
「未见」≠「无」：未见 = 我没找到；无 = 材料明确否认。混起来等于给材料栽赃。
