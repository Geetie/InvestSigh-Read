But how does one construct such a network? We can use 8 separate leaf-switch planes to connect to each of the 8 100G ports on each GPU. Each plane will have 256 spine switches and 512 leaf switches, with the 512 leaf switches connecting to 256 individual GPUs using 1 link of 100G each, for a total of 131,072 GPUs.
But each plane will only connect to one 100G logical port per GPU, so we need 8 planes. Multiplying 8 planes times the 768 switches per plane we arrive at 6,144 switches. This is a ratio of 21.3 GPUs per Switch, which is more efficient than the ratio of 9 GPUs per switch if we had to use a 4-layer network using 800G ports. This is the network topology that is being deployed at Oracle’s Stargate – and it is one specific use case where Nvidia and Broadcom’s 512-Radix switches are gaining traction.
