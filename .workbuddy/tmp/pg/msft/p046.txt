From 2,048 GPUs to 524,288 GPUs - The Magic of High-Radix Switches at Microsoft
The network Microsoft has deployed into its Fairwater 2 Atlanta Datacenter is innovative and is on the frontier of what is being deployed for AI clusters today. Fairwater 2’s network takes the idea of a two-layer 512-radix network one step further, adopting a rail-only topology to increase the maximum number of GPUs that can be connected on a 512-radix two-layer network from 131,072 GPUs to 524,288 GPUs.
The number of GPUs that can be connected on a non-blocking clos network using switches with k ports and L layers of switches can be calculated using the formula below. If we assume a 2-layer network (L=2) built up using Spectrum-X SN5600 switches featuring 64 logical ports of 800G (k=64), then we find that the maximum number of GPUs we can connect on a 2-layer network is 2,048:
$$
2 \big ( \frac { k } { 2 } \big ) ^ { L }
$$
$$
2 \big ( \frac { 6 4 } { 2 } \big ) ^ { 2 }
$$

But what if we were to instead split the single 800G logical port per GPU into 8 ports of 100G each? The CX-8 NIC can support a breakout to 100G lanes, but not all 51.2T switches support 512 logical ports of 100G each – you need a 512-Radix switch such as the Spectrum-5 switch. The magic comes from the fact that the number of ports k is exponentiated by the number of layers L, and with this breakout scheme, we can reach up to 131,072 GPUs – a huge increase over the 2,048 without a high-radix switch.
