However, operating onsite gas generation or energy storage as peak assets requires integration with local electric utilities and/or grid operators. This can be used as an incentive to speed up grid interconnection, but it opens datacenter developers to additional administrative complexity. Additionally, reconfiguring an onsite gas system into a peaker plant requires the system to have good economics as a peaker plant, independent of its value to the collocated datacenter. If the local grid topography already has a glut of generation, then an onsite gas system becomes stranded once it is no longer a bridge power asset.
