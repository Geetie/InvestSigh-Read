## 2. 十二题各自要拿到什么（本册的核心）

> 全册第一纪律：**弃其评级、抽其假设**。评级与目标价只作背景，不进事实层。
> 每题的及格线：**① 结论 → ② 具体内容（谁·何时·什么·多少·什么口径）→ ③ 判断（所以什么）**。只写结论 = 不合格。

### Q1 关键假设取值（六项）

从估计表取六行，各带财年标号与口径（金额单位、GAAP 还是 adjusted）：

**收入增速 · 毛利率 · 营业利润率 · 资本开支 · 实际税率 · 摊薄股数**（可附 EPS）。

- 写法：`- **收入增速**：FY25A +22.2%、FY26E +25.5%（收入 252,261 百万美元）` —— 量名 + 值 + 期间 + 口径四件齐。
- 表里只有 EPS 与 P/E ⇒ 其余写「表内未给该行」，**不许从 EPS 反推**。
- 比率能算就自己算并注明"按 X/Y 推算"，算不出就照抄表内值。

### Q2 他和我差在哪一项、哪一年

**我方模型不在本仓库**，所以标准的诚实写法是两段：

1. 第一句：`我方模型数值不在本份材料内，逐行"他 vs 我"的对照需跨批（交主控）。`
2. 第二段做**本材料内可核的对照**：
   - 报告里若附共识表（FirstCall / Visible Alpha / FactSet / Bloomberg consensus / "vs consensus"）⇒ 做「**他的估计 vs 报告所附共识**」对照表，给 2–4 行、标财年与差额，并写差异集中在收入端还是利润率端。
   - 报告里没有共识 ⇒ 改做「**他本期 vs 他上期**」或「**他 vs 公司指引**」对照，同样给数。
   - 两者都没有 ⇒ 写清 `我方该项未定 ⇒ 记缺口`，并登记 1–2 条能证明"本件只有单点估计、无对照"的依据（估计表列头行）。

**不得倒推我方值**，不得写"我认为"。

### Q3 财年是谁的财年

- 看估计表列头：`FYE Dec` / `Dec-25A` / `12/25` / `FY2026E` / `fiscal year ending…` ⇒ **公司财年，且是十二月结账，等于日历年**，可直接与日历年末共识比。
- 非十二月结账（如 6 月、9 月结账）⇒ 写清"公司财年 vs 日历年差一个季度，不可直接比，需换口径"。
- 列头只写年份加 `E` 而不标月末 ⇒ **按日历年处理并注明"推定"**，不得当作已确认。

### Q4 预测修正：改了哪一项、从多少改到多少

- 找 `old / new`、`prior / current`、`from \$X to \$Y`、`raise/lower our … estimate`。
- 逐行：**旧值 → 新值（变动幅度）**，标财年。**只给方向不给旧值的，记"仅方向无幅度"，不自己补基数。**
- 必须分层判定：**改的是假设还是结论**。
  - 只改评级/目标价 ⇒ **结论变了，假设没变** ⇒ 写"不重要（观点变了，事实没变）"。
  - 改了收入/利润率/资本开支/EPS 估计 ⇒ **假设变了** ⇒ 重要，逐行给。
- 本份是首次覆盖、没有上一版 ⇒ 写「首次覆盖，无上一版可比」，并登证据（"Initiating Coverage" / 首次评级句）。

### Q5 情景

- 有 Bull/Base/Bear（或三档 PT）⇒ 三档各记 PT 与触发假设，说明差别落在收入增速还是利润率。
- 只有一个目标价 ⇒ 写「**单情景**」，并说明"未设三档，仅列下行风险方向"，登 PT 句。
- 目标价差三成而假设只差一个点 ⇒ 点出"杠杆在倍数不在经营"。

### Q6 估值方法（能互相印证吗）

- 方法 + 输入：相对估值给**倍数 + 指标 + 口径（NTM 还是本财年）**；DCF 给 **WACC + 永续增长率**。
- 目标价 = 倍数 × 指标，两个输入都要落下，否则无法复算。
- 多方法 ⇒ 明确说"两法是否得同一结果"（印证 / 不一致）；只有一种 ⇒ 写「**只给一种方法**」。

### Q7 目标价依据 / 方法解释 / 风险列示（2241(c)(1) 三件）

逐条判 有/无，三条都要有实质内容：

1. 目标价由**哪个方法**算出（能复算的公式）；
2. 方法的**关键输入**（EPS、倍数、WACC、永续增长率、溢价理由）；
3. **可能阻碍达成目标价的风险列示**（不是"竞争加剧"这种模板句，要有具体条目）。

缺任何一件 ⇒ 写「**未见依据**」并点名缺哪一件 ⇒ 这是**形式不合规，必须上报**。

### Q8 评级分布三件（2241(c)(2)）

1. **三档占比**：全公司 Buy/Hold/Sell（或 OW/EW/UW）各百分之几；
2. **各类别中过去 12 个月有投行关系的占比**（IB clients / Investment Banking Relationships 那一行/一列）；
3. **观测时点**：`as of <日期>`，通常"截至最近日历季末"；发布日距季末 <15 天可用上上个季末，**记清用的是哪一季**。

**三件必须来自披露表本身，不许自己数报告里的股票条数聚合、不许口算。** 没有 ⇒ 写「未见」+ 查了哪里（披露附录哪一节没有该表）。

### Q9 评级 / 目标价历史走势图

- 有图/表 ⇒ 记**覆盖期间**（起止日期）+ **变动条数** + 最近一次（日期/评级/PT）。覆盖满一年才须附，图长取自首次评级起与三年取短。
- 只有一句"Price target and rating history chart(s)"的声明而**文本层无数据** ⇒ 写「声明有图、文本层无数据，判未见」。
- 覆盖未满一年 ⇒ 写"覆盖不足一年，无须附"。

### Q10 九项冲突披露（本册最容易写废的一题）

**必须用表格逐项写**，格式固定：

```markdown
首页以样板句指明披露页（"See page N for …"），逐项内容在披露附录。逐项核对：

| 项 | 有/无 | 位置与内容 |
|---|---|---|
| ① 分析师及家庭持仓 | 未见 | 披露页仅列认证段，无任何分析师本人/家庭成员持股句 |
| ② 报酬是否挂钩投行收入 | 有（间接） | p.N 称报酬基于研究质量、客户反馈与"overall firm revenues"，未直接挂钩投行收入 |
| …（③–⑨ + ⑩其他重大冲突） | | |
```

九项固定口径：① 分析师及家庭持仓 ② 报酬是否挂钩投行收入 ③ 近 12 个月主/副承销或收取投行报酬 ④ 未来 3 个月是否寻求投行费 ⑤ 近 12 个月非投行服务报酬 ⑥ 是否客户及服务类型 ⑦ 实益持有该类普通股 ≥1% ⑧ 是否做市 ⑨ 分析师过去 12 个月是否从标的收酬 ⑩ 其他重大冲突。

三条硬规矩：

1. **「未见」不是两个字**：要写"查了披露附录哪一节没有该句"+"为什么相近的那句不算"。
2. **通用声明 ≠ 本项确认**。典型误判：印度/香港子公司"可能持标的债务证券 1% 以上"，不能算"母公司持本标的普通股 ≥1%"。这类写「有相近声明但主体与标的均不符」。
3. **「有」必须落到四要素**：谁 · 何时 · 什么（证券类别/服务类型/比例）· 原文怎么说。缺一项只能算"无法核验"。

范例（合格）：

> ✅ `实益持有该类普通股 ≥1%：未见。唯一相近的是一句通用声明：Citigroup Global Markets India Private Limited 及/或关联方「可能不时持有标的债务证券 1% 或以上」。主体是印度子公司、标的是债务证券，与本项要确认的「母公司持本标的普通股 ≥1%」主体与标的均不符，故判未见。`
> ❌ `7. 实益持股 ≥1%：未见。`

**收尾一句红旗**（本项确实有实益持股/做市/投行关系时写）：`红旗提示：该机构实益持有本标的 ≥1% 普通股 + 做市 + 近 12 个月收投行费 ⇒ 引用其观点时立场折价。`

### Q11 风险章挂了数字吗

- 判据：能不能写成「**若〔变量〕变 X ⇒〔哪一年〕EPS 或 PT 变 Y%**」。
- 能 ⇒ 抄下敏感度（通常估值段附表：WACC ±1%、永续增长率 ±0.5%、目标倍数 ±1x 对 PT 的影响）。
- 不能 ⇒ 写「**样板风险**（不是缺口）」，说明共几条、全为方向句、无一条附百分点或金额。

### Q12 静默期窗口

- 比：**发布日 vs 发行日**。作为承销商：IPO 后 ≥10 天、二次发行后 ≥3 天不得发布（例外：新兴成长公司 / 重大新闻经法务授权 / 活跃交易证券）。
- 绝大多数件 ⇒ 「否」：写清发布日、本件是常规覆盖更新、全文未见发行时间线。
- 若披露里出现 `Manager`/`Co-Manager`/`underwriting`/`IPO`/`follow-on` 且日期接近 ⇒ 逐条判，并写明是否落窗。

## 3. 依据区怎么写（校验器只认这一种格式）

```
### 依据

- p.2｜Revenue 200,965 252,261 294,274
- p.7｜Gross Margin 80.3% 81.3% 82.3% … 82.0% 81.6%
```

- 一行一条 `- p.N｜原文片段`。`N` = `pages.json` 里的 `n`。
- **逐字**：从该页 `text` 原样复制，不改字、不概括、不加省略号、不换语序、不补标点。
- **实体码原样保留**：`&#160;` `&#8201;` `&#8220;` `&#9744;` 照抄；`\$725` 这类**反斜杠一起抄**（这是 GS 的写法，去掉会判 unverified）。
- **数字被拆行是正常的**：校验器不认空白，`$` 和 `51,242` 分行时，可在一行内用空格连起来写。
- **表格行抄完整一行**（`<tr>…</tr>` 那类照抄，别抄半行、别删 cell）。
- **有几处支撑就登几处**，不同页分开登；**每一行有答案的题至少 1 块**（校验器唯一硬卡）。
- 一节一般登 3–8 块；**同一句不要在多题反复粘**（确需复用最多两次，且两处用法不同）。

**「材料未给出此项」「未见」「不适用」的行也必须登依据**：登那条能证明"本件范围"的原句（首页标题行、估计表列头、"产品型不符"的页眉）。**只登 1–2 条**，别把同一张长表在六题里粘六遍。

## 4. 文本层损坏 / 载体异常怎么办（诚实地写，不许编）

1. **披露页 OCR 乱码**（典型：Goldman 的 p.6–p.9、部分 Bernstein 附录，字符粘连如 `We,Ericertredtirde`）：
   仍可写结论，但依据要登**该页可辨识的残片**（例如 `Additional disclosures required under the laws and regulations of jurisdictions other than the United States`），
   并在答案里注明「该页文本层编码损坏，逐字读取不可行，仅能确认该节存在/不存在某表」。**不许把乱码当内容猜。**
   若同页仍有可读表格（如 GS 的 `Rating Distribution` 表百分比是干净的）⇒ 正常取数。
2. **`xlsx` 模型件**：`pages.json` 的每一页 = 一个**工作表**，`p.1` 是工作表目录。先读 `p.1` 认表名，再跳到 `P&L Summary`/`Valuation`/`Cash Flow` 对应页。Q1 从假设页逐行取，Q6 从 Valuation 页取。答案里注明"载体为模型件，`p.N` 指第 N 个工作表"。
3. **只有 1–2 页的短件**（评级变动通知、摘要、中文摘译）：按手册 §4.5 四查（署名/日期/评级目标价/冲突披露），缺两项以上 ⇒ 写「形式要件缺 X 项，按转述处理」，档位 Ⅲ，并**逐项说明缺哪几项**。
4. **主题/行业件无个股评级**：Q1、Q5、Q7、Q9 可答「产品型不符（本件为主题研究，无个股评级与目标价）」，但**要给依据**（首页标题行/摘要句），且把该件**有的**东西写进 Q1（长期假设行：渗透率、增速、TAM 等）。
5. **同一报告的中英文两版**（如"大摩 Meta 新云 5 点"中译、"摩根士丹利开放权重三种状态"中译）：各按**本份材料**写，不互相引用、不补译版没写的内容。

## 4.6 试跑补丁（实测踩过，必须遵守）

1. **依据行不许是残片**。`- p.5｜% chg vs.`、`- p.2｜as % of` 这种 8 个字符的碎片，虽然能过校验器，但等于没登证据。
   依据行要求：**能独立读出一个事实**（含数字、公司名或完整短句），一般 ≥25 字符；表格行抄完整 `<tr>`。
2. **Q10 要写"名单含/不含本标的"**。Morgan Stanley 的披露常是逐票列名型（一长串公司名）：
   抄名单时要点明本文标的在不在其中（例：`名单含 TSMC、ASE、KYEC` ／ `名单只列 LG、SK hynix，不含本标的`）。
   这是最有信息量的写法，比"有"一个字强一百倍。
3. **Q4 的变动幅度自己算对**。`32.99 → 31.51` 是 −4.5%，不是 −0.1%。凡写百分比，用 `(新−旧)/旧` 复算一遍；
   原文自带百分比的照抄原文并注明"原文口径"。
4. **产品型不符也要把该件真有的东西写进 Q1**。主题件没有损益表，就写它真在用的那条假设链（产能/资本开支/渗透率/单 GW 换算），
   然后明确"毛利率、营业利润率、税率、股数四项材料未给出"。干写"产品型不符"四个字 = 不合格。

## 6. 交回来时报告什么（给我，不写进 material.md）

每份一行：


## 7. 反面清单（这些是实测被退回来的写法）

| 不合格 | 为什么 |
|---|---|
| 抄下"目标价 800、维持买入"当答案 | 那是观点，不是事实层 |
| Q1 只写 EPS 和 P/E | 六项假设才是值钱的部分 |
| Q8 自己数报告里的 Buy/Sell 条数 | 评级分布是机构级披露，不是数出来的 |
| Q9 只有一句"有图" | 要给覆盖期间与最近一次变动 |
| Q10 写成「未见。」两个字 | 与"没查"无法区分 |
| Q12 写"未见静默期声明" | 静默期不是靠声明判的，要比发布日与发行日 |
| 依据里概括原文、加省略号、改语序 | 校验器立即 unverified |
| 多题复用同一句长表 | 反填充：长表只在真正用到它的那一题登 |
| 答案里写"经逐项核对，确认…" | 自述不算证据，查证体现在引用里 |
