## ima 客户端：六条路逐条排除，结论是"无程序化通道"

用户提示"ima 需要客户端才能下载源文件，客户端本机已安装"，于是把客户端方向全部试了一遍。
**结论：本机取 ima 知识库只能人工点下载，没有任何程序化入口。** 六条路每条都有证据：

| # | 路径 | 结果 |
|---|---|---|
| ① | ima.qq.com web 端 | 无知识库视图（五路由 404 / hash 渲染首页 / 从不请求 kb 接口） |
| ② | 客户端 `imsdk/*/im.db` | 只有 IM 表（session/groupinfo/topicinfo/kvstore），groupinfo 与 topicinfo **均 0 行** |
| ③ | 客户端 `127.0.0.1:5283` | **是 TLS 服务**（HTTP 会被 400 挡回），但任意方法+路径都返 **200 空 body** = 哑响应 |
| ④ | 「IMA知识库」扩展搬到普通 Edge | UI 完整渲染，但 `chrome.imaFrame === undefined`、`chrome.storage.local` 空 → 点"立即登录"**静默无效** |
| ⑤ | 客户端 `--remote-debugging-port=9222` + 独立 user-data-dir | 第二实例起得来（39 进程、profile 已建），但 **9222 无监听**、主进程零 Listen 只有出站 443 |

### 关键取证细节（下次别再重试）

- **扩展依赖私有权限 `imaFrame`**：`permissions` 里有 `imaFrame` / `fileSystem` / `downloads`，
  但普通 Edge 只有标准 chrome.* API，`chrome.imaFrame` 是 undefined。这是它**只能在客户端内跑**的硬原因，
  不是 manifest 缺 background（它确实没有 background，纯页面）。
- 扩展 ID `nkohmbngmopdajidckglcoehlaeepeoi`（IMA知识库 v5.20.2），manifest 带 `key` 字段 ⇒ 加载后 ID 不变。
  `chrome_url_overrides.allknowledge → index.html`；`chrome://allknowledge` 在普通 Edge 里是 `ERR_INVALID_URL`。
- 扩展的接口前缀是 `${base}/cgi-bin/s/`，鉴权用自定义头 `x-ima-cm` / `x-ima-ckey` / `x-ima-ctk` / `x-ima-ctk-expire`
  （TRPC 风格）。知识库列表接口路径是**变量拼接**的，静态搜不到字面量。
- ima 的 `Preferences` 里**没有 download 配置** ⇒ 客户端点"下载"落系统 `Downloads`。
  Downloads 里确实有 `曦源.pptx`（10-29 12:28，12.5 MB）这类近期导出物。

### 可行方案（已写进 yaml 的 `daily.drop_dir`，默认空=未启用）

### 3 份 UNVERIFIED 的三种不同根因（都修了）

`node server/check.mjs` 报 3 份 `查无此文`，逐块二分定位后是**三类完全不同的原因**：

| 材料 | 块数 | 根因 | 修法 |
|---|---|---|---|
| `...-2026-02-17-InternetWhatAPP...` | 3 | quote 末尾多抄了 `</tr>`，原文该处后面还有 `<tr><td></td>...` | 剥掉尾部闭合标签 |
| `...-2026-07-06-GREATER...` | 1 | 连字符差异：quote 用 `-`(U+002D)，原文是 `‑`(U+2011 不断行连字符) | 宽松匹配定位后**按原文回填** |
| `...-2026-07-02-MetaPlatforms` | 4 | **大小写**：quote 写 `1Q28E diluted GAAP EPS`，pages.json 是小写 `1q28e...`（MinerU 把 PDF 小型大写抽成小写） | 小写不敏感定位后按原文回填 |

**回填法**（关键手法）：用「去空白+去零宽+统一连字符+统一引号」的宽松串在原文里定位，
再把 loose 坐标**逐字符映射回原文坐标**，取原文切片替换 quote —— 这样字符与 pages.json 完全一致，
而不是硬改校验器（改 norm 会削弱全库校验强度）。
